- **Feature: Durable job queue**: `jaclang.scale.jobs` adds `enqueue`, `cancel` and `job_info`. A walker can queue a walker or function (private ones included) with arguments, an idempotency key, a start time, retries and a timeout; `[scale.jobs] enabled = true` runs a runner per server worker that claims its own service's jobs from the `jac_jobs` table with `FOR UPDATE SKIP LOCKED`, renews the lease of each job it is waiting on, gives up on an attempt at `timeout_s`, re-queues a stopped runner's job when its lease expires, backs off between attempts and marks a job `dead` after `max_attempts`. Shutdown waits for running jobs only as long as the drain budget allows. Queue depth by status is exported as `jaclang_scale_jobs`.
