- **Feature: Durable job queue**: `jaclang.scale.jobs` adds `enqueue`, `cancel` and `job_info`. A walker can queue a walker or function with arguments, an idempotency key, a start time, retries and a timeout; `[scale.jobs] enabled = true` runs a runner per server worker that claims jobs from the `jac_jobs` table with `FOR UPDATE SKIP LOCKED`, renews a lease while a job runs, re-queues a dead runner's job when its lease expires, backs off between attempts and marks a job `dead` after `max_attempts`. Queue depth by status is exported as `jaclang_scale_jobs`.
