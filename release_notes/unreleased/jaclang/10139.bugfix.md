- **Fix: build-kit seals the native kernel again after #10135**: #10135 typed a flow path reached only through `Never` as `Never`. The native backend lowers from the types the checker records, and code in an arm the checker considers impossible still has to be lowered, so the kernel seal aborted with E5092 on `EsJsxProcessor.element`. Such a path now falls back to the declared type again. An `is None` check on a type that cannot hold None still narrows that arm to `Never`, so `NoneType` does not leak past the `if`.
