- **Serve: a request key that is not a Jac name binds a renamed field**: `@restspec(params={"from_date": "from"})` maps a walker field or function parameter to the request key it binds. An endpoint can now take keys that are Python reserved words (`from`, `class`, `async`, which E0067 rejects as field names) or that contain a dot (`hub.mode`) without changing its URL contract. The request key is used for path, query, form, JSON body and upload keys, for webhook bodies and WebSocket messages, and in the OpenAPI schema and validation errors. A request that sends the field name still binds, so Jac client code that spawns the walker keeps working. `@restspec` raises `ValueError` when a mapped name is not a field or parameter, when two fields share a request key, or when a request key is another field's own name. E0067's help now points at the option.
