- **Scale: the unreachable CPU and memory quantity parsers are gone**: `#7828` unified the Kubernetes deploy path and deleted the method that called `validate_resource_limits`, but left the validator in place along with its now-stale import. That validator was the only caller of `parse_cpu_quantity` and `parse_memory_quantity`, so all three went dark together and stayed that way, exercised by nothing but their own tests. What made them worth removing rather than leaving alone is that `runtime/cli/diagnostics.jac` had meanwhile reimplemented the same Kubernetes quantity rule as `_cpu_to_millicores` and `_mem_to_bytes`: the package carried a dead original beside a live duplicate, two spellings of one rule with only one of them reachable, which is exactly the shape that sends a later fix to the wrong copy. `parse_storage_quantity` reads as the third sibling and deliberately stays, because `resize_pvc_if_needed` calls it and that path is live. Pure deletion with no behavior change; the tests that went covered only the removed functions.
