- **Fix: a native lowering that stops for its dependencies builds no IR first**: since #10150 a unit whose dependencies were not lowered yet stops, has them lowered, and is lowered again. The stopped attempt had already built the whole runtime helper set and declared every imported module's types and abilities, all thrown away and built again by the next attempt. Dependency discovery now runs before any IR is built, so a stopped attempt only walks the imports and asks for their interfaces, and each unit builds its runtime helpers once.
