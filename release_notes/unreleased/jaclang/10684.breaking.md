- **Breaking: Groups, sharing and an ADMIN level**: `set_access(node, who, level)` and `clear_access(node, who)` give a user or group `Member` access to a node and everything under it without changing who owns anything, replacing `Jac.allow_root`, `disallow_root`, `allow_group` and `disallow_group` (entries they stored are still read). Changing access needs the new `AccessLevel.ADMIN` and raises `PermissionError` when refused; grants only raise a level and a `NO_ACCESS` setting always blocks. The SQL access filter's cost no longer grows with the number of groups a caller belongs to; see the breaking changes page.
