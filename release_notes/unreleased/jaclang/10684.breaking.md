- **Breaking: Groups and an ADMIN level**: a group is any node that owns itself, `set_access(node, who, level)` and `clear_access(node, who)` manage `Member` edges that give `who` the node and everything under it, and changing access now needs the new `AccessLevel.ADMIN` and raises `PermissionError` when refused. Grants only raise a level and a `NO_ACCESS` entry always blocks; see the breaking changes page.
