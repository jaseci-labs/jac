- **`root.shared` no longer fails in a `jac test` file or test that runs after one that built a server**: `JacAPIServer` registers a process-wide shared-root resolver, and the reset `jac test` runs between files and tests kept it along with the guest-root id it had cached. A later `root.shared` in the same worker then failed with `Shared root unavailable: id … did not resolve to a Root node`, so suites failed depending on test order. The reset now drops the resolver, and `JacTestClient.close()` releases the one its server registered, so tests no longer need to call `set_shared_root_resolver(None)` themselves.
