- **Client: dependency installs skip versions published in the last day**: `jac build` and `jac start` failed with a registry 404 when a dependency had a version published only minutes earlier, because npm cannot serve a brand-new version's download right away. Every dependency install Jac runs (client builds, `jac install --npm --global`, and desktop and mobile setup) now skips package versions newer than one day and uses the newest older version that still matches. Change the age with `min_release_age_days` under `[client.npm]` in the project's `jac.toml` (`0` turns it off), and list packages it should not apply to in `min_release_age_excludes`; both apply to every install in the project, and a global install uses the project it is run from.
