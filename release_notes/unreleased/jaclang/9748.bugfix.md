- **Client: dependency installs skip versions published in the last day**: `jac build` and `jac start` failed with a registry 404 when a dependency had a version published only minutes earlier, because npm cannot serve a brand-new version's download right away. Client dependency installs now skip package versions newer than one day and use the newest older version that still matches. Change the age with `min_release_age` under `[client.npm]` in `jac.toml` (`0` turns it off), and list packages it should not apply to in `min_release_age_excludes`.
