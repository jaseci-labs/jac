- **Fix: operator chains never wrapped in `jac fmt`**: Binary (`+`, `*`, `|`, ...), comparison, and match-or chains joined operands with a plain space, so the printer had no break opportunity and hand-wrapped chains collapsed onto one unbounded line (a 6-line string concat became a single 377-char line). All operator chains now share the bool-chain layout: one breakable group, operand per line when over width, operator leading the continuation line. Precedence is preserved (a tighter-binding subexpression stays an opaque operand), keyword operators like `spawn` keep the legacy layout, and compact contexts (filter/assign comprehensions) stay compact.
- **Fix: bare Python import used by client code now errors instead of silently breaking the page**: `import from react { useRef }` (no quotes) resolves in the Python ecosystem, so placement pinned it server-side and the ES backend pruned it from the client bundle; the page then died with `ReferenceError: useRef is not defined` while `jac check` stayed green. A client value use of a bare-import symbol is now `E5084`, naming the symbol and module and pointing to the quoted npm form (`import from "react" { useRef }`). Annotation-only uses stay silent (ES output erases annotations), and every bare `import from react` in the shadcn registry, admin UI, ai_ui, and littleX now uses the quoted form.
