- **Fix: Native Optional callbacks, and bound methods that compare and release correctly**: On the native backend, calling a `Callable[[...], R] | None` value after a `None` check now works (a `None` value raises `TypeError: 'NoneType' object is not callable`, as in Python); previously the call demoted its function, or in statement form (`self.on_event(x);`) was silently dropped. Two bound methods of the same receiver now compare equal (`c.bump == c.bump` is `True`, as in Python) instead of comparing two closure objects by address, so `if cb == self.handler` unsubscribe checks work. A bound method read from a temporary (`return Counter().bump;`) no longer leaks its receiver, and reading one through a `None` receiver raises `AttributeError` instead of storing a null callback.
