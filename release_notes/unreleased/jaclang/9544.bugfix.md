- **Fix: Native Optional callbacks and bound methods**: On the native backend, calling a `Callable[[...], R] | None` value after a `None` check now works (a `None` value raises `TypeError: 'NoneType' object is not callable`, as in Python); previously the call demoted its function, or in statement form (`self.on_event(x);`) was silently dropped. A bound method used as a value (`f: Callable[[int], int] = c.bump`, `Holder(f=c.bump)`) now lowers to a closure over its receiver instead of failing or storing a null callback that crashed when called, and `c.bump == c.bump` is `True` as in Python.
