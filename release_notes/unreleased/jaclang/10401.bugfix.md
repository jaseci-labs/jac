- **Native: a local read before its assignment raises UnboundLocalError**: When native code read a local before it was assigned on that path, it returned the zeroed slot (`0`, an empty string, a null reference). When the read came before the assignment in the source, the call it fed got a null argument and the process died with SIGTRAP or SIGSEGV. Such a read now raises `UnboundLocalError` with CPython's message, and a handler can catch it. A loop-carried read, one that runs only after an earlier iteration assigned the local, now lowers natively instead of demoting its function.
