- **Fix: Large string literals no longer compile in quadratic time**: The lexer rebuilt each string token one character at a time. CPython makes that amortized linear by resizing in place, but the native compiler copies on every append, so one literal cost time proportional to the square of its length. Token text now comes from the source span the scan already tracked. A 1 MiB literal type checks in 0.016s instead of 14.5s.
