- **Fix: a second module-level definition of a name is an error (E2036)**: Two module-level functions or archetypes with the same name compiled silently; the later one ran while calls were checked against the earlier one, so `jac check` passed a call that then failed at run time. The duplicate is now reported at the second definition, naming the first one's line. A declaration with its `impl`, decorated definitions such as `@overload`, and Python sources are unaffected.
