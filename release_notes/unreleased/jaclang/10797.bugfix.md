- **Fix: a build no longer stops when the jac cache can't be written** (#10663): a build whose client code uses the graph (nodes, edges or walkers on the client) stopped with `PermissionError` while caching the client OSP kernel when `$JAC_CACHE_HOME/jir` was read-only, for example in an image whose cache belongs to root but runs as another user. The kernel is now cached in `$TMPDIR/jac-cache-<uid>/jir/client_kernel` when the jac cache can't be written, and an existing cache is still read first, so a cache baked read-only into an image keeps working. If the kernel's JS can't be stored anywhere, the build keeps it in memory, logs one warning and carries on.
