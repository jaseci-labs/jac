- **Compiler: closed-world native interop link (#9782 step 1)**: Native code that calls a server-side function must now have a declared provider or the build fails — a bare `import from os { getppid }` no longer lowers to an unbound extern resolved against the process symbol table. Interop callback symbols are module-qualified (`__jac_na_import_*`), so qualified, bare, and aliased spellings of the same function resolve to one symbol; the "called before registered" stub raises instead of returning 0, and unmarshallable callback signatures are rejected rather than silently typed as `i64`.
