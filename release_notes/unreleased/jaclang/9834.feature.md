- **Native: qualified interop symbols and a declared-provider gate**: A native call to a server function now links against one module-qualified symbol, `__jac_na_import_<module>_<name>`, derived from the module that defines the function. Bare and aliased imports of one function share it, and the same name imported from two modules calls each module's own function. The JIT, the shared-library glue, the Python callback table and sealed product records all key callbacks by that symbol, so a native product built by an older jac must be rebuilt. Callbacks pass sized scalars (`i8` to `u64`, `f32`, `f64`) at their own width and sign. A native function in a mixed module can now call a server function its module imports. A native call to a server function with no provider is refused by native legality (E5092): the calling function is placed in Python, or the build fails when the module must be native. A callback reached before the module defining its Python function ran stops the process instead of returning 0.
