- **Fix: Native enums no longer silently collapse to zero, or crash when declared in an `impl` block**: Under the native backend, an enum whose values native cannot store (such as `enum Ratio { Half = 0.5, Whole = 1.0 }`) lowered every member as `0`, so `Ratio.Half == Ratio.Whole` was `True`. It now reports `E5092` where the enum is used, and the file runs on the Python backend instead. Enums whose members are declared in an `impl` block (`enum Color; impl Color { RED, GREEN }`) no longer crash native compilation.
