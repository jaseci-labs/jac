- **Checker: a method on a generic archetype can name its own class's type parameter**: the scope test consulted the innermost enclosing function *or* the innermost enclosing class, never both, so an enclosing function short-circuited the check and a class parameter used inside a method reported `E1065: Type variable "T" has no meaning in this context`. An `impl` block was not recognized as a scope at all, its signature hanging off an `ImplDef` rather than an `Ability`, so `impl C.m(v: T)` reported the error even where the same method reads clean in the class body. Scope resolution is now one lexical walk outward: a function binds its declared type parameters (which were not consulted before, so a `def m[U]` whose `U` appeared only in the body was reported) along with the ones its signature mentions, an archetype binds the class's, and an impl block binds what its own signature mentions and then hands the walk to the declaration it implements, so it sees exactly what the class body sees. A method's own parameter shadows the class's naturally, since the walk meets the function first. The walk still ends at the first enclosing archetype, which is PEP 484's rule that a nested class does not inherit the outer class's type variables. With that closed, the bundled `contextvars` shim ships: `ContextVar[T]` as a single process-wide cell with `.name`, `.get()`, `.get(default)` and `.set(value)`, walking CPython's precedence from the value last set through the call's default and the constructor's default down to `LookupError`. `None` is the sentinel for both "no value" and "no default", so an explicit `get(None)` reads as an omitted argument where CPython keys that step on whether the argument was passed; there is one cell per variable rather than one per context, since the native pathway has neither asyncio tasks nor threads to separate them, so `copy_context`, `Context.run` and the `Token` that `set` returns are not provided; and the type argument must be a reference type, since a generic archetype is type-erased natively, a scalar one being refused naming the instantiation rather than lowered.
