- **Fix: C source export compiles code with a saturating unsigned subtraction**: The LLVM optimizer turns `a - b if a > b else 0` on unsigned values into `llvm.usub.sat`, and the C backend wrote that intrinsic's floor as the undeclared name `ULLONG0` (`UINT0` for 32 bits), so the exported `main.c` did not compile. The floor is now written as `0`.
