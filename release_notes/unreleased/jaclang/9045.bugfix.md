- **Fix: Unset `jac.toml` environment variables are reported by the commands that use them**: `jac scale deploy` now stops when a `[scale.secrets]` or `[scale.kubernetes]` value needs a variable that is not set, instead of shipping the literal `${VAR}` text, and `jac run` warns on an unset `${VAR}` and stops on an unset `${VAR:?message}`. `jac check`, `jac fmt` and other tooling stay silent, so they never need deploy-time variables exported.
