- **Fix: imports from platform-variant modules resolve on any host**: `jac check` (and native builds) on a darwin host refused the relative imports made by linux-suffixed modules (`signal.linux.jac` to `._signal_native`, `subprocess.linux.jac` to `._subprocess_native`) and its bare `import signal`, because variant lookup probed the host os alone. Variant resolution now starts from the importing module's own declared os.
