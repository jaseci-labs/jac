- **Editing a native-only runtime unit no longer rebuilds the compiler**: `runtime/na_stdlib/**`, `compiler/jc_unit.jac` and `compiler/jc_materialize.jac` join the compiler digest by path rather than content (`!` lines in `compiler_inputs.txt`). An edit to one of them relowers that unit and relinks the kernel (about a minute) instead of moving the whole module cache to a new generation and recompiling every self-host module (about ten).
