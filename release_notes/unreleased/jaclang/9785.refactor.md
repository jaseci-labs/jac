- **Refactor: Native lowering analysis runs before the IR emitter**: The native backend's `NaIRGenPass` used to decide what each construct meant while it wrote the LLVM IR for it. Those decisions now live in a pass that runs first (`NaLowerAnalysisPass`), and the emitter reads its result. No behaviour change is intended: the same programs lower natively to the same IR, and the same constructs are refused with the same diagnostics.
