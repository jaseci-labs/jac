- **Fix: every binder that rebinds a variable to another type is reported** (#10453): after `title = Label()`, writing a string into `title` with tuple or list unpacking, a chained assignment (`other = title = "x"`), a walrus (`title := "x"`), `with ... as title` or `except E as title` passed `jac check`, and native code then used the string as the object. These are now `E1001`, the same as `title = "x"` and a `for` target. Unpacking an element that is not a tuple also gets the type iterating it yields, so `for [k, v] in rows` over `list[list[str]]` types `v` as `str`, and `for (a, b) in d` over a dict no longer types `b` as the dict's value type.
