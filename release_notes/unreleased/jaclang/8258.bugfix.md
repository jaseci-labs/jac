- **Native: an AOT build that produces no IR says which module and why**: a module the placement solver decided was native could finish an `aot_mode` compile with no LLVM IR and nothing in the diagnostic ledger, so `jac nacompile` printed a bare "Native compilation produced no LLVM IR" while `jac check` and `jac run` stayed green on the same file. The compile driver now delivers an `E5092` naming the module, and when the native codegen passes are dropped from the schedule by an `ImportError`, that error is quoted in the diagnostic instead of being swallowed. A guardrail compiles the multi-module chess example to a binary and plays a game with it, so the AOT lane cannot regress behind a green run lane.
