- **New bundled `fcntl` module (native backend)**: `fcntl.fcntl` (F_GETFL/F_SETFL/O_NONBLOCK and friends) and `fcntl.ioctl` backed by a `_fcntl_native` libc floor. `ioctl` returns the (updated) arg buffer -- e.g. a packed `winsize` struct for `TIOCGWINSZ` -- for any `bytes` arg (CPython returns None for immutable buffers), and raises `ValueError` where CPython raises `OSError`.
- **New bundled `termios` and `tty` modules (native backend)**: CPython-shaped `termios.tcgetattr`/`tcsetattr` (`[iflag, oflag, cflag, lflag, ispeed, ospeed, cc]` with cc as 32 one-byte `bytes` objects, matching CPython) over a `_termios_native` libc floor -- the raw 60-byte glibc `struct termios` travels opaquely so save/restore is byte-exact -- plus `tty.setraw`/`tty.setcbreak` ported from CPython's `tty.py`. Errors raise `ValueError` where CPython raises `termios.error`.
- **New bundled `select` module (native backend)**: `select.select(rlist, wlist, xlist, timeout=-1.0)` over `poll(2)`. Divergences from CPython: `-1.0` is the block-forever sentinel (not `None`), POLLERR/POLLHUP report an fd as readable *and* writable, and the exceptional list is always empty.
