- **`raise` accepts `any` values and catches non-exceptions it used to miss**: `raise e` with `e: any` was rejected with E1090 "Cannot raise Any"; it is now accepted, as are `type[E]` values and TypeVars bounded by an exception. A union with a non-exception member, such as `ValueError | None`, is now E1090 instead of a runtime `TypeError`, and a `raise X from cause` whose cause is not an exception or `None` is the new E1161. The name bound by `except (A, B) as e` is now typed `A | B` rather than the tuple of classes, so `e.args`, `raise e` and `raise ... from e` check correctly.
