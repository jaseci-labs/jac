- **Fix: client tests in a `.test.jac` annex find the module under test**: `jac test` handed a `.test.jac` annex straight to the client test runner instead of resolving it to the module it belongs to, so a client-placed module's tests compiled without the module itself. The test called a name nothing defined and failed at run time with `ReferenceError: <name> is not defined`, or, where the base module carried the placement pin the annex no longer matched, with the client backend refusing a builtin it had left unlowered. Only the client branch was affected: the server branch already resolved the annex to its base file. `module_is_client()` and `run_cl_test_file()` now resolve an annex to its module, which fixes directory runs and explicit `jac test foo.test.jac` alike.
