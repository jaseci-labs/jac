- **byLLM: System One backend**: A `by llm()` call site whose return type is closed-set can now be served by a System One decision model instead of a chat model, with no change to the Jac source. Name the model `systemone:<provider>/<model>` (providers: `typesafe` for Jev, `litellm` for the proxy route, `openjev`, `laya`) and byLLM lowers the call to the `/v1/systemone` protocol from the compiler's IR: an `enum` return becomes a `choice` whose criteria are the members' `sem` strings, `bool` becomes a `noul`, `list[E]` becomes one `noul` per member with the answer ordered most probable first, and an `obj` whose fields are all closed-set becomes one question per field in a single request, rebuilt into the object. Provider capabilities (option caps, state budget) decide eligibility per model. Anything open-ended, or a call carrying tools or streaming, is handed unchanged to the configured `fallback` chat model; `min_confidence` escalates low-confidence answers the same way. Declare `-> Decision[T]` to receive the value together with its calibrated confidence and per-question probability distribution. `visit ... by llm()` with `select=1` asks a single choice. Each served call records tokens, confidence and the distribution in telemetry under `call_kind: "systemone"`. Transport is stdlib only.
