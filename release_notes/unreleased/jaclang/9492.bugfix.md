- **Fix: `bytes(n)` and the other bytes constructors lower natively**: `bytes(n)` (n zero bytes), `bytes()` and `bytes(b)` had no native lowering, so a function calling one was demoted to Python and a program depending on it fell back to the server codespace. They now lower natively. A negative `n` raises `ValueError: negative count` for both `bytes` and `bytearray`, and `bytes(list)`/`bytearray(list)` raise `ValueError` for an element outside `range(0, 256)` instead of silently truncating it. `list(bytearray)` now returns the byte values; it used to read the narrow storage as 64-bit ints. The ownership checker no longer treats `bytes(x)`/`bytearray(x)` as moving `x`.
