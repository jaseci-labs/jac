- **Breaking: endpoint exposure follows the declaration**: Plain `def` / `walker` declarations are private (not served, not client-importable, not bridgeable across apps); `:protect` is the authenticated endpoint and `:pub` the anonymous one. The `_`-prefix, entry-import and module-pin exposure rules are gone and `[placement.pins]` is placement-only. Run `jac fix access` to migrate; see [Breaking changes](../breaking-changes.md).
- **`jac fix access`**: Rewrites previously served plain walkers and functions to `:protect` and lists `:priv` declarations that used to be served.
- **`def:protect` is endpoint placement evidence**: A protected function or walker in a server-kind app is server-anchored like `def:pub` and is never pulled into the client bundle.
