- **Fix: a generated test symbol is a per-module ordinal, not a process-global counter** (issue #8177): a test block whose name the parser had to invent -- the bare `test { ... }` form, the identifier-named `test box_holds { ... }` form the parser error-recovers, and a `test "..."` whose description holds no identifier characters -- took that name from `Test.TEST_COUNT`, a `static has` counter bumped once per `Test` node constructed anywhere in the process. Two parses of one source could therefore never agree, tree content depended on parse history, cached module trees were parse-order-unstable, and any cross-tier or cross-process tree comparison had to route around such files. The parser already owned a deterministic per-module counter for one of the two generation sites (`Parser._gen_test_idx`); `parse_test` now owns both and always hands `Test` a fully formed `Name`, so the ordinal is a function of the source alone. With the parser as the single owner, the `Test.postinit` fallback is deleted, `Test.name` narrows from `(Name | Token)` to `Name`, and `TEST_COUNT` goes with it -- including the `FieldDesc(name="TEST_COUNT")` entry the static was contributing to `Test`'s JIR node spec. The emitted format is unchanged (`_jac_gen_<n>`, symbol `test__jac_gen_<n>`), which matters because that string is the Python function name test discovery, `jac test --test_name` filtering, and the runner's reporting all see.
- **Seal parity: identifier-named and bare tests join the canary corpora**: the #8140 parse-parity corpora used string-named tests only, because the native and bytecode tiers carry independent `TEST_COUNT` statics and so disagreed on any generated name by construction. With the name derived from the parse, the seal-time harness corpus now carries both generated-name shapes and the sealed-parser parity suite gains a dedicated identifier-named case, so the seal build fails on a divergence in this shape instead of never seeing it. The `TEST_COUNT` save/restore in `test_rd_parser_validation.jac`, which existed only to undo the global, is gone.
