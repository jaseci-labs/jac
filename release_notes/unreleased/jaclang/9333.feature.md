- **Native: host-driven entry-library lane for sealed native jabs**: `jac build` now seals, alongside the standalone executable, a `jac_entry`-exporting entry library whose na->sv callbacks are lowered to host-fillable `__jac_bind_*` dispatch slots -- no unresolved Python symbols, so the library loads under `RTLD_NOW`. The sealed pair is built from a single compilation. Apps that call back into Python (`native_imports`) seal as the bound entry library alone, recorded in a `<lib>.interop.json` sidecar, and `jac run` loads them in-process (callbacks registered before deferred `__jac_shared_init`) instead of falling back to the JIT.
