- **Native: a string view returned through a union, optional or `any` result is a string of its own**: `return body` where `body` is a slice of a parameter and the function returns `str | list[int] | None`, `str | None` or `any` handed the caller a pointer to a copy the callee released on exit, so the caller read freed memory (JacPython compiled every raw string literal to garbage and could not parse its own Makefile, which failed the build). The return now materializes the view before boxing it, as tuples and index stores already do.
