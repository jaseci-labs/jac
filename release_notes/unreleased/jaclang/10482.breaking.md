- **JacPython is the only Python**: **Breaking change**: The `jac` binary, the CI kit and every build now run on JacPython; stock CPython is no longer built, bundled or downloaded. `zig build` builds the JacPython runtime on the previous build's output or on the checksum-pinned bootstrap seed in `bootstrap/python/seed.json` (`-Djacpython-host=seed|<path>`); `-Dpython`, `-Djacpython-host=stock`, the `jacpython` artifact (`jac native build|status jacpython`) and the `native:jacpython` label are gone. The standard library and the conformance suites are vendored (`bootstrap/python/src`, `jac/tests/python_conformance`), the runtime tree is `.python-build/<platform>`, and `scripts/check_python_references.sh` keeps other implementations out of the tree. JacPython still identifies as `cpython` (`sys.implementation`, SOABI, `cp314` wheel tags) so binary wheels and C extensions keep working.
