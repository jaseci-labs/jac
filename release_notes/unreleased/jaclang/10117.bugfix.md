- **Fix: native method calls no longer drop arguments**: on the native tier a builtin method could ignore some of its arguments and return a different value than Python, with no error. `s.index("/>", 5)` searched from the start of the string, `str.find` ignored its end, `str.rfind`, `str.rindex` and `str.count` ignored both bounds, `center`/`ljust`/`rjust` padded with spaces whatever fill character was given, `list.index` and `tuple.index` ignored start and stop, `a.union(b, c)` (and `intersection`, `difference`, `update` and the `*_update` forms) used only `b`, `str.encode("latin-1")` produced UTF-8, and keyword arguments such as `s.expandtabs(tabsize=2)` were dropped. These calls now honour every argument, or are refused with `E5092` so their function runs on the Python tier: the native method dispatcher now records which arguments each lowering reads and refuses a call that leaves one unread. Also fixed: `"aaa".rfind("aa")` returned 0 instead of 1, a negative width made `center`/`ljust`/`rjust` try to allocate an enormous buffer, and `tuple.index` returned -1 for a missing value instead of raising `ValueError`.
