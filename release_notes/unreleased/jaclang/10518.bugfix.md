- **`return` in a `with entry` block is now E0057 at check time**: a `return` directly inside a module-level (or archetype-level) `with entry` block passed `jac check` and failed only when the module was compiled, with `E5043 Bytecode compilation failed: 'return' outside function` on the Python backend and `SyntaxError: Illegal return statement` in the client bundle. Analysis now reports E0057 `'return' is only valid inside a function body` at the `return`, beside the existing `yield` (E0055) and `break`/`continue` (E0058) rules. Functions, methods, `impl` bodies, abilities, block lambdas and `test` bodies are unaffected.
