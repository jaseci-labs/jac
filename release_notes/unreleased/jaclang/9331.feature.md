- **`&` borrows a path through managed values, and native code stops refcounting it**: A local declared `head: &memo | None = &p.tokens[i].memo_head` is a view of a managed structure: it holds no reference, so binding and rebinding it emit no retain and no release on the native backend, and only a value that leaves the function is retained. The checker proves the path stays valid: the borrow must start at a parameter, `self`, an `own`/`imm` binding or another borrow (`E1323`), nothing may write a field the path walked while the borrow is live, by assignment (`E1321`) or by a call that may write it (`E1322`), and `&` stays read-only, so assigning through a shared borrow is `E1320` (previously only mutating method calls were caught). The JacPython parser uses it: compiling Python needs 3.3% fewer instructions.
