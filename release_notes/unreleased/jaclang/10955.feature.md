- **Jac Scale: CPU and memory requests for Prometheus, Loki and Tempo**: the three were deployed with no request, so nothing was reserved for them and they were among the first pods evicted when a node ran short of memory. `[scale.monitoring]` now takes `prometheus_cpu_request`, `prometheus_memory_request`, `loki_cpu_request`, `loki_memory_request`, `tempo_cpu_request` and `tempo_memory_request`. There are no defaults: a request is set only for a key that is set, so an app that sets none is deployed exactly as before. Requests only, no limits. Setting or changing one replaces that pod once. See [Monitoring resource requests](../../reference/plugins/jac-scale-kubernetes.md#monitoring-resource-requests).
