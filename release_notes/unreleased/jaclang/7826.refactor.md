- **Type-safety hardening for the shared invocation surface**: the dispatcher's `_validate_fields` now returns a named `ValidationOutcome` (error + coerced fields) instead of a raw `(str | None, dict)` tuple that didn't match its annotation; `InvocationRequest.fields` is `dict[str, any]` (dropping the non-idiomatic `typing.Any`); and the FastAPI adapter types its `route` parameter as the shared `RouteSpec` instead of `any`, so verb/path/param classification can't drift from the contract.
- **One canonical transport envelope**: `InvocationResult.to_body()` is now the single source of the `{ok, data | error}` body, and the native webview (`_transport_body`), sv bridge (`_transport_json`), and FastAPI sidecar (`_transport_envelope`) renderers all build on it instead of each re-assembling the same dict.
- **One canonical scalar coercion**: `coerce_scalar` lives in `invocation` and is shared by dispatcher field validation and the `http_surface` path/query binding (which previously carried a divergent copy).
- **Canonical HTTP capabilities + dispatch mode**: `HTTP_CAPABILITIES` is defined once in `http_surface` (with `desktop_config` importing it), the orphaned `scale/shared/utils._extract_path_param_names` is removed, and transport outcomes carry a `DispatchMode` enum (`SSE`/`JSON`/`ERROR`) instead of bare strings at the broker seam.
- **Coverage**: the opt-in sidecar's websocket handler (`_ws_walker`) now has an end-to-end test, and the `docs/desktop-portal-architecture.md` design doc referenced by the code is tracked.
