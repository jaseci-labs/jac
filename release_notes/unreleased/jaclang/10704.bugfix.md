- **The gateway caches every hashed client bundle as immutable**: Since 0.39.2 the gateway guessed from the file name whether a client file was content-hashed, and about a quarter of real hashes (no digit or no capital letter, like `client.CAdHr-OU.js`) were served `no-cache`. The client build now writes Vite's manifest and the gateway marks exactly the chunks listed there as immutable; other files revalidate. Builds made before this change keep the old behaviour.
