- **Fix: native bytes subscript assignment (`buf[i] = v`)**: the read path lowered via `_codegen_bytes_index`, but stores hit E5092 and demoted -- blocking `na_stdlib` POSIX floors that pack structs into `bytes` (`_termios_native._put_u32`, `select._add_entry`). NaIRGen now emits bounds-checked u8 stores through `_codegen_bytes_index_set`, mirroring the read emitter. Stores through a `bytes` literal are refused (the literal lives in `.rodata`), matching Python's immutable-bytes contract.
- **Fix: scalar `raise` causes are boxed**: `raise SystemExit(128 + signum)` -- the signal-floor exit convention -- arrived as a raw i64/f64 where the raise ABI takes `(obj ptr, i32, msg ptr)`; scalar causes now box through the `repr` leaf functions.
