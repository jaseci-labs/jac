- **Fix: a module function named like a fixed-width type is called natively**: a bare call to a function the module defines itself under a fixed-width type's name (`u16(data, at)`) or a `wrapping_*` builtin's name was lowered as the cast or wrapping operation, failing with E5092 (or silently casting, with one argument). It now calls the module's function, as the interpreter does.
