- **Fix: native imports no longer bind to another module's `glob:priv`**: A module that imported from a module with a `glob:priv` also declared that private global, so a public global of the same name imported from a third module could bind to the private one instead. The private global cannot be linked from outside its module, so the program built but crashed at startup, with a segfault or `symbol lookup error: undefined symbol`. Importers no longer declare another module's private globals, matching how private functions were already handled.
