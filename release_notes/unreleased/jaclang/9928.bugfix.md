- **Fix: native `sum` over a `bytearray` no longer adds bytes of 128 and above as negative numbers**: A bytearray is a list of `u8` underneath, and `sum` sign-extended its elements like any other narrow integer, so `sum(bytearray([1, 2, 250, 255]))` returned -4 natively and 508 in Python. Bytes and bytearray operands are now summed as unsigned bytes.
