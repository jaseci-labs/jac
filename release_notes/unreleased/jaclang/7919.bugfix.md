- **Fix: Implicitly concatenated `.py` string literals decode correctly**: A Python constant built from adjacent literals (`"a" "b"`, commonly split across lines) is ingested as a single string token spanning every literal in source, and only the outermost quotes were stripped when lowering it to a constant. The interior quotes and the source newline/indent leaked into the runtime value, silently corrupting log and error message text in any `.py` module jac compiles. Such a token is now split into its constituent literals and decoded part by part; the token's source form is unchanged, so `py2jac` still emits the folded concatenation.
