- **Performance: native cycle collection costs follow garbage, not the live graph**: Objects whose type has no trace function (vectors of floats, lists of ints) are now marked untraced the first time they are released to a nonzero count and never buffered as candidate roots. After each collection the next waits for a quarter as many candidate roots as the live objects it traced (never fewer than 1000), and the trace lookup probes the shared registry first. A game engine holding a level's worth of live objects rendered its frames 5-10x faster (Q2 base1 8.1 ms to 0.8 ms, matching the `rc` profile).
