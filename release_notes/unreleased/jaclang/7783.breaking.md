- **A dropped client-used import is now a hard error (`E5084`)**: previously, an import that placement stamped server-side was silently pruned from the client bundle even when client code used its symbols -- the build stayed green (a `W1100` warning at most, invisible under `--nowarn`) and the page threw `ReferenceError` at runtime. Client code that uses a symbol from an import resolving to no Jac module, no declared or installed npm package, and no framework package now fails the build with `E5084`, from both check-only and build-only runs. Imports whose uses are all server-side keep pruning silently.
