- **Fix: the native lane's unlowerable seams reach a diagnostic instead of a value**: Runtime attribute reflection (`getattr`, `setattr`, `hasattr`, `delattr`, `vars`, `dir`, `callable`) has no native representation -- native lowers `has` fields to fixed struct offsets and keeps no name table beside them -- but its emitters returned `None` and the codegen call path suppresses its own E5092 for builtin-kind calls, so the calls vanished: `setattr` compiled clean as a no-op, `print(hasattr(f, "x"))` printed a blank line, and beside an na_stdlib import the null reached a dereference and killed the compile with a bare segfault. The family is now compile-time vocabulary in `codeinfo` that the capability gate reads before placement, so a call in a function body demotes that callable to a native seam and one at module scope refuses the module, both naming the builtin in E5090. The coercion authority had the same shape of hole: it rebuilt elements across the specialized/jacval storage boundary for `list` only, letting `dict` and `set` fall through to a raw pointer cast, which corrupted `json.dumps` over an ordinary `dict[str, int]` (`{"k": 7, "j": 42}` rendered as `{"k": 42, "j": ""}`). That rule is now container-kind-agnostic.
