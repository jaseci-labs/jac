- **Deploys retry a transient client-build failure instead of hard-failing on the first blip**: the host-side client bundle build starts from a cold dependency install on every deploy, so a momentary registry or network failure on the build host used to fail the whole deploy immediately. The build now retries install- and network-shaped failures (and subprocess timeouts) up to three times before giving up; a genuine compile error still fails the deploy on the first attempt with the real build error.
