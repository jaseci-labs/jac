- **Compiler: bare `import` no longer crashes with an internal IndexError**: a file containing only the bare token `import` (or any import whose module path parse-recovery leaves empty) made `resolve_module` index into an empty list, surfacing as `Error checking 'x.jac': list index out of range` instead of a syntax diagnostic. Empty module targets now resolve cleanly to "unresolved" so the parser's diagnostic is what the user sees. Closes #8534.
