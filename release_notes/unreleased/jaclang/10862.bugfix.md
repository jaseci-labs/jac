- **Fix: calling a function through a `Callable` of a different signature**: natively, a function stored in a `Callable` whose argument or return types differ from its own was called with the wrong types, so a bare `Callable` holding a function returning `int` gave a wrong value, and one holding a method that takes an argument crashed. The arguments and the result are now converted, so the call returns what it returns in Python. When the argument counts differ, the function holding the value falls back to Python, which raises `TypeError` when it is called.
