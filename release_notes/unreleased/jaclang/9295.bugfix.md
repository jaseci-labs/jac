- **Fix: Builtin keyword arguments resolve by name on the ES target**: `sorted(xs, reverse=True)` no longer crashes with `key is not a function` on the client (ES) target. Builtin calls used to pass keyword-argument values to the compiled JavaScript in source order, so a value could land in the wrong parameter -- `sorted(xs, key=f, reverse=True)` and `sorted(xs, reverse=True, key=f)` could behave differently, and `pow(exp=3, base=n)` or `complex(imag=2, real=1)` swapped their arguments. Method calls on builtin types had the same bug (`xs.sort(reverse=True)` crashed and `s.split(maxsplit=1)` returned the wrong list), and `list.sort` ignored `reverse` entirely. Keyword arguments to builtins, builtin class constructors and builtin-type methods are now slotted by the signature the type checker resolved from the stubs, so no hand-maintained list is needed.
