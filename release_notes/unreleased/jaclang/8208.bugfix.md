- **Fix: keyword-argument keys are no longer rewritten by client state lowering**: A `has` field on a client function lowers reads of its name to a state cell, and that rewrite used to fire on the *key* of a keyword argument too. `Box(theme=theme)` inside a function declaring `has theme` emitted unparseable JavaScript, and `label(theme=theme, size=2)` silently passed `theme` as `undefined`. Names in an identifier slot -- a kwarg key, an attribute after a dot, parameter, import, and declaration names -- are now emitted verbatim, and an unrecognized keyword key shape raises `E5099` instead of being demoted to a trailing spread.
