- **Breaking: a local must be assigned on every path before it is read**: Reading a local that some path leaves unassigned is now error `E1006` on every backend, as in Java, C#, Swift and Rust. Python allows these reads and raises `UnboundLocalError` when the path runs; the native backend instead read a zero or a null and could crash with no output. The check follows the control-flow graph, so an assignment in every branch of an `if`/`else`, `match` (with a `case _`) or `try`/`except`, a `while True` loop left by `break`, and a walrus in the true branch of `and` all count. A loop-carried read such as `if i > 0 { use(last); }` before `last = ...` in the same body is now rejected; assign the variable before the loop. The control-flow graph itself was rebuilt around one rule for where each statement continues, which removes a spurious edge from a `try` header past its body, a false exit from `while True`, the fall-through out of an exhaustive `match`, and missing `break` edges for a loop that ends an `if` body.
