- **A type parameter used as a value is now E1163**: inside `def g[T: Exception](e: T)`, `raise T`, `return T`, `x = T`, `isinstance(e, T)` and `cast(T, v)` passed the checker, because it gives `T` and a value of type `T` the same type, then failed at runtime with `NameError: name 'T' is not defined` on the Python backend, which drops a function's type parameters. Any value use of a non-comptime type parameter is now E1163, including inside a class, where `T` is a bare `TypeVar` at runtime. Annotations, generic arguments, `as` casts and values of type `T` or `type[T]` are unchanged.
