- **`raise T` with a type parameter `T` is now E1090**: inside `def g[T: Exception](e: T)`, `raise T` and `raise ... from T` passed the checker, because it gives `T` and a value of type `T` the same type, then failed at runtime (`NameError: name 'T' is not defined` on the Python backend, a lowering error on native). Raising a bare type parameter is now E1090 and using one as a cause is E1161, both reported as "type parameter T"; `raise e` with `e: T` is still accepted.
