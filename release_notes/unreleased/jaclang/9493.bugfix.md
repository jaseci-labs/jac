- **Fix: Native set displays of tuples lower**: On the native backend a set display whose elements are tuples, such as `{(1, 2), (3, 4)}`, no longer crashes lowering with "Operands must be the same type". Its elements are boxed like `.add()` and set comprehensions box them, so the display hashes and compares tuples by value and shares its layout with `set[tuple[...]]`. The box built for the first element is also released with the set instead of leaking.
