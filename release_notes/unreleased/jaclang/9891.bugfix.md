- **Fix: `jac deploy status` no longer reads an app as crash-looping because one of its pods once restarted**: Status judged a crash loop by the container's lifetime restart count, which never goes down, so any rollout after a single past restart showed `degraded / CrashLoopBackOff`. It now counts a container only when it is not Ready and is waiting in `CrashLoopBackOff` or has terminated before, and ignores pods that are being deleted.
