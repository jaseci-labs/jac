- **Native: lock-free thread-locals and hashed `isinstance`**: Reading a thread-local slot in native code no longer takes a lock on every access, and `isinstance` against a class compiled in another module looks the class up in a hashed ancestor index instead of comparing names across a program-wide table.
- **JacPython: tokenizing, parsing and compiling Python is 1.1x to 1.25x faster**: The tokenizer scans source as code points rather than one-character strings, and string literals are decoded in runs rather than one character at a time. With the native changes above, the instruction-count gap to stock CPython narrows from 2.65x to 2.10x. Compiled output is unchanged.
