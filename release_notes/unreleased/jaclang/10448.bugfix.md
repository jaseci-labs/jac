- **JacPython: the registered modules are wired into the native object again**: the archwire migration removed the `PyInit_*` imports from `native_api.jac`, so no replaced stdlib module was reachable from the compiler entry and `build.sh`'s text grep failed on the first registry entry. `archwire.jac` now wires every binding module into `native_api.jac`, and `prepare_native.py` validates the compiled plan's public exports and the merged module's definitions instead of grepping source text; a registry entry without a reachable binding fails the build with the missing `PyInit_*` names.
- **Fix: JacPython shared statics are no longer split across modules**: writes to process-wide C-port statics (the `SOCK_CLOEXEC` probe, the netdb lookup lock, libmpdec allocator/trap hooks) now go through owner-provided setters instead of storing to wire-imported globals, and the `native:jacpython` lane passes its wiring checks.
