- **`/cl/__error__` limits each client, refuses oversized reports and logs browser-extension errors below ERROR**: one page reporting in a loop, from a runtime older than #10272 or a direct client, used to get `200` for every report while one shared per-process budget silently dropped every other user's errors. Each client now gets 20 reports a minute and then `429` with `Retry-After`. A report over 64 KiB gets `413`. A report whose stack frames all point into a browser extension is logged at INFO, tagged, instead of at ERROR. A fleet gateway applies the same per-client limit before forwarding, even with its general rate limit off; tune it with `[scale.gateway.rate_limit] client_error_rpm` (default 20, `0` turns it off).
