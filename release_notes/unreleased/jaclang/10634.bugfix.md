- **Perf: native builds cache and deduplicate unit dependencies**: Repeated native
  builds no longer re-analyze or re-lower a unit once it has been lowered in the
  session, and two identical copies of a package root with the same directory
  name now share one link unit instead of being compiled and emitted twice.
  Copies whose recorded dependency interfaces diverge are still refused, and a
  declaration-only module that produced no native interface is remembered so it
  is not re-analyzed on every build.
