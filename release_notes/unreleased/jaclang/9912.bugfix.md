- **Fix: byLLM union return types fail as conversion errors and are retried**: a typed `by` call returning a union such as `int | None` whose reply could not be parsed raised `AttributeError: 'types.UnionType' object has no attribute '__name__'` on Python 3.10–3.13 instead of `OutputConversionError`, so typed-output retries never ran; on 3.14 the error and the retry prompt named the type `Union`. Errors and retry prompts now name the return type as written (`int | None`, `list[Person]`, `Literal['low', 2]`), the `finish_tool` validation error does the same instead of reporting a generic failure, and the parse and `finish_tool` errors chain the underlying validation or JSON error as their `__cause__`.
