- **TLS to an external Postgres**: `JAC_DB_URL` (and `[scale.database] url`) now honours libpq's `sslmode` (`disable`, `allow`, `prefer`, `require`, `verify-ca`, `verify-full`) and `sslrootcert` (a CA file, or `system`), so a Jac app can use hosted Postgres such as Neon, Supabase, RDS or Cloud SQL, which refuse the plaintext connections the wire client used to make (`connection is insecure (try using sslmode=require)`). Without `sslmode` nothing changes, and a Unix socket never uses TLS. `channel_binding=require` is refused with an error rather than ignored, because the client does not do channel binding yet; remove it from a provider's connection string or use `channel_binding=prefer`.
