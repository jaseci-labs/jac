- **Client: quoted bare imports always mean the npm package**: `import from "sonner"` inside a file itself named `sonner.jac` (the bundled shadcn toast wrapper) compiled to a relative self-import (`from "./sonner.js"`), so the component rendered itself forever and the browser tab died with a silent out-of-memory crash; a same-named sibling file silently shadowed the npm package the same way. The quoted-vs-bare distinction was erased before module resolution, so the Python-style local-first lookup applied to what the language defines (see W1105) as an ESM package specifier. A quoted bare specifier now resolves as a package import only -- never to a local `.jac` file -- while quoted relative paths (`"./x.css"`) and bare dotted names keep their local-first semantics. A quoted specifier that matches no declared or installed npm package now warns `W1106` instead of silently falling back to local resolution.
