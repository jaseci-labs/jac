- **Feature: Bound-endpoint traversals and `jid()` on the native backend**: `[a ->:E:-> b]` and `[edge a ->:E:-> b]` (the hop's results that reach `b`, a node or a list of nodes) now lower natively, including with edge predicates and in the middle of a chain, instead of sending their function to the server codespace. `jid(n)` lowers natively for nodes and edges, returning a 32-character id that stays stable for the object and is never reused for another one; an Optional argument must be narrowed with `is not None` first.
