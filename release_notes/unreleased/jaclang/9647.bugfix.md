- **Fix: `jac run --serve` builds the client of a web app that never declared its kind before it reports ready**: preparation compiled the client only when the served app's `kind` field read `web-app`, and an app without an `[apps]` table carries whatever `[project] kind` says, which is empty when the project never wrote one. Such an app resolves to `web-app` everywhere else in the CLI, but it prepared with no client, printed "Server ready", answered `/healthz`, and then compiled the whole client program and ran Vite inside the first page request while every other page request queued behind it (11.5 s on a starter app, 208-303 s per request on a 479-module one). The decision now asks `JacConfig.resolved_kind`, so the client is compiled during preparation, as it already was for an app that spelled its kind out.
