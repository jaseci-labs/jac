- **Fix: py2jac no longer crashes on PEP 634 mapping star patterns**: `jac tool py2jac` on Python using `case {"k": key, **rest}:` emitted Jac with a single `*` before the rest name, and the re-parse of its own output failed with cascading "Expected literal (INT, FLOAT, or STRING) as mapping pattern key" diagnostics at wrong columns. The unparser now emits `**` for mapping rest patterns (matching what the parser, normalizer, and all three backends already expect), so mapping star patterns round-trip cleanly.
