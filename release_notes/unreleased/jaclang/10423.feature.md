- **Static assets: the `--scale` gateway, local `jac start` and the embedded gateway serve `public/` at the web root through the shared resolver**: the gateways now resolve asset URLs through the same `jaclang.server.serving.static_assets` table as `jac serve`, so `public/brand/logo.png` is reachable at `/brand/logo.png` in every run mode, and a given asset URL returns the same bytes, headers (`ETag`, 304, Range, one cache policy) and 404 everywhere. `static_mounts` are part of that table: a mount owns its URL prefix, and a request it owns but cannot find returns 404 instead of the SPA shell or the root service's answer (a mount at exactly `static` remains an additive overlay on `/static/*`). Local `jac start` now passes `client_dist_dir` and `static_mounts` from `jac.toml` to its gateway, and the admin console's assets get the shared cache policy (`no-cache` for the shell).
