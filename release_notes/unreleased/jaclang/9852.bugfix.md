- **Fix: native-tier differences from the Python tier found by running the compiler natively**: `a?.b` and `a?[i]` now yield `None` for a `None` receiver (and for an attribute only a subclass carries) instead of raising; `for (i, (a, b)) in enumerate(pairs)` binds `a` and `b` inside a function; `[x for _ in range(n)]` no longer moves `x` out of its variable on the first pass, which left every later element null; `==` between an untyped value and an object, and on a name unpacked from `enumerate`, calls the class's `__eq__` instead of comparing addresses; `a == b` through a user `__eq__` no longer releases an owned operand twice; `type(err).__name__` on a caught exception returns the class name instead of crashing; a class with more than 63 fields can be constructed through a class value; an archetype declared as `obj Name;` whose body comes from `impl Name { ... }` lowers natively instead of being demoted without a reason; a `dict` whose values are pointers is no longer reinterpreted as one whose values are boxed (for example a `dict[str, str]` literal in a conditional expression typed `dict[str, any] | None`), which is now refused with a diagnostic naming both layouts.
- **Fix: the native JSON encoder and string parser are linear**: `json.dumps` and `json.loads` in native code built strings a piece at a time and took quadratic time on long strings with many escapes.
- **Fix: endless compile-time recursion fails cleanly in the kernel**: comptime evaluation counted on Python's recursion limit to stop a constructor whose default builds another of itself; in the native kernel it overflowed the stack. Calls are now counted and the evaluation fails with the same message.
