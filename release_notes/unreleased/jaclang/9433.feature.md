- **Client: Dynamic imports for code splitting**: A client module can now be loaded on demand with `__import__("./Component")`, so the build emits it as a separate chunk that the browser fetches when it is first needed instead of including it in the single bundle it downloads up front. Passing `fromlist=["Component"]` also generates the default export that React's `lazy` expects. A path the build cannot read ahead of time, such as one held in a variable, is now reported as an error rather than quietly producing a bundle that never splits.
