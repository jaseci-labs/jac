- **`jac precompile` reuses the modules the application prepare compiled**: A deploy seal runs the prepare and then precompile, and precompile looked up the cached modules under a different key, so it compiled every module again (299 of 299 on a 299-module app, 467 s). Precompile now also looks for the entry the prepare wrote and repackages it when it carries the bytecode and interface sections. A precompile without a prepare first compiles as before.
