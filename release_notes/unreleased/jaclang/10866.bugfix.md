- **Jac Scale: KEDA autoscaling works for a deployer limited to its own namespace**: with `autoscaler_engine = "keda"`, the check for whether KEDA is installed needed cluster-wide access, so a deployer with only namespace rights got a green deploy with no autoscaler. The check now looks in the deploy namespace, and a deployer that cannot list KEDA objects there gets a deploy error naming the namespace instead of a silent skip. `KEDAAutoscaler.discover_capabilities` now takes the namespace to check as its first argument.
