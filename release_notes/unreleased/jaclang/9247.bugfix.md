- **The shared embedded Postgres cluster reclaims orphaned project databases on its own** (#9247): a project database is keyed to its directory's absolute path, so deleting or moving a project left its database behind forever, and nothing ever reclaimed it unless someone ran `jac db prune -y`; one developer machine held 10,000 databases (76 GB), almost all owned by temp directories that no longer existed. The start-time sweep now reaps them in two phases: the first cluster start to find a database's directory missing marks it, and a later start drops it once the mark is older than the grace period (24 hours by default, `JAC_DB_ORPHAN_GRACE_HOURS`) and nothing is connected to it. A directory that comes back inside the grace clears the mark, a database whose directory exists is never touched (retention stays opt-in via `[database] retention_days`), and the sweep bounds how long it spends dropping so a large backlog never stalls a start. `jac db list` shows the same state the sweep acts on (`orphaned`, `orphaned, reclaim in 21h`, `orphaned, reclaimable`, `orphaned, in use`), `jac db prune` reports it in its dry run and shares the marks with the sweep, and `jac db prune -y` still drops an orphan on the spot.
- **Test runs no longer mint permanent project databases** (#9247): every `jac run`, `jac serve` or `jac test` a test spawned, and every base a test opened in-process without marking it scratch, created a permanent project database keyed to a temp directory. The test runner now exports its own pid as `JAC_DB_SCRATCH_OWNER`, and a database opened under that owner is recorded as a scratch-kind database owned by the runner while keeping its project name, so a fixture's data still survives across the child processes of one test and per-path isolation is unchanged. The runner drops what it owns when it exits, and a runner that dies hard leaves records the next scratch reap reclaims once its pid is gone. A test that must observe a real project database opts out by unsetting `JAC_DB_SCRATCH_OWNER` in the child's environment.
