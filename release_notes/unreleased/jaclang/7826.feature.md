- **Desktop: streaming responses over the in-process dispatch path**: Walker/function generators (sync and async) now drain correctly on the desktop direct-dispatch path -- the native push channel and the local CEF OAuth broker -- not only over HTTP SSE. Generator bodies that touch `root`/memory/identity inside their yield frames now run against a live request context (snapshot captured before the invocation coroutine returns) and commit exactly once at drain time, fixing the "request context torn down before the generator drains" failure. The async step loop (`new_event_loop()` + `run_until_complete(gen.__anext__())`) is consolidated into a single transport-neutral helper in `runtimelib/streaming.jac`, shared by the HTTP, broker, and native transports.
