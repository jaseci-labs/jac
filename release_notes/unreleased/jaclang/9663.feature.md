- **`ENABLE_JS_ENGINE` and `JS_ENGINE_BIN` select js_engine instead of bun**: With `ENABLE_JS_ENGINE` set (any value except empty, `0`, `false`, `no` or `off`), `get_bun()` returns the binary named by `JS_ENGINE_BIN` (or `js_engine` on PATH) before any bun lookup, and fails naming the variable when neither resolves. Every bun caller is covered: client builds and the dev server, `jac install --npm`, `jac x`, the cl test runner, sealing, the React Native tooling and the exported-source build. With the switch unset, resolution is unchanged (`JAC_BUN`, bundled copy, PATH).
