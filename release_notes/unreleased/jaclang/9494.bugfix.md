- **Fix: Native str predicates are bools**: On the native backend `isdigit`, `isalpha`, `isalnum`, `isspace`, `isupper`, `islower`, `istitle`, `isdecimal`, `isnumeric`, `isascii`, `isidentifier`, `isprintable`, `startswith` and `endswith` now return a bool instead of a 0/1 integer, so `print("12".isdigit())`, `str()`, `repr()` and f-strings render `True`/`False` rather than `1`/`0`.
