- **Performance: small native objects reuse freed blocks**: while a program is single-threaded, objects of 48 to 128 bytes (header included) are now recycled through per-size-class free lists instead of going through `malloc` and `free` each time. Once a thread starts, allocation goes back to `malloc` and `free`, and debug builds don't pool. Allocating and dropping an object each step runs 40% fewer instructions (0.36 s instead of 0.92 s for 50 M objects), and binary-trees under `rc` 26% fewer (1.42 s instead of 2.00 s).
