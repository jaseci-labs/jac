- **Fix: a stale LLVM shim no longer crashes explicitly native code**: after a change to `jac/native`, `build.zig` or the LLVM pin, a web app with native code crashed loading its entry module, because the pass pipeline judged native lowering available from imports alone, and a native request settled that verdict while its codegen schedule was still loading, where the shim was never consulted. Native lowering now takes its availability from the shim artifact, decided before the schedule loads: a blocked module reports E5092 naming the stale shim, and `jac native build llvm-shim` repairs it.
