- **Fix: native unit compilation no longer silently falls back to the server implementation**: five compiler functions (`interop_manifest_of`, `literal_from_json`, `_emit_intrinsic_list_data`, `_direct_c_entry`, `is_secret_file`) used constructs that forced them to demote to the Python-only server codespace when jaclang itself is compiled natively, producing mixed native/server execution. They now lower on the native lane, so units compiled under `native_require` stay fully native.
