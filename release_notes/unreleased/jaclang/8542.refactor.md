- **Native backend consumes the core analysis as its single source of type truth**: the LLVM backend no longer keeps a private type model. Its guarded `type_system` imports and their silent `i64` fallbacks are gone, the facts it used to re-derive from mangle strings, LLVM value shapes, annotation syntax and name-keyed registries now come from the checker's stamped types, the scheduled layout pass and the rc-facts pass, and the analyses it ran privately (argument binding, TypeVar solving, flow narrowing, dunder resolution, closure escape) are computed once upstream. Fixes #8539.
