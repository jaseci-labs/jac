- **Fix: a native variable is no longer read or called as another module's function of the same name**: Lowering a module declares every public function of the modules it imports from under its bare name, imported by name or not, and name lookups consulted that table ahead of the module's own variables. An entry variable or `glob` named like such a function was read as the function's address (`burst = Thing(); burst.value` returned garbage), and a call through any variable holding a callable, a local included, called the other module's function, all without a diagnostic. Reads and calls now follow the symbol the name resolved to, so a variable the module binds shadows a function it never imported.
