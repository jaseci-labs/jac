- **Breaking: JacPython drops remote debugging, perf trampolines and the `getaddrinfo` fallbacks, and builds from `main` again.** JacPython is configured without remote debugging (`sys.remote_exec()` and `_remote_debugging.RemoteUnwinder` report it was not compiled in; `python -m asyncio` still starts, since asyncio imports the module) and without perf trampolines (`-X perf` and `sys.activate_stack_trampoline()` report them unavailable). Its table of built-in modules is Jac C data, which restores the links #10153 removed. Tuples, lists, sets, floats, dicts and `OrderedDict`, descriptors, built-in and Python function objects, weak references, module objects, the built-in exceptions and the `typing` TypeVar family, `memoryview`, `int`, `bytes`, `bytearray`, `str` and the core object, call and abstract protocols (`Objects/object.c`, `call.c`, `abstract.c`) are now native Jac (`Objects/tupleobject.c`, `listobject.c`, `setobject.c`, `floatobject.c`, `dictobject.c`, `odictobject.c`, `descrobject.c`, `methodobject.c`, `funcobject.c`, `weakrefobject.c`, `moduleobject.c`, `typevarobject.c`, `exceptions.c`, `memoryobject.c`, `longobject.c`, `bytes_methods.c`, `bytesobject.c`, `bytearrayobject.c`, `unicodeobject.c`, `unicodectype.c`, `object.c`, `call.c` and `abstract.c` are gone), and the C API checks, `binascii`, `math.comb`/`math.perm`, `json`, `struct` and the compiler's AST walk follow CPython's fast paths. Native code built with the new `native_tls` and `native_sjlj` options reads thread-local slots as TLS and arms exception frames with LLVM's builtin setjmp. An `isinstance` that walks a class's ancestry remembers the last vtable it missed. A function's write to a wired C global now counts as a use of the wire (E1146). In the Jac C API declarations, `PyDict_SetItemString`, `PyDict_GetItemStringRef`, `PyDict_PopString`, `PyModule_New` and the `PyUnicode*Error` reason functions take `ptr[u8]`, as in C; pass `ptr[u8]("...")`, or use `capi.dict_set_text`/`dict_get_text` for a `str` key. Native functions that return a tuple of C scalars return it by value instead of allocating it, and `&mut x` passed through a C declaration to a symbol a Jac module defines now lends x's address.
