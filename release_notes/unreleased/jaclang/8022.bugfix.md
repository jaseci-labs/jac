- **CLI: jac-shadcn scaffolds no longer depend on the npm shadcn package**: `jac create --use jac-shadcn` failed on machines without node because the pinned npm `shadcn` package pulls in msw, whose postinstall runs node. The css the package provided is now vendored into the generated `global.css`, the pin is removed from the scaffold and retheme paths, and `jac install --shadcn` stops re-adding it.
