- **Fix: `jac fmt` fails when it cannot write a file**: a module file or discovered impl annex that could not be written (read-only, permission denied) printed an error but still exited 0, and a directory run counted it as formatted and changed, so `jac fmt . && <next command>` carried on after the failure. A write failure now lists the module under FAILURES and exits 1, in serial and parallel runs; the summary and `cache_stats["changed"]` count a module only once all of its writes succeeded, so one whose annex failed counts as failed, not changed. A run where every write succeeds still exits 0.
