- **Fix: `jac browse open localhost:8000` and `jac browse press Enter`**: `open` and `navigate` took a bare `host:port` for a URL with the scheme `host`, so `jac browse open localhost:8000` landed on `about:blank`; a URL without `scheme://` now gets a scheme added, `http://` for localhost and loopback addresses and `https://` otherwise. `press Enter` sent a key event without text, so it did not submit a form from a text input or break a line in a textarea; Enter now carries a carriage return, alone or with Shift.
