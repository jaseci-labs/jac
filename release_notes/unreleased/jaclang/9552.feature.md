- **Feature: JacPython calls the CPython C API by name, and fifteen more native modules**: Native JacPython modules call the CPython C API through generated, typed declarations (`ptr[PyObject]` handles), argument parsing is generated from CPython's Argument Clinic input, and platform constants are generated from the target's headers. `_opcode`, `_stat`, `_types`, `_typing`, `_suggestions`, `_sysconfig`, `_weakref`, `_tracemalloc`, `pwd`, `grp`, `errno`, `syslog`, `resource`, `zlib` and `_bz2` are now native Jac, and the JacPython object again gets whole-program optimization.
