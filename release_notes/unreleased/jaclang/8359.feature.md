- **Feature: the compile driver routes through the native prefix by default, and every fallback names itself**: The compiler's parse step now goes through a routing seam that runs the fused native prefix when the predicate admits a module and the staged pass loop otherwise; the driver trims the schedule by whatever the crossing executed. There is no opt-in flag -- the predicate and the fallback are the control. Every decline is counted and named against a registry of eleven clauses, surfaced as a one-line compile summary, as per-module detail under `JAC_PREFIX_REPORT=1`, and as a `jac check --compile-stats` table reporting how much of each module's schedule ran natively. `JAC_PREFIX_STRICT=1` turns any fallback into a hard error (off by default; the seed of the zero-bytecode invariant), and `JAC_PREFIX=off` forces the staged route. A red-first parity suite compiles the corpus both ways and compares unparse-exact trees, field-by-field tree values, the diagnostic stream, and field-by-field downstream code objects, with an injected-divergence fixture proving the comparators fail when the routes disagree.
