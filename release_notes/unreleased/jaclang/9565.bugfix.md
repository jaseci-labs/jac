- **Fix: native `list[tuple[T, ...]]` elements**: Tuple displays stored into a list of variadic tuples (list displays, `append`, `insert`, `xs[i] = ...`) went in as fixed-arity tuple boxes while reads viewed them as the `list[T]` sequence a variadic tuple lowers to, so `xs[1][1]` crashed natively and sorting compared garbage. Stores now materialize the sequence, and `sorted()`/`list.sort()` order such lists lexicographically.
