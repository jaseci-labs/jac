- **Breaking: jac ships a prebuilt CPython 3.14, runs the bytecode compiler, and uses bun by default**: the `jac` binary now bundles a pinned python-build-standalone CPython 3.14 instead of JacPython, a release no longer seals the native compiler kernel, and JavaScript tooling runs on the bundled bun. `jac build --native` is unchanged. The old paths stay as opt-ins: `zig build -Djacpython` builds and ships JacPython, `JAC_SEAL_KERNEL=1` (or `jac native build kernel`) adds the kernel, and `JAC_JS_ENGINE=1` uses a js_engine built with `jac native build js-engine`. `jac native status` no longer warns that the kernel runs on its floor.
