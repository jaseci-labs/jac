- **Feature: GraphMend predicated data-dependent control flow (`[Where]`)**: GraphMend now predicates data-dependent `if`/`else` branches under `torch.compile` entry points (`jac run --graphmend`). Branches producing the same output are rewritten into a single `torch.where` selection, or `torch.cond` when a branch value contains a call, so both paths stay inside one FX graph instead of forcing a TorchDynamo graph break. Multi-statement branches sharing a trailing call hoist their setup statements only when each is provably effect-neutral on the untaken path; a validation guard nested in a predicated branch composes with trap lowering, its graph-native assert re-gated on the branch predicate. Illegal shapes are left untouched.
