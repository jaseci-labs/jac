- **Native: an experimental MIR backend, opt in with `JAC_NATIVE_MIR=1`**: native code can now be lowered through a typed mid-level IR that either gives each function a native form or refuses it with a reason, and links against a native runtime written in Jac. The current backend stays the default; set `JAC_NATIVE_MIR=1` to try MIR on `jac build --native` and the native tests. It replaces the current backend once it covers the native test suite (#10471).
