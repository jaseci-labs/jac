- **Fix: byLLM no longer returns an empty reply as the answer, or sends blank text back to the model**: in a call with tools, a reply with no text and no tool call used to come back as `""`. byLLM now asks the model once to continue, and raises the new `EmptyReplyError` if the next reply is empty too. Blank assistant text is no longer sent on later requests or written back to `conversation=`: an empty reply is left out, and a reply that only calls tools keeps `content` as `None`. Before, litellm turned that blank text into `[System: Empty message content sanitised to satisfy protocol]` for Anthropic models, and the model repeated it as its answer.
