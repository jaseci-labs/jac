- **Fix: jac-scale no longer deploys to the pod's own cluster when the configured one fails to load**: with `kube_context` or `kubeconfig` set, a context missing from the kubeconfig or a missing kubeconfig file used to fall back to the in-cluster ServiceAccount, so deploy, status and destroy run from a pod acted on the pod's own cluster, and on a laptop the error only said to start minikube. Now that is an error naming the configured values and the kubeconfig's own message. The in-cluster fallback still applies when neither is set.
