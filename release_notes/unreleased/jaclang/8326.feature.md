- **Native membership over an erased operand is a checker error, not a silent demotion**: every container answers `in` from its own layout, so an operand that reaches the comparison element-erased has nothing to answer from -- and the native emitter's interim guard responded by demoting the whole function to Python and writing the reason to a debug stream, which is telemetry rather than an answer. `E1124` now refuses the shape at check time and names the remedy, gated to the native lane by the same `_in_native_context()` + `_is_strict_site()` pair `E1121` uses for un-narrowed optionals; server-lane code is untouched, since CPython dispatches `__contains__` at runtime and needs no static element type. There is no dynamic-dispatch tier beneath it and none is coming. What it catches is exactly an operand with no static type -- `None`, `Unknown`, or `any` -- and `is_any_type()` alone misses the last of these, because the `any` keyword resolves to a `ClassType` for `typing.Any` once the prefetch is warm and only `is_any_instance()` sees through that fork. A bare `list`/`dict`/`set` operand is erased too but is deliberately left alone: it *has* a static type, merely unparameterized, and the fix belongs at the annotation, where one refusal covers every use, rather than at each membership test. An earlier cut did refuse it and the seal caught the cost -- `NON_ESCAPED_KEYWORDS` and `_proto_checks_in_progress` are both bare `set`, so the compiler refused to compile itself; a test now pins that boundary with the reason. The emitter's both-operands-`i8*` guard stays as defense in depth. One residual is recorded rather than closed: in `for v in t.values() { if x in v }` over a `dict[str, list[Tag]]`, the checker types `v` as `list[Tag]` -- fully parameterized, nothing to annotate -- and the emitter still erases it, because the erasure is introduced by the lowering of `t.values()` rather than by a missing annotation. `E1124` deliberately stays silent there, a test pins that silence with its reason, and the demotion remains the honest answer until the lowering carries its element layout.
