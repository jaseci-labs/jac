- **Breaking: `jac run` never builds** (#10335): `jac run` only executes or serves. A kind with no program to run (`native-lib`, `py-package`, `js-package`) is refused with the `jac build` command that makes it; `native-binary` executes in-process like `cli-native`; and a `mobile` app serves the Expo dev server with a QR code for Expo Go (`--platform android|ios` opens Expo Go on an emulator or simulator, the new `--tunnel` reaches a phone off the LAN, with the API riding the same tunnel). Installable mobile builds come from `jac build --platform android|ios`. Also fixes `jac build` on a `native-lib` app producing an executable instead of a shared library.
