- **Fix: byLLM `timeout` bounds the whole `by llm()` call**: `[byllm.call_params] timeout` (and `Model(timeout=...)`, `by llm(timeout=...)`) used to limit each HTTP request, so retries, every turn of a tool loop, and the provider client's own hidden retries each started a fresh budget. A 600s timeout could hold a call for 30 minutes or more. It is now one deadline for the whole call: each request gets what is left, a transient failure is retried only if its backoff fits, streamed answers are checked on every chunk, and when it runs out the call raises `LLMTimeout`. LiteLLM streaming calls and the `proxy` transport's OpenAI client no longer retry underneath byLLM; the `proxy` transport's dropped connections and 5xx replies are now retried by byLLM instead.
