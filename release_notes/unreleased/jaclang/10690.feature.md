- **`jac test` can start the heaviest test files first and split slow ones across workers**: with `JAC_TEST_TIMINGS=<file>`, `jac test` records each test file's wall time there and, on later runs, dispatches the heaviest files first, with files it has no record of before all of them. With `JAC_TEST_SPLIT_SECONDS=N` as well, a file recorded above N seconds runs as up to one part per worker, each part taking every Nth of the file's tests. Both are off unless set.
