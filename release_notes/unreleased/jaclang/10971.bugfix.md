- **Fix: a quoted import of a Jac module compiles like the dotted one**: `import from "..ui.plain" { Plain }` (or `"./plain.jac"`, or a hyphenated module name) left `Plain` untyped, so the client bundle called it without `new` and inlined a copy without its methods, throwing a `TypeError` at runtime. It now compiles exactly like `import from ..ui.plain { Plain }`.
