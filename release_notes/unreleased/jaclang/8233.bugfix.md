- A stdlib shim whose parameter is narrower than the typeshed signature the checker reads no longer answers wrong. `Path("a") / Path("b")` compiled clean and printed heap bytes: the bundled `pathlib` declared `str` where CPython takes a path-like operand, and under opaque pointers coercing the object pointer to the declared `i8*` was a no-op, so the shim ran `str` methods over a `Path`. `/` now takes a `str` or a `Path` on either side, `__truediv__` and `__rtruediv__` alike. Underneath it, native dunder dispatch compares the operand against the dunder's declared operand type first, and refuses rather than reinterpreting the operand's bits -- the reflected method still gets its turn, and only when both sides refuse does the compile fail, naming the declared type and the operand type. The gate stays silent unless it can resolve both sides confidently, so an unknown or gradual type never trips it.
- `TypeGuard` and `TypeIs` are ambient, so a predicate can be annotated without importing from `typing`. Both had been unreachable twice over: the ambient installer read the typing module's own scope dict, which does not descend into the live branch of the `if sys.version_info >= (...)` guard typeshed declares them under, so the names were dropped in silence -- and had they landed, the native lane could not lower either form in return position. The installer now resolves through `lookup_symtab`, which walks the guard against the CPython the `jac` binary bundles, and the native lane lowers both forms to the bool both PEPs say a predicate returns. Every other version-guarded name in typeshed was unreachable for the same reason, and is now reachable too.
