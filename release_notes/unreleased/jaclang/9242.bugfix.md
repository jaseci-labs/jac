- **Fix: a bare Python import is no longer placed client because a same-named package sits under `.jac/client/node_modules`**: `import from dotenv { load_dotenv }` (or any stdlib or sibling `.py` name) was recorded as npm evidence whenever a transitive npm package of that name happened to be installed, which seeded the import client and pulled every element that used it, `walker:pub` endpoints included, into the bundle. Bare imports now classify in one fixed order: a local Jac module, then a name declared in `[dependencies.npm]` or owned by the client framework, then a Python module the importing file can import, and only then an installed-but-undeclared npm package. `jac check --placements` names the rule that fired (for example `PY: python import (python module shadows the undeclared npm package)` or `NPM: npm dependency ([dependencies.npm])`).
