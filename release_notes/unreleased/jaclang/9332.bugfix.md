- **Fix: native builds no longer crash inside shipped-binary (bootstrap) builds**: `jac build --native` under the shipped binary failed with `NameError: name '_compile_native_module' is not defined` -- the compile-once/link-per-artifact helpers were declared with `impl` but had no matching decl, so the bootstrap transpilation never emitted them as module globals (dev-source builds bound them, hiding the breakage). Both helpers are now defined with `def`.
- **Change: native backend seam/demotion warnings print to raw stderr**: backend-compiler warnings (native seam, demotion) moved from the styled CLI console to `sys.stderr` so the compiler backend no longer imports the CLI layer. Message text is unchanged.
