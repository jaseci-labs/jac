- **Fix: native macOS binaries name their internal functions**: The Mach-O linker wrote only exported and imported symbols, so profilers, debuggers and crash reports attributed every internal function's frames (private helpers, the refcount runtime, trace functions) to the nearest exported symbol. Executables and dylibs now carry each linked object's local code symbols ahead of the external ones, with `LC_DYSYMTAB` and the indirect symbol table indexed past them.
