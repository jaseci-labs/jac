- **Fix: jac-scale no longer swaps pods off the official image when Docker Hub cannot be reached**: with `python_image` unset, any failure to reach Docker Hub (DNS, a blocked proxy, TLS, a timeout, a 429) was treated as an unpublished image, so pods quietly booted on `python:3.12-slim`, and on the experimental channel they ran the `dev` toolchain instead of the PR's build. Now only a 404 from Docker Hub counts as unpublished: pods fall back to `python:3.12-slim` with a warning, and an experimental deploy stops and names the Experimental jac image workflow. Any other failure keeps the official image, unpinned, with a warning. The check runs before any database is provisioned.
