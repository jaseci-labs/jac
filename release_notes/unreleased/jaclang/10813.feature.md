- **The admin Logs page reads pod logs when Loki is not deployed**: with `[scale.gateway.logs] enabled = false`, the Logs page and the trace view answered "Log backend unavailable". They now read recent lines from the app's gateway and service pods through the Kubernetes API, with the same service, level, search and trace filters. This needs `[scale.kubernetes] ops_console = true` and the `kubernetes` client in the app's dependencies; otherwise the page says which one is missing. It also names any container whose older lines it could not read.
