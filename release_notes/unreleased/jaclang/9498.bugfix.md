- **Fix: `math.sqrt`, `math.sin` and other libm-named `math` functions stay native across modules**: `math`'s exported native layout left out every function sharing a name with a libm extern declared by `_math_native` (`sqrt`, `sin`, `cos`, `tan`, `atan2`, `exp`, `log`, `hypot`, ...). In a multi-module native build, any function calling one of them was demoted to Python. The layout now keeps a module's own definitions and drops only real clib externs.
