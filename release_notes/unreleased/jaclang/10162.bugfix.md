- **Fix: a native build session stops the garbage collector from rescanning what it keeps**: a native build keeps every analyzed module, its types and its interface until the session ends, and each full collection of CPython's cyclic garbage collector walked all of it again, at a cost that grew with the heap (single collections of 10-14 s on the kernel closure). At each unit boundary the session now collects only what is new since the last boundary, so a unit's dropped products are still reclaimed, and freezes the survivors so later collections skip them. The collector is handed back exactly as the session found it. `JAC_GC_NO_COMPILE_BOOST` turns this off like the other compile-time collector tuning.
