- **Scale: monitoring no longer needs a manual namespace relabel**: the deploy stamped `pod-security.kubernetes.io/enforce=baseline` on the namespace it created, then refused to upgrade any namespace that already carried an enforce label, so the privileged level that node-exporter and Alloy need could never be applied and the hostPath DaemonSets were rejected by PodSecurity admission. jac-scale now records which enforce level it set and upgrades its own, while a level an operator set is still left alone with a warning.
