- **Serving is Jac-native: FastAPI, Starlette, uvicorn, pydantic, fastapi-sso, aiohttp, pyjwt, bcrypt, and python-multipart are gone from the runtime**: `jaclang.runtimelib.serving` is the single serving stack for both the dependency-free core path and jac-scale -- an asyncio HTTP/1.1 server (keep-alive, chunked transfer, streaming, graceful drain, one port-retry implementation), a router over the `JEndPoint` IR with path params and deterministic ordering, Jac-type-driven parameter binding and coercion that replaces the pydantic `create_model` + `exec()` signature-synthesis bridge (the whole `scale/jserver` package is deleted), a multipart parser, one SSE emit/parse implementation, an RFC 6455 WebSocket codec shared by server and client, CORS/custom-header middleware, an OpenAPI 3.1 emitter driven by the endpoint IR (Swagger UI at `/docs` on both paths), and stdlib crypto: HS256 JWTs and scrypt password hashing (bcrypt hashes from earlier releases no longer verify -- users must reset credentials; bcrypt survives only for htpasswd generation under `deploy.k8s`). The two previously drifted server implementations (stdlib `ThreadingHTTPServer` vs FastAPI) are one engine behind `JacAPIServer.build_app`.
- **sv-to-sv RPC, the microservice/embedded gateways, and SSO run on a Jac-native HTTP/WS client**: httpx and aiohttp leave the serving closure (httpx remains only under the `llm` capability for byLLM). RPC keeps its retry/circuit-breaker/SSE semantics on the native sync facades; gateway HTTP and WebSocket forwarding proxy through the native async client; Google/GitHub/Apple SSO implement the OAuth2 authorization-code flow directly (Apple via `form_post` and the configured client-secret JWT) and Firebase keeps firebase-admin verification. Request models (`auth_models`, `scheduler_models`, webhook) are plain Jac objects with `from_dict` validation. Tests dispatch through an in-process `ServingTestClient` (with a real-socket sync WebSocket bridge), retiring starlette's `TestClient` -- including as the desktop in-process transport. The `serve` capability now declares only `sqlalchemy`, `python-dotenv`, and `requests`; `upload` needs no third-party dependency. `jac eject` still emits a standalone FastAPI project as the exit ramp off Jac, with refreshed pins.
