- **Lint: string statements inside a body are flagged and stripped**: a string written as a statement inside a function, method or block body does nothing, but only the first one in a body warned (`W0060`) and `strip-docstrings` (`W3051`) never removed any. `W0060` now flags every one, and under `strip-docstrings` (on with `select = ["all"]`), `jac fmt --lintfix` removes them. F-strings, strings inside a JSX `{...}` slot (rendered content) and a lambda's lone statement (its return value) are left alone. Docstrings go before the declaration; a note inside a body is a `#` comment.
