- **The compiler reads a syntax tree node's parent without building a list**: `UniNode.parent` ran a full graph hop and copied the node's incoming edges into a new list on every read, and `decl_parent` read it twice. The parent is now read straight from the node's edge index through a new `last_in0` helper that falls back to the hop whenever the fast read does not apply, and `decl_parent` reads it once. On a 299-module app the cold prepare drops from 1,171 s to 1,122 s and a one-file edit from 898 s to 844 s, with no change in memory.
