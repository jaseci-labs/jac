- **Fix: a `None` glob no longer crashes native code that imports its module**: a module with `glob NN = None;` (or `static has X: None = None;`) made every native importer of it fail with an ICE, and the module itself reported a false E5026 symbol collision. A glob's native type is now decided in one place for its module and each importer, so both always agree, and a `None` value is stored the way a `None` literal lowers.
