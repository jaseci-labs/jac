- **Fix: opening the admin console no longer stalls the server**: the first request to an admin sub-path built the console inside the request, on the event loop, so every other request waited for the build (up to 300 s); on Kubernetes that was the gateway, so all traffic stalled and the readiness probe could fail. The console now builds once in the background into a new `admin` cache bucket, keyed by the UI sources and the compiler, while the request gets a 503 with `Retry-After` and a page that reloads itself. Builds are shared across requests and worker processes, appear only once complete, back off after a failure, and work from a read-only install such as the official Docker image. A console left under `.jac/admin` by the old in-request build is no longer trusted; only one a deploy staged is.
