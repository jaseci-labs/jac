- **Fix: `jac scale deploy` ships the whole workspace**: a workspace whose services live beside the served app rather than under it refused to deploy, reporting that a service entry resolved outside the deployed tree and telling you to deploy from the project root even when you already were. The deploy now ships the project root that declares `[apps]`, so no placeholder entry file at the root is needed, and deploy, destroy and status all read the project root's `.env` so they cannot resolve different settings from the same entry file.
