- **Native units compile in owned compiler sessions**: The link plan compiles each stale unit in a compiler session it owns instead of one shared native build session, so one unit's syntax and type state never reach the next. aarch64 links take the LSE outline-atomics helpers from the vendored compiler-rt archive (`libclang_rt.atomics.a`) instead of generated inline assembly, and the floor and static-runtime lookups (`static_link.jac`) no longer have forwarding copies in `linker_common`.

- **JIT foreign-library binding is explicit**: Each C import binds to its declared shared library within its execution engine. Missing libraries or symbols produce compilation errors before an engine is exposed; unrelated process symbols no longer satisfy a missing import.
