- **Breaking: stable graph schema identity and explicit shared persistence domains**: Prepared applications no longer persist private Python module namespaces derived from entry paths. Types use a stable project namespace, app or declared persistence domain, and logical declaration name, so relocating an application does not rename its stored schema. Declare `[persistence.domains.<name>]` with `owner`, `apps` and exact `modules` when multiple apps intentionally share persistent types; undeclared consumers receive E5113. Reads resolve to the consuming app's local class, while globals remain app-local. Foreign references are preserved without quarantine or deployment flags, and missing local schemas fail explicitly. Rebuild existing artifacts and explicitly migrate legacy type names; path-prefix stripping and implicit cross-app schema sharing are not supported.
