- **Jac packages**: `jac install org/name` resolves Jac libraries with a PubGrub solver (one version per package, conflicts explained step by step), pins them in a committed `jac.lock` with content hashes, fetches them into a machine-wide store and mounts them under `.jac/packages`, so `import from org.name { ... }` works. Path (`--path`) and git (`--git`, `--rev`) dependencies, `jac install --frozen` for CI, `jac update [org/name]`, and a `jac.lock` record of the exact Python distributions pip installed. A package's own PyPI and npm requirements install with it. See the [Packages reference](../../reference/packages.md).
- **Compiled dependencies are shared across projects**: a module of a dependency package compiles under its own `jac.toml` and caches machine-wide, keyed only by what can change its code (target, memory model, codespace defaults), so a second project using the same package version reuses the compile.
- **Fused binaries verify their app image**: a binary built with `jac build --as binary` checks its embedded app against the recorded sha256 before running it.
