- **Nested lookups now work on `dict`, `list` and `tuple` written without type arguments**: reading one level out of a bare `dict` was fine, but reading through that value again was not, so `data["name"]` passed while `data["main"]["temp"]` failed with an `<Unknown>` type error. The same happened when calling a method on the value, using it in arithmetic, or looping over it, which made ordinary JSON handling awkward and pushed you toward marking everything as `any`. A bare `dict` now behaves the same as `dict[str, any]`, which is what the "defaulting to `dict[any]`" warning already said it meant.
