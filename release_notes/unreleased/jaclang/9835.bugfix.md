- **Fix: warm `jac run` no longer re-parses dependency sources to re-check cache freshness**: When restoring a prepared application, the compiler had already re-verified every input's content and annex digests, yet the per-module native link-plan rebuild re-derived each compile-time dependency digest anyway; for definition-level rows it meant parsing the dependency's sources again on every launch. Restore now skips rows the prepared-application record already validated, while rows pointing at files outside that set are still checked.
