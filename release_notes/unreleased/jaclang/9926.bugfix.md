- **Fix: an assert keeps earlier narrowing inside its own condition**: The type checker applied an assert's predicate to the operands of that same assert's condition, as if it had already passed. Working that predicate out for a condition such as `assert chart.revision == 0 and not chart.connected(1, 2)` typed `chart.connected` while `chart` was still being narrowed, against its declared `Chart | None`, and reported E1099 on a variable an earlier `assert chart is not None` had already narrowed. An assert now narrows only the code after it; its operands see what was known before it plus the short-circuit edges between them.
