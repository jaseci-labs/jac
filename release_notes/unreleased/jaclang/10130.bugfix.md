- **Fix: `jac fix placement` no longer turns a client component's `sv import` into a service app**: every top-level `sv import from X` became an `[apps.X] kind = "service"` table, so a 0.34 client shell that reached its own server module with `sv import from .store { ... }` (the layout `jac-cl-organization` recommended) was migrated into a separate service app whose calls then failed. Each `sv import` is now classified by its inferred placement: a client-placed one only loses its prefix, and a server-placed one still declares the service app, with the output naming the file and line of the import. `jac.toml` is left untouched when no service app is added.
