- **Breaking: gateway `/static/*` serves only the client dist and `/static/assets/*`, by exact path**: the `--scale` and local `jac start` gateways used to try a ladder of project directories under `/static/` (`assets`, `dist`, `public`, `.jac/client/dist`, `.jac/client/compiled`) and fall back to a basename match, so `/static/brand/logo.png` could return `public/brand/logo.png` and `/static/x/logo.png` could return `assets/logo.png`. `/static/<path>` now resolves only from the client dist, and project assets only at `/static/assets/<path>`; files under `public/` are served at the web root instead. A URL that only resolved through a removed fallback or a basename match now returns 404.
- **Breaking: a miss under a `static_mounts` prefix returns 404 through the gateway**: a request whose prefix a mount owns, but whose file is not in the mount, used to fall through to the SPA shell or be forwarded to the root service. It now returns 404 for `GET` and `HEAD`, including at the bare prefix itself (a mount at `downloads.json` owns `/downloads.json` even when `public/downloads.json` exists), so a mount never serves another root's file at its path.
