- **Fix: `jac scale destroy --component application` keeps the database and monitoring Services**: The sweep that removes the application's Services, PodDisruptionBudgets and Ingresses selected everything labelled `managed=jac-scale`, so it also deleted the postgres, Prometheus, Grafana, Loki, Tempo and kube-state-metrics Services. Their pods kept running but could no longer be reached by name, for example at `{app}-postgres-service`, until the next deploy recreated the Service. Services and PodDisruptionBudgets now carry `jac-scale.role` like Deployments do, and those sweeps select on it, so only the application's own objects are removed. Services and PodDisruptionBudgets created before this change have no role label, so destroy removes them by name from the app labels of the fleet Deployments, which always carried the role. Ingresses created before this change are skipped by destroy until the next deploy relabels them.
