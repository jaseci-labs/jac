- **Fix: a function with no return annotation returns None under native**: native used to compile a function or method written without `-> T` to return the integer `0`, so `v = f(); v is None` was False and `if result is None` guards never fired. Method calls also turned a `-> None` result into `0`. These callables now return None like on the server: `f();`, `print(f())`, `return f()`, a conditional such as `f() if c else g();`, and storing the result in a declared variable all stay native, and binding it to a new variable moves only that function to the server, where it gets `None`. Calls across the native/Python bridge also pass None correctly: a void native function called from Python no longer returns a garbage integer, and a Python callback with no return annotation no longer raises a ctypes `TypeError`.
