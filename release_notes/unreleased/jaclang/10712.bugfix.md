- **Type checker: comptime values survive id reuse, and scope lookups are linear**: a node whose comptime evaluation failed is now remembered by identity, not by its id alone, and released with the other check caches, so in the language server or a long session a later node that reuses the id no longer loses its comptime value. Member lookup through enclosing scopes scans each nested scope once per lookup instead of once per ancestor, and the names a module's imports bind are computed once per module.
