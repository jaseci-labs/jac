- **Fix: bad requests get the right status, and unhandled errors stay in the log**: Spawning a walker on a malformed node id now answers 400 `INVALID_NODE_ID` instead of 500, with no traceback in the log, and a node that doesn't exist or can't be read answers 404 `NOT_FOUND`. A non-ASCII bearer token answers 401 instead of 500 when `JAC_BRIDGE_TOKEN` is set. The server's last-resort handler now answers `{"error": "Internal Server Error"}` instead of sending the exception's type and text to the caller; the traceback is still logged. The exception message a walker or function sends to its caller is unchanged.
