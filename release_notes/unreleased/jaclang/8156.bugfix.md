- **Native: a field read through a generic archetype's type-erased slot demoted the whole callable** (issue #8149): a generic archetype is laid out once, not once per instantiation, so a `has` slot typed by the class's type parameter lowers to a bare pointer with no class attached -- and #8052 already made the layout registry emit those erased definitions so declarations, constructors and rc hooks stop leaving undefined symbols at link time. The other half was missing: the backend keys its struct registry by class name (`SubTag`) but tested it against the checker's mangled type key, which carries the arguments (`SubTag[Token]`, or `NoneType|SubTag[Token]` through an option). `_struct_name_of` therefore missed on every parameterized annotation, and the fallback that infers the class from the LLVM value cannot rescue a `JacOpt` aggregate, so `self.access.tag.name` resolved to no receiver layout and the enclosing accessor shipped as an `abort()` stub. A local built by a bare `SubTag(...)` read fine by accident -- its LLVM value *is* a `%SubTag*` -- which is why this only ever surfaced through an annotated slot. A parameterized mangled key now resolves to the erased archetype it was laid out as (splitting a union key at bracket depth zero, so `Cell[A|B]` is one member and not two), which is sound precisely because the erasure is: one struct serves every type argument, and the slot is a pointer regardless of it. The type argument the site already carries does the rest, since the checker evaluates `c.slot` off a `Cell[Leaf]` receiver to `Leaf` rather than to `T`, so the load is typed by the same bitcast a narrowed receiver already gets. A subscripted constructor call (`Cell[Leaf](...)`) is the same gap seen from the callee side -- an `IndexSlice` where a name was expected, so the call lowered to nothing -- and now routes to the erased archetype's instantiation through the callee's own `type[Cell[Leaf]]` type. This retires seven of the twenty-eight `unitree` seam waivers: `Import.is_jac` (`self.hint.tag.value`), `AstAccessNode.access_type` (`self.access.tag.name`), and the five re-emissions of `access_type` that `TypeAlias`, `GlobalVars`, `Archetype`, `Enum` and `Ability` inherit, since a property declared on a non-primary ancestor re-lowers per concrete class. It is also the narrow half of #8133's generics-monomorphization item, reached without monomorphizing any layout.
