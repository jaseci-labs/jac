- **`jac scale deploy` reads the app dependency graph again instead of booting in declaration order** (#9012): computing app edges walked the compiler's module hubs while boundary analysis was registering new modules into those same hubs, so every deploy of a multi-app workspace raised `RuntimeError: dictionary changed size during iteration`, the deploy swallowed it with a warning, and the fleet booted in the order the apps happened to be declared rather than the order their bridges require. The hubs are now re-read to a fixed point, so modules registered during the walk contribute their edges too.
