- **Performance: native list subscripts check bounds with one unsigned compare**: every native list read `xs[i]` and write `xs[i] = v` normalized the index (test for negative, add the length, select) and then tested both ends before touching the element, about seven operations per access. The in-range case is now a single unsigned `index < len` compare, which also catches negative indices because they read as huge unsigned values. Negative indices then get the length added and are checked again in a separate block laid out off the hot path, which raises `IndexError` if the index is still out of range. Behavior and error messages are unchanged. A list-heavy benchmark (a sieve and a matrix multiply on flat lists, `jac build --native`) runs 11% faster (334.5 ms to 297.6 ms) with 18% fewer instructions.
