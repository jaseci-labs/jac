- **Fix: the Kubernetes e2e observability phase follows `[scale.monitoring] enabled`**: M-14.a waited on a Prometheus Deployment whenever `[scale.gateway.logs]` was enabled, although Prometheus, kube-state-metrics and node-exporter deploy only under the monitoring switch, so both nightly `microservice e2e (k8s)` lanes failed on a logs-only deploy. The phase now reads both switches through the scale config loader, waits on Prometheus only when monitoring is on and asserts it is absent otherwise, and the deploy log no longer names components it may not deploy.
