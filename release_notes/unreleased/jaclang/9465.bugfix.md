- **Fix: A `with ... as` alias is typed through `__enter__` wherever it is read**: The alias type used to be set only when the checker walked the `with` statement. So when a native program's import was typed earlier, while its interface was built, the alias came out Unknown. That made `jac check` report E1032 inside the bundled native `zipfile` and then fail with "Native dependency analysis failed". A native module's `open` also now resolves to the native builtin even when the module is typed outside a checker pass.
