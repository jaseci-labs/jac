- **Breaking: Simplify Jac object field declarations**: Use ordinary `has` defaults in Jac archetypes. The Jac-owned `field` helper and its Jac library re-export remain available for explicit factories and field options, including on `@make_object class` declarations. Compiler-generated descriptors still use `ObjectField` directly. The unused `compare` and `metadata` options are removed from both APIs, and Jac reflection no longer copies those attributes from Python dataclasses. `dataclasses.field` remains specific to Python dataclass interoperability.
