- **Breaking: Simplify Jac object field declarations**: The runtime `field` helper and its Jac library re-export are removed. Use ordinary `has` defaults in Jac objects and `dataclasses.field` for Python dataclasses. Compiler-generated and internal dynamic declarations construct `ObjectField` directly. `ObjectField` no longer accepts the unused `compare` and `metadata` options, and Jac reflection no longer copies those attributes from Python dataclasses.
