- **Serve: an opt-in session cookie for browser media requests**: With `JAC_SERVE_AUTH_SESSION_COOKIE=1`, login also sets an `HttpOnly`, `SameSite=Strict` session cookie that authorizes same-site `GET` and `HEAD` requests, so `<img>`, `<video>`, `<audio>` and download links can reach protected endpoints; `POST /user/logout`, which `jacLogout()` now calls, clears it. A request with an `Authorization` header is unaffected, and writes are never authorized by the cookie.
