- **Refactor: Android Compose intent pipeline**: Reactive detection now records target-neutral semantics into `IntentModule` via `IntentCollector`, `IntentSession`, and per-target adapters; `ComposeGenPass` lowers kotlin_ast leaves and native Compose view IR into a separate `ComposeModule` wrapper. `ComposeEmit` and the `jac build --client android` gate consume that model end-to-end.
- **Refactor: unified client-surface resolution**: `resolve_client_surface()` in `project/client_kind.jac` is now the single authority for a module's rendering surface (framework, `is_compose`, `is_mobui`), with the `CompileOptions.client_framework` override taking precedence over per-module disk config. Both the checker's ambient gates (`TypeEvaluator._is_compose_module` / `_is_mobui_module`) and ES backend selection (`EsastGenPass._ensure_backend`) delegate to it, so the ES backend now honors the `client_framework` override it previously ignored, which is the path an in-memory Android page compile threads through.
