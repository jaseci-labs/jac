- **Fix: byLLM no longer leaves prompt-cache markers on your messages**: for Anthropic models byLLM wrote its `cache_control` markers onto the stored message dicts (steers added through `on_iteration`, assistant replies, compacted history and `conversation=` lists) and never removed them, so every request carried one more than the last until Anthropic rejected it for having more than four. The markers now go on the request's own copy, at most one each on the system message, the latest message and the last tool, and any marker a saved history already carries is dropped before sending.
