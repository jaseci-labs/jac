- **Client: imported JS/TS classes now construct with `new`**: calling a `.d.ts`-declared class from client code (e.g. `Greeter("world")` for an npm-provided class) compiled to a plain call, which threw `TypeError: Class constructor Greeter cannot be invoked without 'new'` at runtime. The ES backend now consults the resolved callee type and emits a `new` expression for instantiable foreign class references, while Jac archetypes, declared functions, and builtin coercions (`f = int; f(x)`) keep their existing lowering.
