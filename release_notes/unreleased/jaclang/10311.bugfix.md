- **Fix: Sealed apps keep an entry that only renders the client**: `jac build --as sealed` (and so `jac scale deploy`) now seals an app's entry module even when it holds only client code, such as a web app whose `main.jac` renders the UI and reaches its endpoints through client components, or an app with no server modules. The sealed image previously left that entry out and exited at boot with `Sealed application is missing executable artifact`. Other client-only modules are still left out of the seal.
