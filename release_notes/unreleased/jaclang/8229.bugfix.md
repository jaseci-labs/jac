- **Native: a `(T | None)` field on a generic archetype no longer drops the value it is constructed with**: the slot was classified as a *foreign optional*, the bucket for an option over a type the native lane cannot model at all, so the constructor skipped it and its declared default was discarded. It read back as `None` however it had been built, while a later assignment to the same field worked, which is what made the shape compile cleanly and answer wrongly. An unsolved type parameter is not foreign: it erases to the same pointer a bare `T` field already uses, so the option now lowers through that erasure and takes part in construction and defaults like any other slot. The erasure is only sound while the type argument is a reference, since one struct serves every instantiation, so instantiating a generic archetype at a scalar, where a pointer slot cannot carry an unboxed value and the null that spells `None` aliases a zero payload, is now refused with `E5092` naming the archetype, the slot and the type argument instead of segfaulting or silently answering `None`.
