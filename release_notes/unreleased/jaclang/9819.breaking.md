- **Breaking: a local `jac run` serves on loopback instead of every interface (#9819)**: `[serve] host` now defaults to `127.0.0.1` (`0.0.0.0` when running in a pod), so a development server is no longer reachable from every device on the network, and the startup banner lists "Network" URLs only for interfaces the server is bound to. Pass `--host 0.0.0.0`, set `[serve] host` or `JAC_SERVE_HOST` to serve other devices; the official Docker image and generated pod manifests set `JAC_SERVE_HOST=0.0.0.0` themselves, and mobile dev against a LAN address binds every interface for its backend. The dev Vite server and the local fleet gateway (`[scale.gateway] gateway_host`, now unset by default) use the same default instead of always listening on every interface, the gateways honor `JAC_SERVE_HOST` so the image's opt-in reaches them, a `host` set under `[client.vite.server]` still wins for the dev Vite server, and a pod manifest never ships a loopback `[serve] host`. See [Breaking Changes](../breaking-changes.md).
