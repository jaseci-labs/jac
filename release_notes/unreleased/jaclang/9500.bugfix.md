- **Fix: Member names spelled like browser globals no longer seed client placement**: A keyword argument, connect or assign field, class-pattern field or filter field named like a browser global (`Passage(window=True)`, `[?:Room, fetch == 1]`) no longer seeds its function client. Before, that seed pulled the function's archetypes and imports client, so `jac run` of a pure graph program failed native lowering with E5082 or demoted functions over signature types.
