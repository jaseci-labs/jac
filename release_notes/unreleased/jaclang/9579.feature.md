- **Bundled Native `tomllib` and `configparser`**: Ports of CPython's pure-Python `tomllib` (full TOML 1.0.0 `loads` with CPython-exact error messages and line/column positions) and `configparser` (`ConfigParser` with BasicInterpolation, DEFAULTSECT fallback semantics, strict/non-strict duplicate handling, and the complete `Interpolation*`/`Parsing` error family) now run as bundled native modules, no Python required. tomllib parses ~2.1x faster than CPython 3.14 and configparser ~1.8x faster. Also speeds up native `json.dumps`/`loads` string handling and `csv.reader` field building (~13%/20%) via chunked slice-appends, and adds `scripts/bench_parsers*` + `scripts/bench_sqrt_*` benchmark harnesses.
