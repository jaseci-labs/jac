- **Fix: a `dict[K, any]` narrowed out of `any` to a typed `dict[K, V]` is converted, not reinterpreted**: The native unbox took the pointer as is, so the typed dict read JacVal slots as raw `V` values and came out empty or garbage. It now reads the allocation header's type tag: a `dict[K, any]` payload is copied with every value unboxed, and any other payload (a typed dict that went through `any` and back) keeps its identity, so writes through either name stay shared.
