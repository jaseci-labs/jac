- **A conditional between a tuple and `None` lowers natively**: `items.append((a, b) if cond else None)` and other conditionals whose sides are a tuple literal and `None`, typed `tuple[...] | None`, failed native lowering with E5092 ("`any` box of {...}"), because the two sides were met as `any`, which cannot hold a tuple by value, and the containing function was demoted to Python. The tuple side is now boxed to the expression's optional tuple and `None` becomes that tuple's null, so the conditional stays native when appended to, stored in, or returned as an optional tuple.
