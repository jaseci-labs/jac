- **Fix: allocating a scratch database no longer scans every database in the cluster**: Opening a scratch store reaps only `jac_scratch_*` databases (scoped, escaped catalog scan) instead of paying per-database size/session checks for every accumulated project database. Orphaned project databases are now reclaimed only by the start-time sweep, matching the documented "a cluster start reclaims it" contract, and `jac db status` surfaces dead-scratch and orphaned-project counts so accumulation is visible.
- **Fix: flush and catalog scans shed duplicated work**: `_flush_locked` ran `Serializer.serialize` once to compute the persist-hash and again inside `_serialize` to build the row; the hash and the row now share one serialization. Catalog scans used by scratch reaping, the start sweep, and `jac db status` also skip the per-database `pg_database_size` stat (`list_databases(..., with_size=False)`), which walked every matched database's files even though none of those paths read the size.
