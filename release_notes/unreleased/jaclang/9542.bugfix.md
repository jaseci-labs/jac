- **Fix: Native code no longer aborts calling a function that demoted later**: When a native function (or a test) was lowered before a function it calls, and that callee then fell back to Python, the caller kept a direct call into the callee's abort stub, so `jac run` or `jac test` died with SIGABRT (exit 134) and no message. Such callers now fall back to Python as well, transitively, and a native test that cannot run natively runs its Python body instead of failing its module.
