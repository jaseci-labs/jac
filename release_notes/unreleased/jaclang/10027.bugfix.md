- **Fix: a rejected candidate no longer lets `jac install` pick a prerelease**: a prerelease is now chosen only while a requirement of a currently selected version names one, so a candidate the solver inspected and then backtracked out of (for example one depending on a package with no releases) no longer leaves a stable-only project with a prerelease locked and installed. Opt-ins from the project and from surviving dependencies still apply, including when a newer version of a dependency has to be given up for an older one that names the prerelease. When only prereleases match and nothing could name one, solving fails immediately with "only prereleases match, and no requirement names one" instead of retrying versions of unrelated packages.
