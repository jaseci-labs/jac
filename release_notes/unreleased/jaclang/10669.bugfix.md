- **Fix: `jac test <suite>` runs that suite's tests, not those of every module it imports**: importing a module loads its `.test.jac` annex, and the runner ran every test registered by the import, so a suite also ran (and reported as its own) the tests of each module it imports, transitively. A failing dependency test failed every suite importing it, and a project run executed a module's tests once per importer. A suite now runs only the tests of its own module and that module's annexes; a dependency's tests run when its own suite is collected.
