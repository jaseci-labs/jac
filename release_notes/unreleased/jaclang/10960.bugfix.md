- **Fix: code that can never be native is placed in Python up front**: under the native default, a module importing one of jaclang's own Python-side modules (such as `jaclang.cli.workpool`), and a function using a Python-only builtin (`eval`, `exec`, `compile`, `globals`, `locals`, `vars`, `breakpoint`, `testraises`, `testskip`, `testfail`), are now placed in Python by placement instead of failing native lowering and being demoted afterwards.
