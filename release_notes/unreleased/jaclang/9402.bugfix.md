- **Fix: `str()` on an owned `T | None` temporary no longer returns a dangling string on the native backend**: `_emit_optional_str` extracted the optional's payload pointer and returned it borrowed, but the caller released the owned optional right after the builtin returned. The `str()` result then pointed at freed memory, and the next string allocation -- typically the concat buffer in `"p=" + str(opt_call())` -- reused that exact chunk, printing garbage. The payload now gets its own heap copy when the source optional is owned (an RC retain is a no-op under `nogc`), and the resulting phi is marked owned so the copy is released exactly once; the `None` incoming is heap-allocated in that case too, since `nogc` release is a plain `free()` with no RC magic check. Pinned by `test_native_optional_str_temp.jac` across every memory profile.
