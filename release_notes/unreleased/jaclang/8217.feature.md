- **Feature: Native units interoperate with Python-side base classes**: a jac class compiled natively can now inherit from a class that stays Python-side (the `Transform`/`UniPass` shape, where cross-module trust registers only the hierarchy). `super.postinit();` chains into the base's Python `__post_init__` (previously a fatal E5092 that aborted the whole module), stores to inherited fields and calls to inherited Python-resident methods lower natively, all through one primitive: each native instance owns a Python shadow (a real instance of a synthesized subclass of the base, registered by struct address) and inherited member access becomes attribute access on that handle via direct libpython externs, the same interop path the sealed parser's materializer already uses. Scalars, strs and class handles cross the boundary; unsupported shapes keep their loud E5092 so demotion still works. Closes blockers 4 and 5 of #8201.
