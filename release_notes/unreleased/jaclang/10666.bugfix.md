- **Fix: behind an ingress, the `jac scale deploy` gateway sees each browser's address**: the deploy defaulted `JAC_SERVE_PROXY_TRUSTED` to the cluster's private ranges for app services only, so the gateway took the ingress controller as the client for every browser and its per-client limits were one shared bucket. The gateway now gets the same default whenever the deploy puts an ingress in front of it (`[scale.gateway.ingress] enabled`, or a shared ingress with a domain). With no ingress it still trusts no proxy, and an explicit `[serve.proxy] trusted` still wins.
