- **`TypeVar`, `Generic`, and `Protocol` are no longer ambient**: Jac's `[T]` generics syntax (`def f[T](x: T) -> T`, `obj Box[T]`) is the blessed spelling for generics, and `Self` covers self-returning methods. Code that used these three names without importing them must now add an explicit `import from typing { ... }` (still fully supported for Python interop) or migrate to Jac generics syntax. The other 14 ambient names are unaffected. Tooling that read `typing_ambient.pyi` must switch to `jaclang.jac0core.ambient.ambient_imports_by_module()`, which parses the new `runtimelib/prelude.jac` source of truth.
