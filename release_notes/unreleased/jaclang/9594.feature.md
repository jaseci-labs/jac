- **Faster kit builds: stage-0 kernel reuse and a lighter toolchain precompile**: the kit now builds its stage-0 kernel from a fixed copy of the staged package and links it to a fixed, cached output. Kernel units and the linked kernel therefore carry over between builds instead of being re-lowered every time (a second build from a different staging path: 1320 s to 37 s). With a stage-0 pin, the jaclang precompile leaves the compiler's analysis zone to that kernel build and lowers only the native units programs link (cold compile pass: about 1280 s to 214 s). Also fixed: a pinned snapshot is digested under its own `compiler_inputs.txt` (any edit to that file used to disable stage 0 silently); the client modules codegen reads are compiler inputs; and compile-time input rows name package files by package path, so they stay valid when the tree moves.
