- **Hot reload rebuilds client components outside `pages/`**: a client app's prepared record never listed the Jac modules its client compiles, only their assets, and an incremental re-prepare after a server edit dropped the modules it had covered. From then on an edit to a shared component or its impl annex logged `Restoring prepared application` and the browser kept the old build. The client compiler now records every Jac module of the client closure, with its annexes, so an edit to any of them re-prepares.
