- **byLLM: usage/cost now reaches every `by llm()` invocation shape**: previously only `stream=True, logging=True` calls surfaced token usage and cost via the `usage` `StreamEvent`; every other shape (plain non-streaming calls, `stream=True` without `logging=True`, tool-calling loops) computed the same data and silently discarded it. Non-streaming and partially-streaming invocations now get the same visibility through a new `tokens` field on the existing `register_agent_callback` telemetry record.
- **byLLM: more accurate cost on streaming usage**: byLLM now opts in to litellm's native `include_cost_in_streaming_usage` (available since litellm 1.75.2, within byLLM's pinned range), so raw streaming chunks get a cost litellm computes from its own full response context instead of byLLM recomputing one from a synthetic `{model, usage}` shape. Configurable via `[byllm.litellm] include_cost_in_streaming_usage` (defaults to `true`).
