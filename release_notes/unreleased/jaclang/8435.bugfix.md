- **A finished compile releases what it no longer owns**: a long-running `jac serve` or `jac test` process compiles hundreds of modules, and three structures each compile left behind had no owner, so they accumulated for the life of the process. Import boundary facts held the whole tree of every imported service or server-pinned module; the native verdict cache held dependency units with live LLVM state long after the verdict it wanted was read; and the type evaluator's flow-narrowing caches were never cleared. All three are released when a compile finishes now. Hub lookups also normalize the module path, so a symlinked project root (macOS `/var`, a git worktree, a container mount) no longer defeats the module hub and makes every importer parse its own private copy.
