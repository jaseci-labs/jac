- **`comptime` is removed, along with the six tree nodes and the duplicate evaluator it cost the front end** (PR #8321): compile-time metaprogramming was added in #8028 to self-derive the syntax arena's builder surface, and #8052 deleted that arena along with the derived surface, leaving the feature with no consumer anywhere in the compiler or the examples. Gone with it: `ct_expand.jac`, `ct_reflect.jac` and `ctlib.jac`; the independent text-level expander the jac0 bootstrap carried so that jac0core sources could use the same dialect; the `CtBlock`, `CtElse`, `CtFor`, `CtIf`, `CtName` and `CtSplice` node kinds, their twelve `UniPass` enter/exit slots, and their handlers in the normalize, doc-IR, AST-validation and boundary-analysis passes; the `comptime` keyword and the `${` splice token, neither of which had another use in the grammar; and diagnostics E0033 and E0109. Removing the splice primitive restores the tree shapes it had widened: an ability's name is a `NameAtom` again, parameter and has-var names are plain `Name`, and a function signature holds `Sequence[ParamVar]` rather than a union with two statement nodes, so the passes that walk parameters no longer test each entry's kind. Both cache layers stop hashing comptime reflection dependencies, so a bootstrap cache lookup no longer reads and digests every module a source reflected over, and the JIR cache no longer refuses a hit outright whenever a source reflected. Unrelated but identically spelled, the `NATIVE_COMPTIME_*` constants that name compile-time *erased* Python interop markers (`ABC`, `PassRim`, `cast`, `dataclasses.field`, `TypeAlias`, `ClassVar`) are renamed `NATIVE_ERASED_*` so the collision cannot mislead a later reader into deleting the native lane's erasure rules alongside the language feature.
