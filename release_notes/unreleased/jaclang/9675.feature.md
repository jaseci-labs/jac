- **Native kernel builds no longer lower a unit twice to learn a dependency's digest**: a unit lowered before one of its dependencies was registered recorded that dependency's digest as unknown, and the link plan then ran the unit's IR generation again only to fill it in, which on a cold kernel build repeated the pass for most of the 142 units. The plan now adopts the dependency's digest in place when the unit was lowered in the same build, and still re-lowers a unit whose dependency interface actually changed.
