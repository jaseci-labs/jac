- **CI: a pull request's kit is built without the native compiler kernel, and stage 0 is removed**: the kernel was 24 to 64 minutes of a kit build that otherwise takes about 15, so a pull request's `build-kit` now seals a kit without it and its lanes run the compiler from the bytecode that build precompiles. Main, nightly and release kits build the kernel as before; a pull request gets the full kit with the `build-kernel` label. `JAC_PR_KIT_KERNEL=none` asks the seal for such a kit and is refused outside a `pull_request` CI build, and the release smoke test asserts a kernel is loaded. The stage-0 pin (`jac/bootstrap/stage0.json`), its snapshot build, the bump workflow, the `stage0` cache bucket and the `JAC_STAGE0_PIN`, `JAC_STAGE0_ROOT`, `JAC_STAGE0_STRICT` and `JAC_PR_KIT_KERNEL_LINK` switches are gone: the pin tripped the kernel ABI-contract guard within a day of every bump, so builds fell back to the self build anyway. The kernel is always built by the checkout's own compiler.
