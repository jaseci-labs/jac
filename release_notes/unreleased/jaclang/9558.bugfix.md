- **Fix: native `except Base` catches user-defined subclasses**: on the native backend a handler for a user exception class only matched that exact class, so a raised subclass (including a user subclass of a builtin such as `OSError`) escaped and aborted the process, and a class brought in with `import from m { Cls }` could not be caught even by its own name. Raises now record their class's ancestors in a process-wide lineage table that handlers consult, which also covers subclasses defined in modules the handler never imports.
