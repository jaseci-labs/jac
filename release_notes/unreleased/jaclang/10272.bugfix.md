- **Fix: one page can no longer flood `/cl/__error__` with error reports**: the client runtime no longer reports errors whose stack frames all come from a browser extension (`chrome-extension://`, `moz-extension://`, `safari-web-extension://` or `safari-extension://`). Before, an extension that threw in a loop sent one report per throw. Each distinct error is now reported once per page, a page sends at most 10 reports a minute, and at most 200 in all. The early error handler in a served page, the web runtime and the React Native core all share that one per-page budget.
