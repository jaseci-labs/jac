- **Scale: a config-only deploy now reaches running pods**: secret sections are stripped from the bundle before it is packed and the Secret is referenced by a constant name, so a deploy that changed only configuration produced a byte identical pod template. The patch was a no-op, no rollout happened, and the app kept serving the previous values while the deploy reported success. The pod template now carries a `jac-scale.config-revision` annotation holding the Secret's `resourceVersion`, stamped when the Secret is applied, so a config change is a template change and the fleet rolls. The marker is opaque: it carries no secret material, which matters because the ops read role grants access to deployments and replicasets while withholding secrets. Apps with no secrets have no Secret and so get no annotation and no rollout. An app that already has secrets takes a one-time rolling restart on its first deploy after this lands, because the annotation appears on a pod template that never carried one; it is surge rolled and comes back on the configuration already in the cluster.
