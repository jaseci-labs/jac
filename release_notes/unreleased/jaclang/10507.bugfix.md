- **byLLM: a streamed tool call streams the answer the model gave through `finish_tool`**: byLLM no longer makes a second call asking the model to restate it, which could change the answer or leave it empty. The answer streams token by token as the model writes it, with plain `stream=True` too. A plain stream cannot take back text it has sent, so if the answer is cut off after part of it streamed (for example at `max_tokens`), the call now raises `OutputTruncatedError`; before, byLLM retried and the caller never saw the cut-off reply. A `finish_tool` call that comes after another tool call in the same reply is no longer accepted, streamed or not: its answer was written before that tool's result, so byLLM runs the tool and asks the model to call `finish_tool` again.
