- **byLLM: a streamed tool call that ends with `finish_tool` returns the answer the model gave**: with `stream=True` and tools, byLLM used to make a second model call after `finish_tool` asking the model to restate its answer, and the restated text replaced the committed one in the stream and in `conversation=`. It could differ from the original, came back empty on models that ignore `tool_choice="none"`, and added a round trip to every streamed tool turn. The committed answer is now delivered directly, as one piece on a plain stream or one `chunk` event with `logging=True`. A typed answer recovered through `finish_tool` on a `stream_handler` call is now returned as its value instead of as restated text. A loop cut short by `max_react_iterations` or `ABORT_WITH_SUMMARY` still asks for an answer and streams it.
