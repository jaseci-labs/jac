- **Refactor: the main compiler passes take unitree by symbol import**: The twelve `compiler/passes/main` pass families that reached the unified tree through `import jaclang.jac0core.unitree as uni;` now use `import from jaclang.jac0core.unitree { ... }` and bare node names at all 2,164 reference sites, because a module-object import of a jac module cannot join a native compilation unit while a symbol import compiles and links as a separate one; `ownership_check_pass` and `rc_facts_pass` take the dataflow solvers the same way, and the three names that would shadow an existing binding (`Enum` over the stdlib enum, `Ellipsis` over the builtin, `BuiltinType` behind a null-safe module probe) are aliased or read directly rather than left to import order.
