- **Fix: native booleans print as `True` and `False`**: On the native backend, `print(x in s)`, `f"{x > 1}"` and `repr(x < 0)` rendered `1` and `0`. Membership tests now produce the same boolean as other comparisons, and f-strings and `repr()` render booleans as `True` and `False` (a format spec still formats a bool as an integer, as in Python).
