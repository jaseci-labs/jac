- **Fix: the local model cache rejects corrupt or truncated weights and `jac model pull` repairs them**: a `local:` model counted as downloaded as soon as a non-empty file sat at its path, so a truncated or corrupt GGUF was handed to llama.cpp, listed as `downloaded`, and kept by `jac model pull`, which returned "already downloaded". Each bundled alias now pins its Hugging Face revision, SHA-256 and size; a weight is verified once and stamped, downloads are staged, verified and moved into place atomically under a per-alias lock that `jac model rm` also takes, an invalid weight is refused with `jac model pull <alias>` as the repair and replaced by that pull, and `jac model list` reports `invalid` and `incomplete` entries. A weight downloaded from a different revision than the pin is now replaced on the next pull. `jac model rm` also refuses names that are not a plain alias, so `jac model rm ..` can no longer delete the whole jac cache.
