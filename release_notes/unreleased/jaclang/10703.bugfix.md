- **Fix: client builds accept the standard JavaScript built-ins they rejected**: client code calling `Math.asin`, `Math.atan`, `Math.log1p` and other standard functions no longer fails the build with `Type "_Math" has no attribute`. Every JavaScript built-in that client type checking models (`Math`, `Object`, `Reflect`, `Promise`, `Array`, `Map`, `String`, `RegExp`, `Date`) now lists all of its members that every current browser ships. Newer additions such as `Math.f16round` stay out until they reach every browser.
