- **Fix: native lowering resolved the same source paths over and over**: the native code generator called `os.path.realpath` on the same few hundred source files for every archetype, ability and import it looked up, which was about a third of a cold kernel build's sampled time. Each path is now resolved once per process. A cold `jac native build kernel` on one machine went from 90.7 to 71.8 minutes, with the same demotions and the same peak memory.
