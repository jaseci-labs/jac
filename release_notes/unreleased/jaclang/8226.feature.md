- The type checker learns three narrowing rules. User-defined predicates typed `TypeIs[T]` (PEP 742) or `TypeGuard[T]` (PEP 647) now narrow at their call sites: `TypeIs` on both edges, positive to `T` and negative by subtracting it, `TypeGuard` on the positive edge only, where it replaces the declared type outright. `isinstance` narrowing is applied to each declared union member on its own instead of filtering the union as a whole, so a member above the filter class is no longer thrown away when another member sits below it -- `isinstance(x, Mid)` on an `x: Leaf | Base` answers `Leaf | Mid` rather than claiming every value that passes the guard is a `Leaf`. And a short-circuit chain now narrows only on the edges it licenses: the false edge of `A and B` says nothing about `A` on its own, so `if isinstance(x, Foo) and x.bar { } else { }` no longer excludes `Foo` from the else branch, and the mirror rule holds for a disjunction's true edge.
