- **Compiler: headerless (`--gc none --enforce-nogc`) code is correct for the everyday owned shapes**: a named `own` local moved into an own field, an optional own field, an inline-flattened field, or a constructor argument is consumed at the move (the checker stamps `Module.own_move_sites`, the backend consults it through one primitive), optional own fields tear down with their parent, own parameters are dropped by the callee, overwriting an own field drops the old value, and every one of these static drops applies only in the owned world (a nogc-enforced, non-kernel module). The owned-list layout is decided once from the element type (inline only for a closed-world leaf archetype with no heap slots), so `list[own T]` and `list[T]`, generic bodies and their callers, and borrow returns agree on it; `pop`, `insert`, `del`, and `extend` on an owned list move payloads by value. See #8984.
- **Language: `take(place)` and `swap(&mut a, &mut b)`**: two builtins that move a value out of an optional owned place (leaving `None`) and exchange two places, on every backend. E1316 rejects moving a heap value out of an owned slot without `take()`; E1317 rejects moving an element out of an owned list (use `pop()` or a borrow).
- **Language: receiver modes for methods**: the checker infers whether a method reads (`&self`), writes (`&mut self`), or, when written as `def m(self: own T)`, consumes its receiver. A mutating call while a shared borrow is live is E1303, on an `imm` binding E1309, through a shared borrow E1318; a consuming call moves the receiver. An explicit `self` in an obj/node/edge/walker method is admitted only to declare its mode (E2015 otherwise).
- **Checker: the structural loop-move rule is gone**: a binding moved inside a loop and re-assigned before the back-edge is clean; the CFG dataflow already proves the moved-in-a-previous-iteration case.
- **Dev loop: a stub catalog shipped in the binary is validated against the checkout under the dev-source reroute**, so an edit to `jac_builtins.pyi` rebuilds the dev catalog instead of silently typing new builtins as Unknown.
