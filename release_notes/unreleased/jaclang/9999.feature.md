- **A cold kernel build lowers each unit once and optimizes on every core**: during settlement, a unit whose only stale dependency digests were never recorded (the dependency was still being built when the unit was lowered) now records the dependencies' current digests instead of being lowered again; a real digest mismatch still re-lowers. A cold build of the compiler kernel lowers its 144 units 144 times instead of 310. Units with no cached bitcode are then optimized on a thread pool, each worker in its own LLVM context, sized by `JAC_NATIVE_EMIT_JOBS` (then `JAC_JOBS`). The self-build seal on pull requests links unit objects like the stage-0 seal already did; release builds keep the whole-program link. In CI the cold kernel build drops from about 29 to about 15 minutes.
