- **Fix: `print(None)` crashed the binary, and an argument that could not lower vanished**: A bare `None` lowers to a null `i8*`, and the native `print` handed it straight to a `%s` conversion, so `printf("%s\n", NULL)` took the process down with a segfault and lost the buffered output before it. An optional was always fine, because `x: int | None` goes through the optional repr; only the bare literal reached the raw pointer path. It now prints `None`. Separately, an argument whose sub-expression had no native lowering was skipped outright, so `print(b"Hi".upper())` compiled natively, printed nothing at all, and exited 0 with no diagnostic; hoisting the same call to a local demoted correctly and printed `b'HI'`, so the fault only showed when the call was written inline. That argument now declines the lowering the way every other failure in native `print` already did, which demotes the module and produces CPython's answer.
