- **Fix: Solid state lowering under the shared intent pipeline**: `EsastLeafConverter`'s `convert_expr` / `convert_assignment_value` / `convert_stmts` overrides never bound: the subclass omitted their `def` declarations and the impls lived in `esast_gen_pass.impl.jac` instead of the subclass's own `.impl` annex, so calls silently fell through to the base `LeafConverter` stubs (`None` / `[]`). As a result the Solid backend emitted `createSignal(undefined)` for state initializers and lowered state updates to a bare `x = ...` assignment against the `const` signal binding (`TypeError: Assignment to constant variable` in the jsdom control-flow/counter tests). The overrides are now declared on `EsastLeafConverter` and implemented in `intent/impl/leaf_converter.impl.jac`; emitted Solid matches upstream again (`createSignal(0)`, `setCount(...)`).
