- **Fix: a jac source tree inside the project root no longer breaks the dev server**: Any `.jac` file under a prepared application's root was treated as application code, so with the compiler source checked out inside the project (a vendored or submoduled jac used through `JAC_DEV_SOURCE`) a dev server prepared jaclang's own lazily imported modules as dynamic application modules and failed on every start with `compiling .../jaclang/runtime/graph_walk.jac re-entered it`. A module named `jaclang` or `jaclang.*` now belongs to no application.
