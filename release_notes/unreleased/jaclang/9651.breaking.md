- **Fix: byLLM system prompts no longer accumulate or contradict tool-calling guidance**: `system_prompt=` on a `by llm(...)` call now replaces the base system prompt (built-in persona or `jac.toml`'s `system_prompt`) instead of being appended after it, matching how `jac.toml`'s own override already behaves. byLLM's built-in tool-calling instructions no longer assert an opinion on narration or on how many tools may be called per turn -- that cardinality guidance is now computed once from whether parallel tool calling is enabled and supported by the active model, so it can no longer contradict a caller's own prompt or promise parallel tool calling to a model that cannot honor it.
