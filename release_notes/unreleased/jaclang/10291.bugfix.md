- **Fix: `break` and `continue` in a loop's `else` follow Python**: a loop's `else` runs after that loop has finished, so a `break` or `continue` inside it now applies to the loop around it, as in Python. `continue` in an inner loop's `else` no longer fails to compile with "'continue' is not valid inside a loop's else block", in Jac code and in imported Python modules. `break` in an inner loop's `else` now stops the outer loop; before, it only left the `else` and the outer loop kept going. A `break` or `continue` in the `else` of a loop with no loop around it is now reported as only valid inside a loop, where `break` was accepted before.
