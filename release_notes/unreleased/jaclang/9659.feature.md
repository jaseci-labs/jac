- **Kernel builds report where their time goes**: a native kernel build now ends with one `Kernel phases:` line giving the time spent in frontend analysis (split by parse, IR, placement, analysis and boundaries), IR lowering, per-unit optimization and object emission, with the analysed, lowered, optimized and emitted unit counts and the interface cache hits and dependency misses. When the pinned stage-0 compiler cannot build the kernel, the fallback message states how long the failed attempt took before the self build starts, and under GitHub Actions it is a warning annotation.
