Compiler identity now covers every declared input regardless of how a given staging carries it. A packed payload lowers `compiler/frontend/python`, `compiler/backends/py/jacpython` and `runtime/python` into JacPython's native object instead of shipping their sources, and it now records their hashes in `compiler_identity.json` so its digest still describes the same compiler as the checkout it was built from. A staging that drops those sources without recording them raises instead of silently reporting a smaller identity. Adds `JAC_PRECOMPILE_REQUIRED`, which turns a precompiled unit this compiler will not reuse into an error rather than a silent recompile from source.
