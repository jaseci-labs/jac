- **Compiler identity covers natively lowered inputs in every staging**: A packed payload lowers `compiler/frontend/python`, `compiler/backends/py/jacpython` and `runtime/python` into JacPython's native object instead of shipping their sources, and it now records their hashes in `compiler_identity.json` so its digest still describes the same compiler as the checkout it was built from. Previously the two disagreed silently, so a precompiled unit built by one could never be reused by the other. A staging that drops those sources without recording them now raises instead of reporting a smaller identity.
- **`JAC_PRECOMPILE_REQUIRED` turns a declined precompiled unit into an error**: When set, a module that has a `.jir` unit in a `_precompiled` bundle whose key this compiler will not accept raises instead of silently recompiling from source, so a bundle built by a different compiler generation, jaclang version, Python minor or runtime variant fails loudly rather than costing a full rebuild.
