- **Native backend: embedded NUL bytes no longer truncate `str` concatenation**: native `str` was measured with `strlen`, so `chr(65) + chr(0) + chr(66)` silently collapsed to length 1 on the na backend where sv yields 3. The runtime is now length-aware end to end: string literals stamp their byte length via a static const, concatenation and substrings finalize through a shared `_str_finish` step, and `chr()` stamps length 1 instead of relying on its terminator.
