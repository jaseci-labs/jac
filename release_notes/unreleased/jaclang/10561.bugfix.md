- **Fix: `"*"` in `[scale.gateway.cors]` `allow_methods` and `allow_headers` passes a browser preflight**: the gateway answered a preflight with a literal `*`. Browsers never read that as covering `Authorization`, and with `allow_credentials = true` they read it as no wildcard at all, so under the default config a request with a bearer token failed its preflight, and with credentials on so did any request with a JSON body. A `*` in `allow_methods` is now answered with the method the preflight asked for, alongside any methods listed beside it, so custom methods such as `PROPFIND` pass too, and a `*` in `allow_headers` with the headers the preflight asked for. A response for a listed origin now carries `Vary: Origin`, so a shared cache never serves one origin's CORS answer to another.
