- **Fix: linux-aarch64 `jac` binaries no longer segfault on startup**: the native ELF linker resolved a GOT reference to a copy-relocated variable such as libc's `stderr` to the copy itself, so code that loads the variable's address through the GOT dereferenced it twice and passed the FILE's contents as the stream. aarch64's large code model reaches `stderr` that way, so the launcher crashed on `jac --version`. GOT references to copy-relocated symbols now get their own slots holding the copy's address.
