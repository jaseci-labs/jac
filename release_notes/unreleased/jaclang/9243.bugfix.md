- **Per-app `[apps.<name>.scale]` keys are no longer reported as unknown `[scale]` keys** (#9162): a process serving a workspace app validated the app-merged `[scale]` table against the project-level schema, so every key of its own `[apps.<name>.scale]` overlay was warned about as "ignored" although the deployment applied it, and `JAC_SCALE_CONFIG_STRICT=1` refused to start the app. `PluginConfigBase` now validates each configuration layer against its own schema before the merged view is used: the project table under `[scale]`, and the running app's overlay under `[apps.<name>.scale]` with the per-app key suggestions. Plugins declare the app-level schema through the new `get_app_config_schema` hook, which defaults to the project schema for overlays that mirror their table (`[apps.<name>.client]`, `[apps.<name>.desktop]`).
