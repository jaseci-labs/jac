- **Sealing wave 1: compiler passes join the native seal**: Four compiler passes (annex, module codegen, uni-pass traversal, endpoint effects) now ship as AOT native artifacts in sealed builds, each gated by a per-root seam coverage with enumerated waivers and a reachability proof. A runtime tripwire refuses to run a sealed pass's bytecode body unless the pass-serving binder has bound its artifact live (dlopen, export surface, live runtime probe), and the annex merge is the first pass surface proven to execute natively: the sealed parser's new `mat_merge_probe` crossing weaves annex modules on native trees, parity-checked against the bytecode lane at seal time and at every bind.
