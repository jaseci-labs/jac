- **Fix: unannotated function's implicit `None` return matched against an explicit `-> None`**: A function with no `->` annotation had its inferred return type left in class form (raw `NoneType`), while an annotated return type is always converted to instance form. Calling such a function from a `-> None` function compared the two mismatched forms and raised a self-contradictory `E1002: Cannot return NoneType, expected NoneType` alongside the expected `E1003`, and blocked native codespace compilation entirely.
