- **`jac scale deploy`: the seal's precompile reuses the units its prepare compiled**: Without the native compiler kernel, the seal's prepare compiled every module with code generation but left no interface or diagnostics in their cache entries, so the precompile that follows analysed almost every unit again. The prepare now writes both for the units it compiles. On a 299-module app, 292 of 298 units are reused instead of 19, and the precompile goes from 116 s to 54 s, while the prepare takes about 7 s longer. `jac run`, `jac start`, `jac build` and `jac check` are unchanged.
