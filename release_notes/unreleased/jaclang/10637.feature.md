- **`jac scale deploy` builds the client inside the seal's own compile**: The seal's prepare step now compiles and bundles the client in the same application compile instead of a second `jac build --as client` process, so a deploy no longer runs two whole-app compiles at once. On a 299-module app the separate client build took about 11 minutes and 15 GiB; the combined prepare takes about 12 seconds more than the server-only one. `jac build` gets the same saving.
