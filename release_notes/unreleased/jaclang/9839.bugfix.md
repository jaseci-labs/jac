- **Fix: `jac build --as wheel` compresses the wheel it writes**: both wheel writers opened their archive with `ZIP_DEFLATED`, but each entry was written through a hand-built `ZipInfo` (to pin its timestamp for reproducible builds), and such an entry keeps its own default of `ZIP_STORED`, so every file in the wheel, and in a wheel rebuilt from the sdist's bundled backend, was stored uncompressed. Each entry now takes the archive's compression, RECORD included, so a wheel with text sources or package data is roughly half the size; entry timestamps, contents, RECORD rows and byte-reproducible builds are unchanged.
