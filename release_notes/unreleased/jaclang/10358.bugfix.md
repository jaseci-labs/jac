- **`jac fmt` is idempotent on comment-only files**: formatting a `.jac` file that contains only comments used to prepend one blank line per pass (`# c` became `\n# c`, then `\n\n# c`) because the comment anchored to the module's synthetic `EmptyToken` placeholder, whose emitter inserted a hard line after the empty base and then treated the inserted blank as intentional spacing on the next parse. Comment-only files now format to themselves and stay byte-stable across passes; leading blank lines on them are stripped (matching files with statements), blank lines between comments are preserved, and files with statements are untouched.
