- **Fix: the dev server reinstalls client packages after a `jac.toml` dependency edit**: `jac run` on a web app only wrote `.jac/client/configs/package.json` when it was missing, so the `node_modules` staleness check compared the previous run's manifest with its own hash. After `[dependencies.npm]` changed, nothing was reinstalled and Vite failed with `failed to load config from .../vite.dev.config.js`. The dev server now regenerates the manifest from `jac.toml` before the check, as `jac build` already did.
