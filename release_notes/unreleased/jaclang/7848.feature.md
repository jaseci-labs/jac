- **Jac's ambient type vocabulary is declared in Jac and works at runtime everywhere**: the ambient names the checker lets you use without imports are now declared in `runtimelib/prelude.jac` -- the 11 container/callable protocols (`Sequence`, `Mapping`, `Iterable`, `Iterator`, `Callable`, `MutableMapping`, `MutableSequence`, `Awaitable`, `Coroutine`, `AsyncIterable`, `AsyncIterator`) plus the annotation forms `Annotated`, `ClassVar`, and `Literal` -- and the runtime now binds them into every module namespace on every bytecode tier, including jac0-compiled bootstrap modules. Previously W1103 advised deleting imports the runtime still required, which NameErrored on any value-position use; the warning's advice is now safe to follow. Generated Python imports the protocols from `collections.abc` instead of the deprecated `typing` aliases, and `typing_ambient.pyi` is retired. Explicit imports and module-local definitions always shadow the ambient binding.
