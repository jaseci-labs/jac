- **Performance: native list loops read each list's length and data pointer once**: a range loop such as `y[j] += a * x[j]` reloaded both lists' lengths and data pointers after every element store, and kept every bounds check inside the loop, because the generated code told LLVM nothing about what a store could change. List header fields and list elements now carry alias information of their own. When a loop body can't change a list header, each list it indexes has its length and data pointer loaded once before the loop. A body qualifies when it calls nothing but a few builtins, has no `append`, `pop`, slice store or `del`, and doesn't rebind the list. An out-of-range index still raises `IndexError`, and a negative index still counts from the end. On 1000-element lists, `y[j] += a * x[j]` runs 31% fewer instructions and `dst[j] = src[j]` 36% fewer. The matmul benchmark runs 14% fewer instructions (0.31 s to 0.20 s) and fannkuch 20% fewer.
