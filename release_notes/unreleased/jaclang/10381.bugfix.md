- **Checker: a method or ability with the name of a field is an error (E0078)**: a `has` field and a `def` or `can` of the same archetype shared one attribute name, so the function replaced the field and `self.<name>` read it, with `jac check` passing. E0078 now reports the method or ability and names the field's line; Python modules and stubs are not checked.
