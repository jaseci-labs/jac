- **Fix: `jac scale deploy` reuses an unchanged client build and seeded runtime dependencies**: The host client build is keyed on its inputs and kept under `.jac/client-cache`, so a deploy whose client inputs did not change skips the rebuild. A seeded seal reuses the compiled runtime dependencies whose sources still match instead of compiling them again, and a precompile report left in the project no longer stops the sealed bundle from being kept for reuse.
