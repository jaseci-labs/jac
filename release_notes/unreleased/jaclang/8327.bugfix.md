- **The language server's container annotations say what they hold**: first migration cluster ahead of the bare-container hard error (#8323, decision 3), whose blast radius measures 5,975 annotation sites across 934 files on the parsed tree -- 2.4x the split threshold and 5.4x the `typing.Any` sweep, so the refusal lands at the end of a cluster series rather than in front of it. The meter is the existing `W1036` advisory ("Generic type `list` used without type arguments, defaulting to `list[any]`"), which decision 3 promotes the way `W1104` became `E1122`; on this cluster it reads 25 before and 2 after, the two survivors being `deque` and `Future`, generics that are not builtin containers and stay warnings. Every site was typed from what the code actually puts in it rather than by blanket `[any]`: `collect_resolved_nodes` returns `list[uni.NameAtom]` because its only append is isinstance-guarded, `seen_locs` is `dict[tuple[int, int], bool]` after the `(line, col_start)` key the loop builds, `sem_managers` is `dict[str, SemTokManager]`, and `publish_diagnostics` takes `list[Diagnostic]` because both call sites pass `gen_diagnostics`. Thirteen of twenty-four sites keep an `any` in the value position -- `to_dict`/`from_dict` are generic JSON serializers and the JSON-RPC envelopes hold heterogeneous protocol values -- but none became a blanket `[any]`: every one keeps a concrete `str` key, and the two string-to-string maps are fully concrete.
