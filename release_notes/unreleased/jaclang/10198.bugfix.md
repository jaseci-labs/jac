- **Fix: client modules export what other client modules import** (#9131): a plain (non-`:pub`) client declaration was exported only when a cross-module import was what moved it to the client, so a glob its own component already used, any plain JSX component, every plain declaration of a `[placement.pins]` client module, and every name re-exported through another module passed `jac check` and failed `jac run` with `runtime import(s) ... are not exported`. Exports are now decided when the client graph is linked: a module exports its `:pub` declarations and routes, plus each non-`:priv` client declaration and forwarded import that another client module imports at runtime, so the export list matches the importers' import lists by construction, also when the dev server recompiles the provider alone. Names nothing imports stay unexported, so component modules keep Fast Refresh, and a name imported only for a type annotation no longer costs the module its refresh boundary.
