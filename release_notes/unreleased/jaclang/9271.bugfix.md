- **Fix: an erased distinct type binds the primitive it resolved to** (#9271): `type Brand := B;` is a check-time brand over a primitive runtime value, but the Python lowering bound the *spelling* of `B` rather than the primitive `B` resolved to. Since a base must resolve to a primitive, the only way to write one is through a plain alias -- and when that alias arrived through a `comptime import` or an `import type`, neither of which emits a runtime binding, the generated module raised `NameError: name 'MyInt' is not defined` at the alias line on load (an `import type` base was emitted under `if TYPE_CHECKING:` and then assigned anyway). The checker now records the primitive it validated and the lowering binds that, matching what the jac0 bootstrap lane already emitted. `jac tool jac2py` output for a brand is self-contained as a result, and a brand over a generic base binds the bare primitive, so `isinstance(x, Brand)` no longer raises `TypeError`.
