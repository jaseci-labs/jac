- **Fix: a docstring inside a body with no `;` no longer turns into the next line's error**: a string on its own line(s) at the start of a statement, followed by a new statement on the next line, is now one `E0111` ("A docstring goes before the declaration, not inside the body") on the string. Before, the parser joined it to the next line, so `"""Doc."""` followed by `if x > 0 {` reported `Expected 'else', got '{'`, followed by `(a, b) = ...` reported an invalid assignment target, and followed by `[x, 1];` compiled and failed at run time. A body that is only a docstring now gets a help on its return-type error that says the string became the body's return value.
