- **Fix: Native: a generic method on a generic archetype returns its field's value, not an address**: on `obj Holder[V]`, a method with its own type parameter and a `V`-typed parameter, such as `def first[K](key: K, alt: V) -> V { return self.val; }`, returned a heap address on the native tier. The method solved `V` from its argument while the field stayed boxed. It now treats `V` the way the archetype's other methods do, so it returns the field's value; a `Holder[float]` called with an int argument reads its float correctly; and a method like `get[K](key: K) -> V` now runs natively instead of falling back to Python.
