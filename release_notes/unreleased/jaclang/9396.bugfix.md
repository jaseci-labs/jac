- **Fix: Faster native `hashlib`, `hmac`, and `secrets`**: digest calls now finalize a cloned OpenSSL context instead of re-hashing every retained `update()` chunk, and hex/urlsafe output buffers through bytes instead of per-character string concat. Repeated `digest()` is ~20x faster (CPython parity), `hexdigest` ~2.7x, `secrets` ~2x.
- **Fix: Native `hashlib`/`hmac`/`secrets` parity and hardening**: `hashlib.new` is public and gains `sha3_224`/`sha3_384`/`blake2b`/`blake2s`; `hmac.new` requires `digestmod` (`TypeError`) and accepts `msg=None`; `secrets.token_*` accept `nbytes=None` (default 32), reject negatives (`ValueError`), and raise `TypeError` on other non-int input like CPython; `hmac.new` rejects a non-bytes `msg` with `TypeError` and accepts `bytearray` key/`msg`; `hmac.compare_digest`/`secrets.compare_digest` and `secrets.DEFAULT_ENTROPY` added. Hash/HMAC methods raise `ValueError` on a finalized context instead of dereferencing null, and digest output is sized by OpenSSL's reported length rather than a caller-controlled field.
- **Fix: `hmac.compare_digest`/`secrets.compare_digest` no longer early-exit on length mismatch**: the comparison now runs the full `len(b)` loop like CPython's `_tscmp`, so mismatched inputs expose only the length difference CPython already leaks, not a shortcut branch.
