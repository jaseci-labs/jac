- **Desktop: let the user choose the backend at run time**: `[desktop] backends = { local = "embedded", web = "https://..." }` ships one binary that runs on its embedded server or against a remote one. The host boots only the saved choice (or `default_backend`; `"ask"` leaves the first choice to the app's UI), switching relaunches the app, and sessions are kept per backend (`jac_token` always holds the active backend's). The UI reads and changes the choice with `backend` from `@jac/desktop` (`choices()`, `current()`, `use(name)`).
