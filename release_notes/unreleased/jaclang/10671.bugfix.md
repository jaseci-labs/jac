- **Fix: native calls through an `any` or bare `Callable` value are refused with a hint instead of miscompiled**: the demotion warning for a call through an `any` value now shows its `help:` line, which suggests binding the value as `Callable[[...], R]`, and that binding now works: a function stored in `any` is boxed as a closure, so reading it back as a `Callable` dispatches natively instead of crashing. A call through a bare `Callable` with keyword or extra arguments, which dropped them or crashed the backend, is refused with a hint. A class read out of `any` as a `Callable` raises `TypeError` natively instead of crashing; a class held in `any` can only be constructed from a Python/@sv context.
