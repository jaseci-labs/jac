- **Identity: an opt-in TOTP second factor**: Users can enroll, verify, list and remove a TOTP factor at `/user/mfa/*` and receive single-use recovery codes. Password sign-in for an enrolled account answers a short-lived challenge to finish at `/user/mfa/login` with a code, and `/admin/login` asks for the code too. Sessions that proved a second factor carry `aal: "aal2"`, which a walker or function reads with `caller_assurance_level()` from `jaclang.server.identity.assurance`. Accounts without a factor sign in as before.
