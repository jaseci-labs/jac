- **Fix: Gated graph reads stay bounded**: For a logged-in (gated) caller, `len()` of a traversal now counts in SQL, and untyped hops push the read-access test and the `LIMIT` into the query instead of loading every neighbor. Roots and archetypes with a custom `__jac_access__` are fetched as candidates and decided in Python (a multi-hop query resolves up to such a hop first, so a hidden node is never walked through), and a bounded read keeps reading until it has its rows; a node slice now skips nodes rather than the edges that reach them. `GraphQuery(after=(seq, edge_id))` pages a one-hop query by keyset, `resolve_query_page` returns one page of readable nodes with their readable edges and the next cursor, and `resolve_query_type_counts` counts them per node or edge type.
