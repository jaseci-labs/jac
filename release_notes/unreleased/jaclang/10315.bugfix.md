- **Fix: Gated graph reads stay bounded**: For a logged-in (gated) caller, `len()` of a traversal now counts in SQL, and untyped hops push the read-access test and the `LIMIT` into the query instead of loading every neighbor. SQL decides access only for stored types this process has loaded with the default access rules; roots, archetypes with a custom `__jac_access__` and types not loaded yet are fetched as candidates and decided in Python (a multi-hop query resolves up to such a hop first, so a hidden node is never walked through), and a bounded node or edge read keeps reading until it has its rows. `GraphQuery(after=(seq, edge_id))` pages a one-hop query by keyset, `resolve_query_page` returns one page of readable nodes with their readable edges and the next cursor, and `resolve_query_type_counts` counts them per node or edge type, checking at most 200 Python-decided rows and saying when the counts are therefore a lower bound.
