- **Feature: the code generators run in the native compiler kernel**: a kernel compile returns each module's products (its JCIR, its client JavaScript and their metadata) as a record that the host assembles into bytecode, and the parse-and-materialize crossing that handed Python a syntax tree is removed. Native code also resolves module-qualified class references (`lib.Circle(...)`, `isinstance(x, lib.Shape)`), class patterns over imported archetypes (`case Circle():`), and classes an importer sees through a precompiled interface, which previously failed to lower.
