- **Fix: `type()` identity checks and `isinstance(d, dict)` were wrong in compiled JavaScript**: `type(x)` lowered to JS's `typeof x` (a string tag) while a bare type name lowered to a runtime type object, so `type(x) is <builtin>` was always false and `type(x).__name__` didn't even compile; separately, dict literals were misclassified as `Object`, so `isinstance(d, dict)` was false for every dict. Both now resolve correctly: `type()` returns the same type object a bare type name lowers to. Tuple-vs-list and float-vs-int still aren't distinguishable post-compile; that's a pre-existing JS representation gap, not something this closes.
