- **Fix: `type()` identity checks and `isinstance(d, dict)` were wrong in compiled JavaScript**: `type(x)` lowered to JS's `typeof x` (a string tag) while a bare type name lowered to a runtime type object, so `type(x) is <builtin>` was always false and `type(x).__name__` didn't even compile; separately, dict literals were misclassified as `Object`, so `isinstance(d, dict)` was false for every dict, including parsed JSON. `type()` now returns the same type object a bare type name lowers to, for builtins, archetype instances and archetype classes alike. Two representation gaps remain: a tuple reads as a `list` and a whole-valued float such as `3.0` reads as an `int`, because JavaScript has no separate tuple or float type.
