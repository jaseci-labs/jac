- **Bare npm imports resolve**: `import from react { createContext }` now works unquoted in client code. A bare identifier resolves across the module universe in deterministic order -- local Jac module first, then Python, then the client npm world (the union of jac.toml `[dependencies.npm]`, the active client framework's own packages, and what is installed under `.jac/client/node_modules`) -- and one shared classifier drives placement, type inference, and JS emission, so they can no longer disagree. Inference types bare npm imports from the package's `.d.ts` exactly as quoted imports always did. Quotes remain necessary only for names that cannot be identifiers (`embla-carousel-react`, `@jac/runtime`) or to pin the npm form when a local Jac module shadows the name (new warning `W1105`).
