- **Pull-request kits relink the compiler kernel from cached unit objects**: CI kits built for pull requests link the stage-0 kernel from each unit's cached object instead of re-running the whole-program bitcode link, so a PR that changes a kernel unit no longer pays for whole-program optimization. The mode is opt-in (`JAC_PR_KIT_KERNEL_LINK=objects`) and honored only for GitHub Actions `pull_request` builds. The sealed manifest records the link mode, and a sealed image runs an objects-linked kernel only when its record marks it as a pull-request kit. Main, release and nightly kits keep the bitcode link.
