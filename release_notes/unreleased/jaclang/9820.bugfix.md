- **Fix: Moving links into a heavily shared node no longer slows down as the node gains links**: A node with many incoming light edges now drops one by looking it up instead of scanning its incoming list, and compacts that list only when it has doubled. Previously, dropping and reconnecting a link on a node whose incoming count was a multiple of 64 rebuilt the whole list on every move, so 8,192 incoming links cost about 680 us per move instead of about 5 us.
