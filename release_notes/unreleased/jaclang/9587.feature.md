- **Faster toolchain precompile**: the bundled-package JIR precompile no longer runs the analysis schedule (type check, static analysis, lint and the other diagnostic passes) on the jaclang package's Python-lane units, whose emitted bytecode, interfaces and placement are identical without it. `CompileOptions.skip_analysis` and `JacCompiler.get_bytecode(..., skip_analysis=)` carry the choice; user projects are precompiled with full analysis as before.
