- **Compiling a project holds far fewer objects in memory**: Before generating JavaScript for a module, the compiler cleared earlier output on every node of its tree, and clearing created a codegen record on each node that had none. Every node of every compiled module ended up with one. The compiler now clears only the records that exist. Preparing a 299-module app creates 493,574 of these records instead of 2,300,543, and holds 56.7 million objects at its peak instead of 74.8 million. Generated code is unchanged.
