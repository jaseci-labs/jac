- **Fix: a cold native build no longer demotes callers of `math.sqrt`, `math.sin` and friends**: A unit's native layout left out any function it defined under the name of a C extern that one of its imports binds. The bundled `math` defines `sqrt`, `sin`, `cos` and most of its other functions over `_math_native`, which binds libm under those names, so those functions dropped out of its layout. An importer reads that layout only when `math` was compiled in the same process, so a build after a compiler change or with a fresh cache demoted every native caller of those functions. Whole modules then fell back to the server codespace ("Native lowering failed for function 'sqrt'", then "No LLVM IR generated" for their importers), and a warm rebuild of the same tree lowered cleanly. The layout now skips only the C externs themselves.
