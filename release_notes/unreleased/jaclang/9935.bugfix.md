- **Fix: a C record can embed a C record declared in another module**: a native `import from <lib> { obj ... }` record with a field typed by a C record that another Jac module declares failed with `E5092: Native lowering failed for type`, because a unit laid out its own records before those of the modules it imports. The embedded record is now laid out on demand. On the Python side the same module raised `NameError: C type '...' is not bound` as it loaded, because the import of the embedded record was dropped as unused there; an import that a kept C block's declarations are typed by now stays with the block.
