- **Feature: `GET /admin/schedules` lists static `@schedule` tasks with their last run**: admins see every static task a service runs, with its interval, cron or date, its next run, and the tick, worker, status, duration and error of its most recent run. With a database configured, each run records itself next to its tick claim, so every worker and replica reports the same last run. Behind the fleet gateway the same request answers for the whole fleet: the gateway asks every service it serves and each entry names its `service` and that service's `namespace`.
