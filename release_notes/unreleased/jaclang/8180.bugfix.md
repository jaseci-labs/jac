- **Fix: the JIR precompile seed now carries compiler identity**: Payload precompile module keys fold in a content digest of the compiler's own sources (`jac0`, `jac0core/`, `compiler/`, the precompile driver), so a `.jir` produced by one compiler can no longer be reused by a different compiler at the same jaclang version. The seal verifies every module's JIR against that digest before writing the manifest, and CI cache restore-keys are scoped to the same compiler tree. A compiler change now forfeits the seed instead of silently inheriting stale bytecode, with no JIR format bump needed.
