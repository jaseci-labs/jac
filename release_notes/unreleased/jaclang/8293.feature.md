- **Scale: a fleet service accepts the session the gateway minted**: the gateway serves `/user/register` and `/user/login`, so a session token named a user only the gateway knew and every authenticated walker on every other service answered 401. A service receiving a signature-valid, unexpired token for an unknown subject now provisions that user root once and serves the request. Turn it off with `gateway_owned = false` under `[scale.microservices.identity]` when a deployment manages identity itself.
