- **Fix: native `sorted()`/`list.sort()` order tuples, bytes and lists**: The native value sort compared every element held in an erased pointer slot as a string, so a list of tuples was ordered by the leading bytes of its first field and `(float, int)`, `(float, float)`, `(str, int)` and `(float, str)` tuples (and most int-led ones) came back in input order, as did `bytes` lists and lists of lists. The sort now compares such elements through their checked element type, the same way `key=` results are compared.
