- **Fix: `bytes.find` and the rest of the bytes search family lower natively**: `find`, `rfind`, `index`, `rindex`, `count`, `startswith` and `endswith` on `bytes` had no native lowering, so a function calling one was demoted to Python and a program depending on it fell back to the server codespace. They now lower natively with Python semantics, including start/end bounds, empty needles, embedded NULs, int (single-byte) needles, tuple affixes and the `ValueError` cases. `int in bytes` lowers as well. Native `startswith`/`endswith` results on `str` now print as `True`/`False` instead of `1`/`0`.
