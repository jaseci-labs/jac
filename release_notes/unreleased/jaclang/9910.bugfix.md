- **Fix: a package installed from its sdist keeps a valid RECORD for filenames with commas, and the sdist build backend is now Jac**: the PEP 517 backend every sdist ships (`_jac_build.py`) was Python source held in string literals, a hand-kept copy of the wheel writer that joined RECORD fields with `","` by hand, so a data file such as `part,one.txt` got a corrupt RECORD row when installed from the sdist and `importlib.metadata.Distribution.files` raised `ValueError`. The writer is now one stdlib-only Jac module, `jaclang.dist.publish.wheel_archive`, that `WheelBuilder.build` calls and the sdist ships transpiled as `_jac_build.py`, with the package's values in `_jac_build.json`; RECORD is written through `csv` on both paths, the sdist build refuses a backend that would import jaclang, and a wheel rebuilt from the sdist is byte-identical to the direct one.
