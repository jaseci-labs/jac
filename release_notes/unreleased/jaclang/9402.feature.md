- **Native: `signal` and `subprocess` modules**: `import signal` and `import subprocess` now bind bundled pure-Jac ports on the native (na) pathway. `signal` provides `signal`/`getsignal`/`raise_signal`/`alarm`/`pause`/`strsignal`/`valid_signals`/`pthread_sigmask`/`default_int_handler` and the Linux constant set, with user handlers dispatched through a C-ABI trampoline and `SIG_DFL`/`SIG_IGN` installed as real dispositions. `subprocess` provides `Popen`/`run`/`call`/`check_call`/`check_output`, `CompletedProcess`, `CalledProcessError`, `TimeoutExpired`, and `PIPE`/`STDOUT`/`DEVNULL`, driven by `posix_spawnp` with file actions and a `poll`-based `communicate` that drains stdout and stderr concurrently. Linux only; pinned sv<->na congruent by probe tests.
