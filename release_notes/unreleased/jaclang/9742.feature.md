- **Client: `lazy()` works with a one-line dynamic import**: `lazy(lambda () { return __import__("./Component"); })` now works without `fromlist` when the file's component is `:pub`, instead of crashing in the browser with React error #306. A dynamic import now gives back the module's live exports plus a default export set to the component named after the file, which is what React's `lazy` expects. `fromlist=["Other"]` still works, picks which export becomes the default, and also exports that component when it is not `:pub`.
