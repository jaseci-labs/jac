- **Client: `lazy()` works with a one-line dynamic import**: `lazy(lambda () { return __import__("./Component"); })` now works without `fromlist`, instead of crashing in the browser with React error #306. A dynamic import now gives back the module's exports plus a default export set to the component named after the file, which is what React's `lazy` expects. `fromlist=["Other"]` still works and picks which export becomes the default.
