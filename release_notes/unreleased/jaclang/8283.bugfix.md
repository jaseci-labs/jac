- **A class-level attribute read through `self` answers per class**: `self.CATEGORY` missed the instance layout and came back empty, and the argument path substitutes a default for anything that did not lower, so `_init_stub(self, sym_type=self.SYMBOL_TYPE)` passed enum ordinal 0 and every subclass claimed its base's symbol type. Each declaring class now gets its own constant and the read picks between them on the receiver's vtable; where the hierarchy agrees it stays a single load, and where the declaring base carries no value the fallback raises `AttributeError` rather than handing back a zero. A class-level name the emitter still cannot place refuses under E5092 naming the declaring class instead of defaulting in silence.
- **A keyword-argument key is an identifier, not a scope reference**: The declaration/implementation binder resolved every unbound name against the scope chain, guarding attribute names and nothing else, so a keyword key was handed the symbol of whatever local shared its spelling -- 41 such bindings in `elf_linker.jac` alone. The reachable damage was the capture set: a nested function whose only mention of an outer local was a keyword key captured it, giving the emitted function a capture parameter its body never reads. A shared `is_identifier_slot` predicate now covers keyword keys, attribute names and declaration names for the binder, the capture walk and the Python lane, which also stops a keyword key spelled like a runtime builtin from minting a module-level import.
