- **Breaking: The native compiler kernel is the only compiler.** Every compile, check, tool query and native build runs in the kernel, a JacPython native module (`jac_kernel`), and nothing falls back to compiling on the host. A missing or stale kernel is an error naming `jac native build kernel`; it is no longer silently replaced by a slower compiler. `jac native build kernel` starts from the previous release's kernel. `jac0.py`, the host pass pipeline and the self-hosting bytecode compiler are gone.
- **Breaking: What can be native is decided before lowering, in one place.** Native code is lowered through a typed mid-level IR that either gives each function a native representation or refuses it with a reason. Refusals spread to the functions that call or take the refused one, and the result is the unit's demoted set. The old "seam" demotions, which replaced a function body with a stub that aborted at run time, are gone. Where native is required (kernel units, AOT builds, `native_require`), any refusal is an error; elsewhere a refused function runs in Python. `jac check --native-coverage` reports the demoted set without generating code.
- **Breaking: Configuration is typed.** `jac.toml` loads into a typed schema, and unknown keys or malformed values in the core sections are now errors instead of being ignored. Plugin virtual modules are declared as data in the plugin's package metadata; a plugin that registered callables under `[jac.modules]` must declare them instead.
- **Breaking: The native kernel refuses demotions.** `jac native build kernel` requires every kernel unit to lower natively: a function that cannot lower is a build error with its reason. Every existing kernel is stale once and must be rebuilt. A native build session also stops re-lowering a module that already failed, so a failing dependency is reported once instead of once per importer.
- **Breaking: Tools talk to a kernel session.** The language server, studio, MCP, the formatter and the linter query an in-process kernel session that keeps the analysed project across edits, instead of holding their own compiler state.
