- **Breaking: The native kernel refuses demotions.** `jac native build kernel` now requires every kernel unit to lower natively: a function that cannot lower is a build error with its reason, where it used to be replaced by a stub that aborted if the kernel ever reached it. Every existing kernel is stale once and must be rebuilt. A native build session also stops re-lowering a module that already failed, so a failing dependency is reported once instead of being lowered again for every module that imports it.
