- **Scale: a PodDisruptionBudget that protects nothing is no longer emitted**: every service got `maxUnavailable: 1` while the HPA floor defaults to one replica, so the eviction API reported `desiredHealthy: 0` and a node drain or a consolidation could take a single-replica service fully down. The budget is now emitted only when it can actually hold a replica, `pdb.min_available` is available for services that must never go to zero, and `jac start --scale --dry-run` warns when a configured budget would permit evicting everything.
