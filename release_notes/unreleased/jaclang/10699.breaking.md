- **Breaking: JacPython is removed; jac ships a prebuilt CPython 3.14**: the `jac` binary now bundles a pinned python-build-standalone CPython 3.14 instead of JacPython, the CPython runtime rebuilt from Jac sources. The `jacpython` artifact, `jac native build jacpython`, and the `-Djacpython-host`, `-Djacpython-object`, `-Dreuse-python`, `-Dstale-python` and `-Dtarget-platform` build options are gone. `jac build --native` is unchanged and links the same C library archives, now taken from the prebuilt CPython.
