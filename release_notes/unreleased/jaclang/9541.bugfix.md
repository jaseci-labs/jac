- **Fix: Bare from-imported stdlib functions run natively**: A function imported by name from `random`, `os` or `struct` (`import from random { randint }`, then `randint(1, 6)`) now lowers on the native backend exactly like the qualified `random.randint(1, 6)`, instead of demoting its caller (and often its module) to the server codespace. Aliased imports work, and a local that shadows the imported name keeps its own meaning.
