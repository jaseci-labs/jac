- **Breaking: native code that cannot lower is a compile error, with no fallback to Python**: native "demotion" is removed. A native function, method, field or `test` block that the native backend cannot lower used to be quietly kept as Python under `jac run` (with a "native seam -- demoting" warning), and a module pinned or inferred native that failed to lower was silently recompiled for the server codespace. Both are now E5090/E5092 errors naming the construct and the reason, in `jac run`, `jac check` and `jac build --native` alike, which is how `jac build --native` already behaved. A native module pin or native app kind is now a declaration rather than a preference. To fix an affected project, make the construct lowerable (add types, avoid the unsupported feature) or move the code to the server codespace (remove the native pin, or pin the module `server`). `jac check --native-coverage` reports native and server modules only, and the `[check] warn_native_seams` setting is gone (an existing key is ignored). Calling server code from native code (`sv import`, interop bindings) is unchanged.
