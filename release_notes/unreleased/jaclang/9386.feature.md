- **Feature: native `array`, `binascii`, `mmap`, and expanded `struct`**: The na (native LLVM) pathway now bundles `array` (bytearray-backed, all integer/float typecodes, CPython-congruent `itemsize` attribute and `buffer_info()` address), `binascii` (hexlify/unhexlify, base64, quoted-printable, uuencode, crc32/crc_hqx), and `mmap` (anonymous and file-backed maps over per-OS FFI floors; `size()` answers the live file size and raises CPython's `OSError` on anonymous maps, `resize` matches CPython's readonly/shared rules, context-manager protocol), and the `struct` compiler intercept gains `? c s p e P` formats including software IEEE-754 half precision. All four are pinned congruent with CPython (including error-message text) by tri-backend equivalence fixtures.
- **Feature: unsafe raw-buffer intrinsics for bundled native modules**: `__bytes_data`/`__bytearray_data` expose a buffer's payload address and `__mem_load_i8|i16|i32|i64`/`__mem_store_*` give typed memory access, letting bundled Jac modules run inner loops as raw pointer ops. Access widths are carried as registry metadata, not parsed from intrinsic names. `array`, `binascii`, and `mmap` byte paths now beat their CPython equivalents in benchmarks.
