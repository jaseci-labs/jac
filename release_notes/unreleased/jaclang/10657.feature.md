- **`jac scale deploy` can reuse a seal built elsewhere**: Set `[scale] seal_cache` in `jac.toml` or `JAC_SEAL_CACHE` to a shared directory and a deploy looks there after the project cache, reuses a bundle sealed from the same inputs on another checkout or machine, and writes each fresh seal back to it, so CI and fresh checkouts skip the seal entirely. Unset, nothing changes.
