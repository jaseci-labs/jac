- **CI rebuilds JacPython when its native backend changes, and main reuses it otherwise**: the JacPython reuse key now also hashes `jaclang/compiler/backends/native` and `jaclang/runtime/na_stdlib`, so a pull request that changes how JacPython is lowered rebuilds it and fails on its own run instead of on main. Main pushes use the same key and skip the JacPython rebuild (about 10 minutes) when neither the lowered sources nor the backend changed. Scheduled and release builds keep the full key.
