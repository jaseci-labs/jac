- **Fix: the native compiler kernel's answer is final, so a backend crash or refusal never runs as Python** (#10339): a crash during native lowering is now `E9003`, a blocking internal compiler error, instead of an `E5092` refusal. A module that may not run keeps neither its bytecode nor the JCIR the kernel hands the host, so `import hashlib`, `hmac` and `secrets`, which crashed the kernel on `_digest.jac`'s SHA-512 constants and silently ran as Python, now lower natively. The host compiles a program itself only for host-only deferrals: a kernel `integer overflow` crash, or a kernel answer with no unit and no error (for a module, an application entry or a client artifact), is an error rather than a silent recompile. Integer literals are read by an overflow-free 64-bit parser, so `u64` literals past 2**63 and `-2**63` lower natively, and a native int literal that does not fit a signed 64-bit int (and is not typed `u64`) is refused instead of silently wrapping to its bit pattern.
