- Native codegen now lowers a lambda's parameter and return type to what the type evaluator actually inferred (e.g. `str` from a `Callable[[str], str]` call site) instead of silently defaulting to `i64` whenever the lambda carried no `: T` / `-> T` syntax. An untyped lambda's inferred type used to be laid out as `i64` in the emitted IR with no diagnostic, mis-typing anything wider than an integer at the call boundary.
