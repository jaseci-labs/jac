- **`jac test` finds a suite's package root on its own evidence**: a test file nested under a directory with no `__init__` (this repo's `tests/compiler/passes/`, `tests/cli/`, `tests/langserve/`) could not import from the package above the gap (`import from tests.support`), because the runner walked up only while every ancestor was a package and otherwise leaned on the nearest `jac.toml` to supply the right `sys.path` entry. It now also adds the parent of the *outermost* package any ancestor belongs to, so package-absolute imports resolve from where the packages actually are rather than from where a config file happens to sit.
