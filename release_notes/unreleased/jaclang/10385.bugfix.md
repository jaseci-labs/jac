- **Fix: The official image can run its bundled bun as its default user**: `fetch-bun` wrote bun without its executable bit, so every payload shipped it as 0644 and jac set the bit the first time it used bun. Only the file's owner can do that, so it worked from your own cache but not in the `jaseci/jaclang` image (0.37.0 and later), which extracts the runtime as root and runs as the `jac` user: `jac install` with npm dependencies and every client build in the image failed with "bun ... is unavailable: this image ships its floor". bun is now written executable when it is fetched, so the runtime arrives with bun ready to run for any user.
