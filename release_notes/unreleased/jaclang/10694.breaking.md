- **Breaking: the native compiler kernel is removed; the compiler runs as bytecode only**: jac no longer builds, seals or loads a native compiler library, so `jac native build kernel`, `jac native status kernel`, `jac check --kernel-parity`, `jac native build --stop-after` and the `-Dkernel` build option are gone. The compiler runs from its precompiled bytecode, as pull-request kits and the current release path already did. `jac build --native` for your own programs is unchanged.
