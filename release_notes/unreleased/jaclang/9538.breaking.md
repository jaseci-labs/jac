- **Breaking: arch.jac syntax and sealing model**: Wiring blocks are written `graph import [scope] { ... }`; `impl import` no longer parses. The `[arch]` table in `jac.toml` is removed and is now a load error: an `arch.jac` closes its directory by existing, so run `jac arch init --strip` where `[arch] closed` used to apply. A rule's patterns name modules under its arch.jac, so the `any` target is gone (`E0097`), and a provider no longer needs a rule before it may be imported. `E1140` is replaced by the `W2084` warning.
