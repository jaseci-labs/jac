- **Fix: the semver gate catches an added parameter that shifts positional arguments**: a new optional parameter inserted before an existing positional parameter, or placed ahead of `*args`, changes what an unchanged positional call binds (`f(7)` against `def f(b: int = 20, a: int = 10)` returns 10 where it returned 7), but the API diff called it a minor change, so `jac publish` and index verification accepted it as `1.4.0 -> 1.5.0`. Such an addition is now a major change. Trailing optional parameters, keyword-only parameters and a new `*args` are still minor.
