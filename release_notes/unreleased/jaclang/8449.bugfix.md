- **Large uploads through the Jac Scale gateway no longer balloon its memory**: a request body is now streamed to the service that handles it instead of being held whole in the gateway, so a 90 MiB upload leaves the gateway's memory flat where it previously added around 187 MiB for every upload in flight. An upload that never declares its length and then outgrows the body size limit is still refused with a 413, but the service now sees the start of it as a cut off body instead of never being contacted.
