- **Fix: native-only imports and tuple slices across the native seam**: an inferred-native module whose Python side names an import of a C-import-anchored or native-pinned module (a field default such as `has p: Prog = Prog()`) no longer loses that import, so Python callers stop hitting `NameError`; a native `struct.unpack` result stored in a `tuple[Any, ...]` slot is boxed element by element instead of bitcast (its `len` and slices were garbage or empty); and a native slice of a fixed tuple is refused instead of reading the range start as an index.
