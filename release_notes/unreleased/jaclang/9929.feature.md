- **Native: `set(range(...))` lowers**: `set` and `frozenset` over a range, a tuple or a dict of numbers lower natively by draining the iterable the way `list(...)` does. The native `set` constructor only knew bytes, lists and sets before, so `seen = set(range(1, n + 1))` was refused with E5092 and its function sent to Python. Operands that yield strings are still refused rather than lowered, because a set built this way would borrow its elements from a temporary list.
