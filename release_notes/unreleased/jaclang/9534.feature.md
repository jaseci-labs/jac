- **Feature: native `itertools` bundled module**: The native codespace gains `na_stdlib/itertools.jac`, a pure-Jac port of CPython 3.14's `itertools` (`count`, `cycle`, `repeat`, `accumulate` (custom `func` and `initial=`), `batched` (`strict=`), `chain` (+ `chain_from_iterable`), `combinations`, `combinations_with_replacement`, `compress`, `dropwhile`, `takewhile`, `filterfalse`, `groupby`, `islice` (arity-split argument forms with CPython's exact error text), `pairwise`, `permutations`, `product` (`repeat=`), `starmap`, `tee`, and `zip_longest` (`fillvalue=`)), so the same `import itertools` / `import from itertools { ... }` binds CPython on the sv backend and the bundled generators on na.
