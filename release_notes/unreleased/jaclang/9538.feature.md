- **Feature: scoped wires and import roots for arch.jac**: A wire's consumer may name a class, function or method (`pkg.mod.Class.method`), and the generated import lands at the top of that body, so lazy imports are declared in arch.jac and stay lazy; `E2094` now asks for the scoped wire. `[arch] roots` in `jac.toml` names modules by their import path for `src/` layouts and packages under a subdirectory. `jac arch init --strip` now works on a whole package: stdlib, native-stdlib and self imports stay written, jac0 seed modules keep their imports, rules admit importers outside the sealed package with `any`, and arch.jac is written atomically. The payload ships arch.jac so a stripped package recompiles from shipped source. The jaclang package itself is now sealed with arch.jac.
