- **Dev loop: a compiler edit rebuilds the modules it touched, not the whole compiler**: in a source checkout, a compiler module whose own source, compile-time dependencies and Python emitter are unchanged keeps the bytecode an earlier compiler build emitted for it, so `jac run` after a one-line compiler edit takes 1.5 s instead of 119 s. A checkout that builds the native kernel itself gets the same per-unit rule: kernel units are stamped with the kernel's ABI (`NATIVE_ABI_VERSION` and the ABI contract files) instead of the compiler that lowered them, so an edit rebuilds the units whose source or dependencies' interfaces changed, and an edit outside the kernel's units leaves the linked kernel accepted. User programs and test fixtures are always compiled by the compiler as edited, kit builds and CI stay exact, and `JAC_DEV_EXACT=1` rebuilds the compiler's modules and kernel units too.
