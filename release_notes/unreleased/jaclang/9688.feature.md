- **Dev loop: a compiler edit recompiles the modules it touched, not the whole compiler**: in a source checkout, a compiler module whose own source, compile-time dependencies and Python emitter are unchanged keeps the bytecode an earlier compiler build emitted for it, so `jac run` after a one-line compiler edit takes 1.5 s instead of 119 s. User programs and test fixtures are always compiled by the compiler as edited, kit builds and CI stay exact, and `JAC_DEV_EXACT=1` recompiles the compiler's modules too.
