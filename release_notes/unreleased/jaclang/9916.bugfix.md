- **Fix: `SidebarProvider` keeps a `style` passed to it**: The jac-shadcn `SidebarProvider` applied only its two width variables, so a caller's `style` was either dropped or, before the `className` fix, replaced the widths. The caller's style is now merged after the defaults: custom properties reach the wrapper and `--sidebar-width` can be overridden. To bring this or the earlier `className` fix into a component a project already has, remove it and install it again (`jac remove --shadcn <name>`, then `jac install --shadcn <name>`); installing over an existing component changes nothing. Removing deletes the project's copy, so save any local edits to it first and reapply them afterwards.
