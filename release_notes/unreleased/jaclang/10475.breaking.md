- **Breaking: inline Python (`::py::`) is removed from the language**: `::py:: ... ::py::` blocks no longer exist. The lexer does not recognize the fence, the grammar has no inline-Python element, and the `PyInlineCode` node, its formatter, unparser, Python, ES and native handling, and its placement and native-capability evidence are gone, so a file that still contains a block fails to parse. `E0103` (unterminated inline Python block) is retired. Move the Python into a `.py` module next to the `.jac` sources and import it; an enum that needs Python methods is defined in that module.
