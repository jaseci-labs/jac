- **Fix: A bare name in a method body does not see its class's members**: Inside a method, a bare name now resolves the way Python resolves it at run time (local, enclosing function, module, builtins), so a method named like a module function no longer shadows it, and a bare reference to a sibling member is reported (W2001 with a `self.<name>` hint) instead of passing the checker and failing with `NameError`.
