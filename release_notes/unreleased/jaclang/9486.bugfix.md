- **Fix: an event ability named `drop` is no longer treated as a destructor hook**: `drop` is an ordinary identifier, but both backends recognised a destructor hook by name alone. A walker with `can drop with Bomb entry` made the native pass emit a one-argument call to the `(self, here)` event method from the walker's release function, which failed and sent the whole module to Python with no root diagnostic, demoting every function in it. On the Python backend the walker was instrumented for region drops and `drop()` was called without `here`, raising `TypeError` from `__del__`, a region close, or `del`. Only a `def drop` is a destructor hook now, and an event ability named `drop` shadows an inherited one.
