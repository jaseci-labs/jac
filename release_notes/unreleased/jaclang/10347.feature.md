- **Desktop: local profiles instead of sign-in**: `[desktop] profiles = true` lets the user of an app running on its embedded server keep named profiles, like save slots, instead of signing in. Each profile is its own passwordless user and root, and the page boots signed in as the active one. Manage them with `profiles` from `@jac/desktop` (`list()`, `current()`, `create(name)`, `use(id)`, `leave()`).
