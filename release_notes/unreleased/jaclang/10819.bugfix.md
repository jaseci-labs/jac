- **Fix: two imports of one name in the same scope are reported**: `jac check` used to accept `import from os.path { join }` and `import from shlex { join }` in one scope, then check calls against the first while the program ran the second. They are now E2036, in a module with its impl files, a function, an impl body or a test, including imports inside `with entry`. Repeating the same import is still fine, and so are alternatives in `if`/`else` arms or a `try`/`except` fallback.
