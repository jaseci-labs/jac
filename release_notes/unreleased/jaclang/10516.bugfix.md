- **Fix: JacPython builds and runs on macOS**: Its locks used POSIX semaphore calls macOS does not support, so the macOS binary could not link. They now use a mutex and condition variable there, as CPython does.
- **Fix: `jac build --native` no longer needs Homebrew on macOS**: The LLVM shim loaded Homebrew's zstd, so native builds failed with `Library not loaded: /opt/homebrew/opt/zstd/lib/libzstd.1.dylib` on any Mac without it. zstd is now built into the shim.
