- **Fix: Detach WebAssembly memory views on growth**: Memory growth now notifies the JavaScript Memory layer to detach old buffers and views before the backing store is freed, including Wasm-side growth and callbacks reached during the same Wasm call. Failed growth leaves the current buffer attached.
- **Fix: Use the observable `unicode` property in a global `String.prototype.replace`**: AdvanceStringIndex now reads `RegExp.prototype.unicode` instead of the internal `u` flag, and the subject conversion cache is restored after that getter runs re-entrant regexp code. The cache is also keyed on the collection counter, so a swept heap-string id can never hit a stale conversion.
