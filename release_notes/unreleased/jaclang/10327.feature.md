- **Performance: the default `managed` profile inlines the refcount fast path too**: #10226 inlined retain and the plain decrement under `[memory] profile = "rc"` only. Under the default `managed` profile (refcounting plus the cycle collector), every retain and every release was still a call into the out-of-line helpers. Retain and release are now inlined under every refcounting profile. A release of an object that can form a cycle checks inline whether the object has to become a candidate cycle root, and calls out only when it does; acyclic types skip that check. Only a release that drops the last reference, or one that runs after threads have started, calls the out-of-line release. Under `managed`, a loop that retains and releases a list element each step runs 44% fewer instructions per step (46% when the element's type can form cycles).
