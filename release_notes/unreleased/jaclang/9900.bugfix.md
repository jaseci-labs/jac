- **Fix: `jac run --dev` hot-reloads a workspace app's shared modules**: The dev server watched only the directory of the entry file, so in a workspace, where an app's entry sits in its own directory and the modules it imports live in sibling directories, edits to those modules were not picked up until a restart (the banner showed `Monitoring: **/*.jac (4 files)` for an application of dozens). The watcher now covers every top-level directory under the application root that holds a module the application loaded, and the banner counts the files it watches.
