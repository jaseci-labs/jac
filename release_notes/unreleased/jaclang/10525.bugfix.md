- **Fix: `jac run` of a `.py` file keeps its future flags**: The entry compile inherited `CO_FUTURE_ANNOTATIONS` from Jac frames, so the file got string annotations, eager `__annotations__` dicts and no class `__annotate__`/`__classdict__` machinery instead of Python 3.14's deferred-evaluation behavior.
