- **Breaking: JacPython is the only Python.** `jac` and JacPython build only from JacPython: `zig build` bundles JacPython, and the `-Dpython` option, `-Djacpython-host=stock` and the stock CPython build (its configure and make in `bootstrap/python/build.sh`, `build-graph.patch` and `host-graph.patch`) are gone. A build runs on the previous JacPython output for the machine, a JacPython named with `-Djacpython-host=<path>` (an output, its install prefix or a seed tarball), or the seed pinned under `"jacpython-seed"` in `bootstrap/python/sources.json`, fetched by URL and checked against its sha256. `zig build jacpython-seed-pack` packs a finished output as a seed. A build that adopts a native object lowered elsewhere (`-Djacpython-object=DIR`) for its own platform needs no seed: it runs Python only on the interpreter it builds. `build.sh` keeps only the third-party libraries' recipe, which every build now runs into `.python-build/jacpython/<platform>.vendored` and reuses while its key holds. The CPython source archive stays pinned in `sources.json` as the source of the standard library, the tests and a few install files, and JacPython keeps CPython's ABI identity (`sys.implementation.name`, the `cpython-314` SOABI, cp314 wheel tags). `jac native build jacpython` runs `zig build` into `zig-out/bin/jac`, and `jac update --self` updates a JacPython install.
