- **Serve: a raw-body function returns its own response**: A function declared with `@restspec(envelope=False)` can return a `Response` or `RedirectResponse` from `jaclang.server.serving.datatypes` to choose its status, headers and media type per request, a `(body, media_type)` pair for the common case, or a `FileResponse`, which is served with Range support. A plain body still uses `produces`. A raw-body function that already returned a `(body, str)` tuple now sends that body with that media type instead of a JSON list.
