- **Feature: Jobs run as the root that queued them**: a job queued with `jaclang.scale.jobs.enqueue` now runs as the queueing user's root, so `root` and ownership checks inside the job match that user, and it commits together with the walker that queued it. `as_root` may name only the caller's own root from a user's request; system code may name any root. Targets listed in `[scale.jobs] system_targets` always run as the system user, and a job whose root no longer exists is `dead` on its first attempt.
