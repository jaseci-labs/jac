- **Fix: a relative import that climbs above the project root is E1134**: `import from ...outside_zz { of }` in `proj/feat/beyond.jac` climbed above `proj/` and found `outside_zz.jac` there, so `jac check` passed while `jac run` failed with `attempted relative import beyond top-level package`. Inside a project, the dots of a relative import now stop at the outermost folder holding a `jac.toml`, so the import is reported as E1134, while a nested project can still reach its enclosing one. A module outside any project climbs as before.
