- **Fix: a `**` argument runs in source order when a class value builds an object natively**: in native code, `kind(**options(), y=next_y())` with `kind: type[Point]` ran `next_y()` before `options()`, and a later argument that changed the dictionary changed the values passed. Arguments now run left to right, the dictionary's entries are read at its place in the call, and a `TypeError` from the dictionary (a key given twice or an unexpected key) is raised only after every argument has run, as in Python.
