- **Fix: a module with a `comptime import` loads when it is placed native**: loading it failed with `LinkPlanError: ... is not a native unit for this codegen identity, or failed to lower (no diagnostic was recorded)`, naming the comptime-imported module. Native lowering walked a comptime import as a runtime import and recorded its target as a native link dependency, so the link plan demanded native code from a module that only exists at compile time. A comptime import, like a type-only import, is now never a native link dependency.
