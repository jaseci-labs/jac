- **Breaking: CORS credentials are a `[serve]` setting, off by default, and never paired with a wildcard origin**: the server always sent `Access-Control-Allow-Credentials: true`, so a default app paired it with `Access-Control-Allow-Origin: *`, which browsers reject. `[serve] cors_credentials` (`JAC_SERVE_CORS_CREDENTIALS`) now controls it and defaults to `false`. An app that lists its origins in `cors_origins` and relies on cookies from a front end on another origin, such as the session cookie from a sibling subdomain, must set `cors_credentials = true`. With `"*"` in `cors_origins`, `cors_credentials = true` stops the server with an error naming both keys, and `[scale.gateway.cors]` refuses `allow_credentials = true` with `"*"` in `allow_origins` the same way.
