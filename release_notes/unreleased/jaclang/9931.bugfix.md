- **Fix: native lists with the same contents compare equal whatever their element storage**: List equality only compared two lists of one native list type; any other pair fell through to comparing the list pointers, so `list(struct.unpack("<3H", data)) == [1, 2, 3]` (tagged values against plain ints) and a `list[int]` against a `list[float]` were always unequal, with no diagnostic. `==` and `!=` now compare such lists by length and then element by element.
