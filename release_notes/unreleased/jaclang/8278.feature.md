- **The type system's keystone links, and its lower half joins every sealed artifact**: `ClassVar` was the one thing keeping `types.jac` -- the module that defines `ClassType`, and the keystone every other type-system module carries in its fields and signatures -- out of a native unit: the native lane already erases the annotation, but `scan_native_blockers` read `import from typing { ClassVar }` as a non-native import, so no consumer could link it and `unitree`'s `TypeBase`-typed fields were a layout dependency on a module no unit could contain. It joins the compile-time import vocabulary in a frozenset of its own, so a module-scope `glob X: ClassVar = ...` still lowers as a native glob. Every sealed artifact now carries the type system's lower half plus the leaves it reaches, `NATIVE_SEAL_CLOSURE` and the waiver tables grow by them, and every one of the eleven roots seals with its seam set exactly equal to its waiver set. Two things the expansion surfaced are fixed with it: the materializer generator emitted list elements it had no emitter for through the node chain (`Ability.event_triggers` is `list[TypeBase]`, and the generated root then refused to compile), and it now erases such a field the way it already erased an unmaterializable dict key; and the sealed-seam reachability walk now stops at a waived name instead of walking through it, since what ships for one is an `abort()` stub the process never returns from.
