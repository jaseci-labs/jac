- **Breaking: The graph view pages its neighbors instead of dumping the graph**: `GET /graph/data`, which walked and serialized everything reachable from the caller's root in one response, is removed, along with `/admin/graph` and the gateway's merge of every service's dump. `/graph` is now a lazy explorer over two bounded, access-checked endpoints: `GET /graph/node?id=` (type, a truncated field summary and neighbor counts per node and edge type) and `GET /graph/neighbors?id=&dir=&type=&edge=&limit=&cursor=` (one page of neighbors with their edges and the next cursor). The gateway routes both to the service that can read the node. The viewer renders labels as text (a node's field values could inject HTML into the old tooltip), reads the type from the response instead of parsing `repr`, caps the canvas at 1500 nodes, and pins `vis-network` to 9.1.9. `printgraph(format="json")` now follows the same bounded walk as the other formats (`nd`, `depth`, `node_limit`, `edge_limit`) and identifies nodes by their id instead of a Python object address.
