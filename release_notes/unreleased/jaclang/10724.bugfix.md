- **Fix: a deploy keeps its client build and seal for apps with npm dependencies**: `jac.lock` is now keyed without its `[npm] bun_lock` digest, which every `jac install` (the build stage's own included) rewrote from a fresh bun resolution. An unchanged project with npm dependencies now keeps and reuses its client build and its sealed bundle, and its seal key no longer changes between runs of the same commit. The PyPI pins and declared inputs in `jac.lock` still invalidate the caches. Caches of projects with a `jac.lock` are rebuilt once after upgrading.
