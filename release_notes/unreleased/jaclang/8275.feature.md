- **Build: the native seal reuses artifacts whose whole input set is unchanged**: Sealing the AOT compiler artifacts used to wipe the output tree and rebuild every native root unconditionally, costing minutes of LLVM per root even when nothing had moved. Each artifact now records an input key beside it: the key is the source closure it was built from, and the compiler digest, the target triple and the root's demotion waiver table gate whether that key may be trusted. A root whose key, gate and on-disk sha256 all hold is served without a compile or a link, and anything the seal cannot prove is a rebuild, so a touched file rebuilds exactly the roots whose closure contains it. Load and parse-parity canaries still run against reused artifacts; `--seal-skip-reused-canary` turns that off for the tightest dev loop, and `JAC_REBUILD` disables reuse entirely.
