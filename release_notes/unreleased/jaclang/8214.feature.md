- **Native: `isinstance` covers builtin containers, container ABCs, and type arms passed as values**: A native `isinstance` used to answer only through a JacVal tag compare, so it refused the whole call if any arm fell outside that. `tuple`, `bytes` and `bytearray` arms now settle from the operand's static type (which is what makes `isinstance(x, (list, tuple))` lower rather than demote the enclosing method), `collections.abc` container classes such as `Sequence` and `Mapping` reduce to the native shapes that inhabit them, and `isinstance(x, types)` with `types` a parameter compares against each arm it carries. Protocol-shaped ABCs (`Iterable`, `Sized`, `Callable`, ...) refuse with a diagnostic instead of guessing, since an archetype can inhabit those without naming them.
- **Native: `tuple[T, ...]` annotations lower**: A variadic tuple withholds its arity and a native tuple carries arity in its type, so such an annotation now lowers to the same native sequence `list[T]` uses, and a tuple value passed where one is expected converts to it.
