- **Fix: `[*.http_activation]` works on a target of 37 to 45 characters**: KEDA names a ScaledObject's HPA `keda-hpa-<ScaledObject>` and its admission webhook refuses a name over 63 characters, so the ScaledObject create failed with a 403 for these targets, including any app whose name is 26 to 34 characters. jac-scale now sets a shorter HPA name in that case. A name that fits is left to KEDA, so no existing HPA is renamed.
