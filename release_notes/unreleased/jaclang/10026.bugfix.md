- **Fix (security): `/static/` no longer serves files outside the directories it is meant to serve**: on a built project, an unauthenticated `GET /static/../jac.toml`, or the same with the slashes percent-encoded, returned any file in the project tree, including the JWT signing secret in `.jac/data/jwt_secret`. A static request is now contained by the directory it is joined onto, and a path with a `..` segment is refused. Deployments that ran a built project on an affected version should rotate the JWT signing secret after upgrading, since the fix cannot undo a disclosure.
