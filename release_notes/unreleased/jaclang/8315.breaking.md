- **Breaking: a keyword is never an identifier -- the backtick escape is now required, and stray backticks are an error**: Jac keywords were accepted as bare identifiers in most binding positions and rejected in others, with four different behaviours depending on where the name appeared. `has skip: int`, `glob by = ...`, `obj match { }`, `enum test { }` and `for skip in xs` all compiled silently; `def f(skip: int)` reported `E0013`; `skip = 1;` produced three cascading syntax errors (`E0002` "Missing ';'", `E0004` "Unexpected token '='", `E0002`) that never mentioned the word "keyword"; and `root = 1;` reported `E0024`. The rule is now uniform: a keyword token is never an identifier, and `` ` `` is the only way to use one as a name. Every binding position -- archetype, ability, enum, global, field, and parameter -- reports a single `E0013` naming the keyword and suggesting the escape, so `has skip: int` becomes ``has `skip: int``. Two token classes are exempt because they are not identifiers competing with keywords: the eight special references (`self`, `super`, `root`, `here`, `visitor`, `props`, `init`, `postinit`), so `def init` and `def postinit` are unchanged; and the builtin type names (`int`, `str`, `list`, `type`, `i8` ... `f64`), so `has type: int` and `i32 = compute()` still compile. The escape stays legal on both, which is why the 865 existing spellings such as `` `list `` and `` `bytes `` are untouched. The rule does apply to member access: `x.test` and `x.match` now need `` x.`test `` and `` x.`match ``, since an attribute name is an identifier like any other. The escape is now also checked in the other direction: a backtick on a name that is not a keyword is `E0014` ("'{name}' is not a keyword -- remove the backtick"), so stray tick marks fail loudly instead of silently parsing as an ordinary name. `E0067` is unchanged and still fires for Python reserved words such as `pass`, `nonlocal` and `global`, which are not Jac keywords and cannot be rescued by an escape because the lowered code uses the name as a real identifier.
