- **Native brand binding has one driver-owned point**: Binding the materializer registers class identities, so when it happens is observable to the type checker and a binder reached at a new point could leave two brands of the same class in play. `ensure_native_brands_bound` is now the only function that reaches the binder, and `JacCompiler`'s constructor calls it, so a compiler cannot exist without class brands bound, no route can bind lazily from inside a predicate or entry, and every consumer records why it asked. Closes the E1053 binder-ordering bug class structurally.
