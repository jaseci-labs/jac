- **Sealed builds serve native parse trees, with the invariant enforced at startup** (#8139 Steps 1-2): a jaclang image's manifest now records which native roots the build sealed, and the runtime refuses to load an image that cannot serve them on this host -- a missing, corrupt, or wrong-platform artifact is a named startup error, never a silent downgrade to the bytecode tier. Wherever an artifact exists, `parse()` and `parse_diags()` serve through the sealed native parser's materializer crossings: one GIL-held native call parses and rebuilds the tree (plus its diagnostics and comments) as fully Python-owned objects, measured 2-4x over the bytecode parser on compiler sources, with the runtime correctness canary relocated to seal time where a divergent artifact fails the build. `JAC_NATIVE_PARSE_TREES`, `JAC_NO_SEAL`, and `JAC_SEAL_NO_NATIVE` are retired (the build tier is "no manifest", by construction), the zero-copy view marshalling layer is deleted outright, and the standalone lexer artifact folds into the parser root.
