- **Fix: a `jaclang` PyPI package in the project venv no longer breaks every jac command**: the boot finder keeps the toolchain's own `jaclang` ahead of a venv copy and says it is ignoring it, and `jac install` refuses `jaclang` as a declared PyPI dependency. Before, every command in such a project died with `No module named 'jaclang.jac0core.handoff'`.
