- **Breaking: the admin portal is now disabled by default and never ships a default password**: every deployment previously served `/admin` and provisioned an `admin` / `changeme` account on first boot, and the forced password reset that was supposed to contain it was only enforced in the browser, so the login token worked on every admin API. `[scale.admin] enabled` now defaults to `false`, `default_password` has no default, is required to provision the account, and refuses the historical placeholder `changeme`, and a token for an account with a pending reset is rejected server-side everywhere except `/admin/reset-password`. Deployments that use the portal must set `[scale.admin] enabled = true` plus `default_password`, or the new `JAC_ADMIN_ENABLED` and `JAC_ADMIN_PASSWORD` environment variables, which let the credential be injected at deploy time instead of committed to `jac.toml`.
