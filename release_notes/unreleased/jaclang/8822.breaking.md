- **Breaking: the admin portal is off by default and a bootstrap admin needs one password rotation**: setting `[scale.admin] default_password` or `JAC_ADMIN_PASSWORD` turns `/admin` on, and `enabled = true` without one bootstraps `changeme`. Until its password is rotated, a bootstrap admin, including one from an earlier release, has no admin access on `/admin`, `/jobs` or `/metrics`. With the portal off, an admin still on `changeme` has that password revoked at startup.
