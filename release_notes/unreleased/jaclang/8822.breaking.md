- **Breaking: the admin portal is disabled by default and ships no default password**: `[scale.admin] enabled` defaults to `false`, `default_password` has no default and refuses `changeme`, and a token with a pending password reset is rejected everywhere except `/admin/reset-password`. To serve the portal, set `[scale.admin] enabled = true` plus `default_password`, or `JAC_ADMIN_ENABLED` and `JAC_ADMIN_PASSWORD`. An `admin` bootstrapped by an earlier release gets 403 on every admin route until it rotates its password once.
