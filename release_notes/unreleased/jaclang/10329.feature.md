- **Performance: native locals that only name what something else keeps alive skip reference counting**: under `managed` and `rc`, a local such as `b = bodies[i]` or `n = n.next`, or the variable of `for p in particles`, took a reference when it was bound and released it when it was rebound and at scope exit. The compiler now infers when such a local is a borrow, the same as a declared `&` borrow, and binds it without counting. That needs two things: every value the local is bound to is a field or list element reached from a parameter, `self`, another borrow or a local bound once, and nothing in the function can release what the local names (no store on that path, no `pop` or `clear`, no call or operator the compiler cannot see into). binary-trees under `managed` runs in 1.73 s instead of 4.87 s, nbody in 0.25 s instead of 0.50 s, and a linked-list walk runs 92% fewer instructions per node.
