- **Fix: `jac test <file>` runs that file's tests, not its dependencies' too**: every module's `test` blocks register themselves when the module is imported, and the runner then ran every block in the registry rather than the entry belonging to the file it was asked to run. A suite that imported a shared module therefore ran that module's tests as well, reported them under the importing file's path, and re-ran them once per dependent across a suite: on a 148-file application that was 8,777 executions for 2,061 declared tests, and a failure in a shared module was attributed to whichever file happened to import it. A run now executes the blocks the named file owns, and a dependency's tests run under the dependency's own file, which discovery already collects in its own right.
