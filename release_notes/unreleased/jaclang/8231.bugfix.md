- **Fix: a broken compiler source no longer degrades silently**: When a file in the compiler's own sources fails to parse, the pass schedule now fails loudly, naming the file and its diagnostics, instead of falling back to a bytecode-only schedule that silently drops the ECMAScript and native backends from every compile. Genuine absence still degrades as before: a pass module missing from a partial build, a partially initialized module during the self-host bootstrap, or an optional backend a build does not ship.
