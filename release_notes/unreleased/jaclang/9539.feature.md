- **Bundled native stdlib gains `stat`, `glob`, `platform`, and `errno`**: Four more CPython-congruent modules land in `na_stdlib`, so the same `import stat` / `import glob` / `import platform` / `import errno` binds CPython on the Python backend and the bundled pure-Jac module on the native backend. `stat` is pure Jac (constants, `S_IS*` predicates, `filemode`); `glob` ports CPython's `_iglob`/`_glob*` walk over the bundled `fnmatch` and a tiny `lstat`/`readdir` FFI floor; `platform` answers `system`/`node`/`release`/`version`/`machine`/`processor`, `uname`, `architecture`, `libc_ver`, `platform`, and the `python_version` pair over a per-OS `uname(2)`/`popen`/`gnu_get_libc_version`/`sw_vers` floor; and `errno` ships per-OS constant tables plus `errorcode` (`errno.linux.jac` / `errno.darwin.jac`, picked by the resolver's `<name>.<os>.jac` probe). Each surface is pinned sv<->na congruent by `prim_*` equivalence fixtures; scope and divergences are documented in `na_stdlib/README.md`.
