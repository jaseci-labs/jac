- **Fix: Clearer diagnostic for bare tuple loop targets**: `for n, c in items` now reports "tuple targets must be parenthesized" with a help line showing the correct form (`for (n, c) in items { ... }`) instead of the confusing "Expected 'in', got ','". Applies to both `for` statements and comprehensions. Error recovery for these targets also stops at `=`, `{`, `;`, and `}` instead of consuming the rest of the file, so a bare tuple target in a numeric `for` loop no longer swallows everything after it.
