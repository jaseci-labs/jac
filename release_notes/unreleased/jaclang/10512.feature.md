- **CI: the native kernel seal moves to the merge queue**: A pull request's kit no longer seals the native compiler kernel because the change touches the compiler; the merge queue's run does, so nothing reaches main unsealed, and a pull request pays the seal once instead of on every push. The `native:kernel` label still asks for it on a pull request. The js-engine lane builds on the run's kit (binary, precompile bundle, JacPython runtime and LLVM shim) instead of building them again, and on a pull request runs for engine changes only.
