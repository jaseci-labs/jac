- **Fix: `jac run --platform web` on a mobile app serves a page that loads**: Running a `kind = "mobile"` app with `--platform web` (the way to open its UI in a browser) started the dev server without compiling the app's client, so the page failed with `Failed to resolve import "/<app>/compiled/_entry.js"`. The serve path now prepares the client for a mobile app whose platform is web, as it does for a web app.
