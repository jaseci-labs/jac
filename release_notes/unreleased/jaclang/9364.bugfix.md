- **Fix: `jac scale deploy` no longer ships a `${...}` form jac does not read** (#9184): jac reads `${VAR}`, `${VAR:-default}` and `${VAR:?message}`, but other shell forms such as `${VAR:+alt}`, `${VAR:0:3}`, `${VAR-default}` and `${VAR?msg}` were passed over in silence, so the deploy wrote them into a Secret or a target setting as literal text and exited clean. The deploy now stops on them, naming the setting and the forms to use instead, even when the variable is set, because the literal would reach the cluster either way. Shell syntax in `[scripts]`, and a positional such as `${1}`, is left for the shell to expand.
