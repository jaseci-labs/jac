- **Fix: a call keeps every overload of a function reached through a star import**: an `@overload`-ed function reached through `include` or a stub's `from x import *` lost its last overload and listed its first one twice, so a call only the last accepts failed with E1054. Overloads are now gathered from the definition scope in declared order. This also fixes `basename("x")` from `os.path` when the stub catalog is not in use.
