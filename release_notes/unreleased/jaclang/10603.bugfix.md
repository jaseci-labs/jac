- **Fix: An omitted function argument keeps its declared value and type**: A served function called without an optional argument received the text of its default, so `flag: bool = False` ran with the truthy string `"False"`, `count: int = 5` got `"5"`, and appending to a `tags: list[str] = []` default answered 500. It now receives the declared value, as walkers already did. `GET /function/{name}` and `/openapi.json` report these defaults with their real types too, and the startup banner no longer drops falsy defaults.
