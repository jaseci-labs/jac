- **Fix: An omitted function argument keeps its declared value and type**: A served function called without an optional argument received the text of its default, so `flag: bool = False` ran with the truthy string `"False"`, `count: int = 5` got `"5"`, and appending to a `tags: list[str] = []` default answered 500. It now receives the declared value, as walkers already did. `GET /function/{name}` and `/openapi.json` report these defaults with their real types too, and the startup banner shows every default, using its repr.
- **Fix: A JSON response is always valid JSON**: A dict with a key JSON can't represent, such as a tuple, dropped the connection with no response, so one such default on a walker took down `/openapi.json` for the whole app. `NaN` and `Infinity` were sent as bare values that browsers can't parse. Those keys and values are now sent as strings, so a response containing `float("inf")` carries `"inf"`.
- **Fix: A default is copied for every request**: A served walker or function that changed an object default, such as `box: Box = Box()`, changed it for later requests. Every default is now copied per request, not only `dict`, `list` and `set`.
