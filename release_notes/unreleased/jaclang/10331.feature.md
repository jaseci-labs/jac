- **Performance: native code that never raises pays less for exception support, and allocations skip two lookups**:
  - **Context lookup.** Every function that owns a reference, and every `try`, called the out-of-line exception-context lookup. While the program is single-threaded, that lookup is now inlined.
  - **Region lookups.** Until some thread enters a region, a `try` no longer asks for the thread's region depth, and an object allocation no longer asks for the current region.
  - **Unwind records.** A function that holds a reference only across its own `raise` statements and checks, such as Richards' `find_tcb`, no longer links an unwind record. It releases its locals at those raises instead.
  - **Alloc ids.** Release builds stop numbering every allocation, since only debug builds read those numbers.

  A loop that calls such a function runs 23–32% fewer instructions per call, allocating and dropping an object runs 12% fewer, Richards runs 6–9% fewer, and binary-trees under `rc` runs 9% fewer.
