- **Fix: a second embedded desktop boot in one process finds its own Postgres**: The artifact router cached the `postgres` resolution per process, but the desktop host moves `JAC_PG_HOME` / `JAC_PG_DIST` to each app's data dir. A later boot therefore reused the first app's distribution and failed with `.../bin/initdb: No such file or directory` once that dir was gone. Entering or leaving an app's embedded store now drops the cached resolution.
