- **Breaking: Jac no longer builds Python wheels.** `jac build --as wheel`, its sdist and PEP 517 build backend, `--allow-drop-client`, `kind = "py-package"` and `[project.include.data]` are removed. Share Jac libraries with `jac publish`, reach JavaScript with `jac build --as npm`, reach other languages with `native-lib`, and give a Python project editable source with `jac build --as source`. A project with `kind = "py-package"` now stops with an unknown-kind error, so drop the `kind` or move to a `jac publish` library. Using PyPI packages is unchanged: `[dependencies.pypi]`, `jac install --pypi`, `jac build --fat` and `jac install -e` all work as before. See [Breaking Changes](../breaking-changes.md).
