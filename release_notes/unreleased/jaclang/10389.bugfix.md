- **Observability no longer lifts the Pod Security sandbox it does not need**: Turning on monitoring, logs or tracing used to relabel the app's namespace to Pod Security `enforce=privileged` for good, including the `default` namespace. Now only node-exporter (Kubernetes metrics) and log collection, the two components that mount host paths, request it. Tracing alone keeps the namespace at `baseline`. Switching Kubernetes metrics or logs off removes the node-exporter or Alloy DaemonSet on the next deploy, and a `privileged` level jac-scale set is then restored to `baseline` once nothing needs host access, and `default` is never relabelled.
