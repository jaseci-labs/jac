- **jac-scale: `initial_cooldown_period` for HTTP activation**: `[scale.kubernetes.http_activation]` and `[apps.<name>.scale.http_activation]` take `initial_cooldown_period`, set as `initialCooldownPeriod` on the target's ScaledObject. A new target has served no request yet, so without it KEDA scales the target to `min_replicas` as soon as it is created. The metric autoscaler already offers this as `autoscaler_initial_cooldown`. Unset or `0` leaves the ScaledObject as before.
