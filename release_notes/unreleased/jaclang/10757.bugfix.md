- **Fix: a client-pinned function pulls the imports it uses into the client**: with `[placement.pins] "main.app" = "client"`, the import `app` used stayed on the server, so `jac check` passed and the client build failed with `E5101`. What a pinned client element references is now pulled into the client; its callers stay where they are. Calls through two aliases of the same server function are now typed by each alias's own import, so only the client alias is an un-awaited RPC stub.
