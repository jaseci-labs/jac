- **Fix: a client-pinned function pulls the imports it uses into the client**: with `[placement.pins] "main.app" = "client"`, the import `app` used stayed on the server, so `jac check` passed and the client build failed with `E5101`. What a pinned (or dual) client element uses is now pulled into the client and keeps its server copy (an import keeps one only when server code in the module reads it), and never drags the server functions that share it. Calls through two aliases of the same server function are now typed by each alias's own import, so only the client alias is an un-awaited RPC stub.
