- **Fix: assigning several client state fields at once**: in a client component, a tuple, list, star or chained assignment to `has` fields, such as `(a, b) = (b + 1, a + 1)` or `a = b = 0`, threw `ReferenceError` when it ran because the fields were written as undeclared variables. Each field is now updated through its state setter, and every value is read before any field changes, so a swap works as in Python.
