- **Fix: the jaclang.org docs no longer get stuck on "The docs graph is still growing"**: the site's docs sync tick recorded when to check again before its writes were committed. When the tick lost a serialization conflict and the request loop re-ran it, the re-run saw that record, skipped the import, and committed nothing, so the docs stayed missing until the next recheck. The tick now records it with `on_commit`, so only a committed import holds off the next one.
