- **Fix: a kernel artifact store no longer rewrites bytes already at its key**: `store_unit_artifact` wrote unconditionally, even though the path it writes is content-keyed, so a rebuild that reproduced the same bytes still moved the artifact's mtime. Concurrent test workers sharing one cache directory rewrote each other's kernel IR and JS artifacts that way, which surfaced as an intermittent `test_kernel_units` failure claiming the warm read had not engaged. A store whose bytes are already at the key now leaves the file alone; bytes that differ still land.
