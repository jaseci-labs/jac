- The compiler front end moves to a flat syntax arena: the parser emits the concrete syntax tree as index-linked integer pools instead of a mutable object graph, compiles fully natively (zero seam demotions), and ships as a sealed artifact alongside the lexer, with full compiles riding it at 1.5-1.9x over the bytecode path. `jac check --parse_only` is now truly syntax-only and the language server publishes parse errors immediately on change, 13-16x faster than a full parse; a new `jac gen-unitree` generator derives the arena builder surface from the unitree constructors with a `--verify` CI drift gate. Native backend fixes along the way: Mach-O inline relocation addends and zerofill/common-symbol merging, optional-list `extend`, multi-member union lowering, and runtime `.value`/`.name` on string-valued enums.
