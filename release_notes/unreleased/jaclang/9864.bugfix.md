- **Fix: an aliased `typing.overload` is no longer a duplicate method**: With torch installed, every module that imported it failed with 36 `E0076 Duplicate method` errors and produced no bytecode, because torch binds the decorator as `from typing import overload as _overload` and the duplicate-method check only recognised the spelling `overload`. The check now learns the marker from the module's own imports, so an aliased `overload` and the `typing.overload` attribute form are skipped like the bare name.
