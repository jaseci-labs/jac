- **Fix: adding lines to `archwire.jac` no longer leaves cached analysis pointing at the old lines**: a name a module gets through a wire is recorded at the line where that wire sits in `archwire.jac`, but moving a wire up or down, for example by adding unrelated wires above it, did not count as a change to the modules it feeds. Their cached analysis kept the old line numbers, so source locations for those names were off, and a run with interface verification turned on failed with "analysis-cache verify failed … the served interface digest … differs from a fresh source compile's …". A module is now re-analyzed when any of its own wires moves; editing other modules' wires still leaves it cached.
