- **CLI: `jac install --no-npm` now actually skips npm dependencies**: the auto-generated `--no-X` form of every bool flag parsed to the same value as not passing the flag at all, so `jac install --no-npm` still ran the full bun closure on client projects. Bool flags now parse tri-state when they opt in (unspecified vs `--X` vs `--no-X`), `--no-npm` skips the npm provider during a full install while `--npm` add-mode and plain `jac install` are unchanged, and for tri-state flags an explicit `--no-X` on the command line can no longer be silently re-enabled by a `jac.toml` config binding. Help and completions render negations as one paired entry and drop the meaningless `--no-no-save` style options.
