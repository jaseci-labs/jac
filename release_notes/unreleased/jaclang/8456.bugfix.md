- **Scale: a failed cluster-node probe now says so instead of silently answering 'local'** (#8405): `cluster_type()` wrapped its whole probe in a bare `except Exception { return 'local'; }`, so a timeout, an RBAC denial on `list_node` (nodes are cluster-scoped, and the ops Role this surface grants does not include them) or any client error was indistinguishable from minikube. That answer selects `LocalProvider`, which sets `needs_nlb_wait()` to False, so `get_service_url` skips the load balancer endpoint lookup and fabricates `http://localhost:{node_port}`, and the service-type and scrape-port decisions follow local semantics: on a managed cluster the operator is handed a URL that cannot work, with nothing logged to explain it. The catch now splits, reporting an `ApiException`'s status and reason or any other error's type and message, and both arms name the consequence rather than only the failure. The fallback itself is unchanged, so a transient list failure still does not abort a deploy; only its visibility changes.
