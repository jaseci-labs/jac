- **Native: a `*` spread in a list or set display is copied instead of dropped** (issue #8070): a display was lowered by walking its elements one for one and appending each, which a spread cannot be -- it stands for however many elements its source holds at that point, a runtime quantity. Only the first element's lowering failure was propagated (`E5092`, and with it a demotion); every later element was appended under an `if val is not None` with no `else`, so a spread anywhere but the front vanished and the program kept running with a shorter container. `[1, *a, 9]` built `[1, 9]` and `{1, *a}` had length 1, silently, where CPython and the sv codespace give the full container -- a wrong answer no seam coverage counting `E5092` could see. A spread element now expands into the same len/get copy loop the variadic-call path already uses to spread a list into `*args`, in both list and set displays and in any position: the operand is resolved against the registered native list and set types (a set exposes its elements by dense index, so one loop serves both sources), a leading spread seeds the display's element storage from the source's own element type when no static element type decides it, and every copied element goes through the same coercion and the same pointer-into-scalar-slot guard #8052 added, so a spread cannot smuggle in a storage flavour the rest of the display disagrees with. A spread whose operand is not a native list or set (a dict, a string) and one whose element type has no representation in the display's slot are refused with `E5092` rather than dropped, and a non-spread element that fails to lower now propagates that failure too, so the last silent path becomes a demotion. `UniNode.insert_kids_at_pos` and `UniNode.set_kids` go back to `self.kid = [*self.kid[:pos], *nodes, *self.kid[pos:]]` and `self.kid = [*nodes]`, the form #8063 had to rewrite as a typed accumulate-and-`extend` to shed the seam.
