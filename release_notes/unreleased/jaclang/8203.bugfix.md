- **Fix: Class-level tuple metadata and type aliases lower on the native pathway**: `static has PROVIDES: tuple = (...)`, a constant `tuple` glob, and `glob X: TypeAlias = Callable[...]` each refused the native codespace, which put every `Transform` subclass in the compiler out of reach of a native compile. A widened `tuple` annotation carries no arity, so it now takes its layout from the constant the declaration is initialized with, reusing the inference that already serves un-annotated globs; the empty tuple lands on a zero-field struct. Static fields stay real values rather than being dropped. A `TypeAlias` glob is read as the compile-time declaration it is instead of being given a layout.
- **Fix: A `static has` no longer counts as an instance field**: a class-level constant carrying a default forced every instance field declared after it to carry one too (`E2004: Non default attribute 'ir_in' follows default attribute`), and was judged against instance layout compatibility (`W5032`). `static has` is class-level, so it takes no part in either rule, on the native or the server lane.
