- **Fix: native exception messages survive `except T as e`**: on the native backend, `str(e)` for a caught exception class with no fields (`obj ProgrammingError(DatabaseError) {}`) printed `<ProgrammingError object at 0x...>` instead of the raised message, which broke every error message of the bundled native `sqlite3`. `raise e` of a caught exception now re-raises it with its class and message intact.
