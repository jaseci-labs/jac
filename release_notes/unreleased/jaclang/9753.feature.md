- **Performance: native loops skip releasing body locals the iteration never assigned**: at the end of every loop iteration, native code released each reference-typed local declared in the loop body with a release call and a null store, even when that iteration had not assigned it. Each release is now behind an inline null test, so an unassigned local costs a load and a not-taken branch. Objects are still released at the end of the iteration that assigned them. An interpreter-style benchmark whose 8 branches each read through their own local (`jac build --native`) runs 16% faster (289.2 ms to 242.6 ms) with 51% fewer instructions.
