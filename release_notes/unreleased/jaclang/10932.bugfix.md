- **Fix: `jac run --serve` binds `JAC_SERVE_PORT` and `[serve] port` instead of 8000** (#10916): a file whose kind does not serve always bound port 8000, and on every serve path `JAC_SERVE_PORT` was ignored. The port is now `--port`, then `JAC_SERVE_PORT`, then the app's `[serve] port`, then 8000, and a fleet gateway and a sealed `.jab` take the same port (a `.jab`'s own `[serve] port` no longer beats `JAC_SERVE_PORT`). A port you choose is bound exactly; only the 8000 default moves to a free port. `--port` no longer copies its default from jac.toml, so a typed `--port` always wins, even when it matches the jac.toml value.
