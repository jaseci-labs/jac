- **Breaking: boolean `JAC_SERVE_*` variables must be true/false words**: values like `disabled` or `flase` used to turn the feature on; now they stop the server with an error. An empty variable now means unset, so the `jac.toml` value is used. An empty `JAC_SERVE_CORS_ORIGINS` used to allow no cross-origin requests; it now keeps `cors_origins` from `jac.toml` (`["*"]` by default), so set `cors_origins = []` there to allow none.
