- **Fix: Native backend dict values are boxed consistently**: `dict[K, V]` in the native backend now stores values as `jacval` regardless of the value type, fixing natively-compiled dict literals that stored correct keys alongside garbage values for some literal shapes, and dict lookups (`d[k]`, `in`, `.get`) that could miss or return `None`. `d.items()` / `d.keys()` / `d.values()` results keep their typed element layouts, so indexed reads like `d.items()[0]` no longer fall back to string indexing.
