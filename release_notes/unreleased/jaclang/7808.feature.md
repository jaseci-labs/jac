- **Feature: Android Compose dev host and example rework**: `jac start --client android --dev` installs a base host APK and hot-swaps `classes.dex` over HTTP via `JacDevHostActivity`; the `compose_android` example drops hand-written Kotlin screens in favor of generated output, documents the dev loop and on-device e2e script, and wires CI headless emulator verification.
- **Feature: logcat-based on-device render verification**: the generated dev host emits `JAC_COMPOSE_MOUNTED v=<version>` when a freshly swapped `classes.dex` is applied and `JAC_COMPOSE_RENDERED` once the Compose tree composes without throwing, so the on-device e2e asserts render success from logcat instead of the `uiautomator` accessibility service (which ANRs the headless CI emulator's `system_server`).
