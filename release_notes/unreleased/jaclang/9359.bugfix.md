- **Fix: a class may name itself in its own generic base**: `class Selfy(Holder[Selfy])` resolved its base by asking for the type of `Selfy`, which was already on the symbol-resolution stack, so the re-entry guard answered Unknown and every member reached through that base came back untyped. A forward reference to a class declared later always worked, which is what made the failure specific to naming yourself. The class type is now published on its declaration before the bases are resolved, with the base list, the derived class flags and the MRO filled in afterwards, and the re-entry guard hands back the class under construction instead of Unknown. Interning is keyed on the declaration site rather than the base list, so publishing first does not change which shared record a class gets. This is why `sorted(s)` returned `list[Unknown]` and `list(s)` returned a bare `list` where the same calls over `bytes`, `list[int]` and `tuple[int, ...]` were exact: typeshed writes `str` as `class str(Sequence[str])`. Both now give `list[str]`.
