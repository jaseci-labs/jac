- **Fix: native functions and globs may share a name with a C symbol**: A native module that defined its own `floor` (or `sqrt`, `strlen`, `puts`, `main`, `connect`, ...) either hit an internal compiler error and fell back to the server codespace (`DuplicatedNameError: floor` beside `import math`) or silently took over the C function the compiler and runtime call under that name (`float.as_integer_ratio` looped on a user `floor`). Such a definition is now emitted under a Jac-owned `__jac_def_<name>` symbol, so it coexists with libc, libm, and the foreign libraries bundled modules bind; a glob or entry variable of that name is no longer shadowed by an imported module's C extern either. A C-ABI shared library now exports a `def:pub` of such a name as `__jac_def_<name>`.
