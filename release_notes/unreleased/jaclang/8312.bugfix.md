- **Fix: the ambient test builtins raised `NameError` instead of skipping**: `testskip`, `testfail`, `testraises` and `RaisesContext` were exported by `jaclang.runtimelib.builtin` and declared in the checker's ambient stub, but missing from `JCIR_BUILTIN_NAMES`, the set the codegen matches names against to decide whether to synthesize `from jaclang.runtimelib.builtin import <name>` into a module's preamble. No import was emitted, so every call site reached the interpreter as a bare global and raised `NameError: name 'testskip' is not defined`. Nothing caught it earlier because these calls sit on skip paths that only run when a gate closes (no `bun`, no `node`, a sealed runtime, a missing optional dependency), so a test using one passed everywhere the gate was open. All four names are now in the codegen set, and the census that pins the runtime registry to the checker stub pins the codegen set too, in both directions: a name in `__all__` but not in `JCIR_BUILTIN_NAMES` raises at the call site, and a name in `JCIR_BUILTIN_NAMES` but not in `__all__` fails at module load. Five test files that still carried `import pytest` (which no longer resolves now that pytest has left the binary payload) were migrated to `testskip` as well.
