- **Native: a subclass and its imported base agree on the object header, so inherited fields lower instead of demoting**: `needs_vtable` asked `bool(parents)` -- "do I have a base" -- alongside two disjuncts that ask whether anything is dispatched through the class. `LayoutPass` is per-module, so a base whose only subclass lives elsewhere came out flat while the child claimed a vtable pointer in header slot 0, every inherited field shifted by one slot, `headers_agree` refused the pair, and `adopt_imported_bases` declined -- leaving the child's layout without the inherited fields at all and demoting every method that touched one. The build-time decision is unchanged, so no existing layout moves; adoption, which is the point where both layouts are finally in hand, now drops a child's vtable slot when nothing is dispatched through it and no ancestor carries a header either. A pair that genuinely has no assignment satisfying both keeps its refusal, and keeps it loud.
