- **Fix: native `str()` of an owned temporary no longer reads back empty**: `NativeBuiltinEmitter.emit_str` returned its argument as the result on the str-handle and pointer identity paths without taking a reference, while builtin call sites release owned argument temporaries after dispatch -- so `str("".join(chars))` aliased a freed handle and produced `""` (a variable argument survived because it is borrowed, not owned). The sealed parser's test-slug derivation is exactly this shape: `_test_ident_from_desc` came back empty for every described test, `parse_test` burned a `_jac_gen_<n>` ordinal on it, and the seal's parse parity canary refused the materializer artifact on macOS arm64 -- the rolling dev-binary release had been red there since the #8181 corpus made the shape visible. The identity paths now retain the value they return; scalar identity paths (`int()` of int, `float()` of float) have no refcount and are unchanged.
- **Fix: native string subscripts wrap negative indices and raise `IndexError` out of range**: `_codegen_string_index` gepped the raw index, so `s[-1]` read the byte before the string data (the tagged-length header) instead of the last character -- silently corrupting `_string_lit_text`'s closing-quote check in the sealed parser, among any other negative string index. String subscripts now normalize negative indices and raise `IndexError("string index out of range")` when out of bounds, matching the list/bytes subscript emitters; the for-loop body path keeps its raw non-negative induction index.
