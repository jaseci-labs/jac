- **`jac fmt` no longer deletes the `awaiting` clause of a `try` statement**: formatting a file containing `try { ... } awaiting { ... }` silently removed the whole `awaiting` block from the source. Nothing reported it, and the file still compiled afterwards, so the only symptom was that the loading state stopped appearing at runtime. Format-on-save, the pre-commit hook, and the CI formatting check all triggered it. The clause now survives formatting intact, on its own and alongside `except` and `else`, both in ordinary code and inside a JSX slot.
