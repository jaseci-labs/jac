- **Fix: a typed hop honours an entry that blocks the caller**: the permission filter a typed traversal pushes into SQL treated a record as visible whenever it was granted to all, or named the caller or one of the caller's groups at any level, so a `NO_ACCESS` entry on the record or on its owning root did not hide it the way the access check does. Typed and untyped hops now agree: the SQL filter reads the record's grant to all, its owning root's grants, and its entry for the caller in the same order as `check_access_level`, and a group entry admits only above `NO_ACCESS`.
