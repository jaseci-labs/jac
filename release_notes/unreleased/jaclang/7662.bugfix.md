- **Fix: jac2js host constructor calls**: Bare calls to JS/Web API constructors in client code (e.g. `TextEncoder()`, `URL(...)`) now lower to `Reflect.construct(Cls, [args])` instead of invalid bare constructor calls. `jac check` emits W6010 suggesting the portable `new(Cls, ...)` spelling.
- **Fix: complete JS host constructor registry**: The constructor list is now derived from a single tagged registry (`JS_HOST_GLOBAL_TAGS` in `jac0core/constant.jac`) shared with browser-seed placement and the client ambient-name audit, so the three views can no longer drift. This extends W6010/`Reflect.construct` lowering to ~39 previously uncovered constructors (`Blob`, `FormData`, typed arrays, `WeakMap`, error types, observers, etc.) and drops the nonexistent `ReadableStreamReadResult`.
- **Error: keyword args on host constructor calls**: Bare calls like `URL(..., params=...)` now report E6010: host constructors are positional-only, use positional args or `new(Cls, ...)`.
