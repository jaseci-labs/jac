- **Fix: a declaration that never gets an implementation is an error**: A `def` written as a declaration with no matching `impl` compiled to a silent no-op returning the return type's default, so `obj Box { def doubled -> int; }` made `Box().doubled()` yield `0` and nothing said a word. E2087 now names any ability that reaches the end of declaration/implementation matching with no body; `abst`, `by` abilities, accessor blocks, `@overload` declarations and abilities inside imports stay exempt, and archetypes and enums are left alone because `edge Knows;` is an empty edge, not a declaration waiting for a body. The diagnostic found 101 interface declarations across the server, scale, runtime and ECMAScript packages, which are marked `abst`, and one dead declaration (`PgWireConnection._pump_ready`, never implemented and never called), which is removed. It also turned up a seed divergence: the jac0 bootstrap transpiler appended `abc.ABC` to the bases of any class holding an abstract member, which the real compiler never did, so a seed module declaring `obj X(Protocol)` with an `abst` member died at class creation during bootstrap. The seed now emits the bases the source declares.
