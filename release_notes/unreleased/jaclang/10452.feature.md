- **Performance: a walk no longer slows down as it detaches nodes**: each walk kept the nodes it must skip in a list, and every detach and every step scanned that whole list, so a long walk that detached many nodes grew quadratically slower. The list is now a set. The compiler gains most, since every AST field write detaches a node: when building the native kernel, four modules that took 1,000 to 1,900 s each to lower now take about 36 s.
