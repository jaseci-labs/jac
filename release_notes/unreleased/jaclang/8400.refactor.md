- **`jac check` on a directory no longer re-compiles a module once per annex**: the walk globbed `**/*.jac`, so `foo.impl.jac` and `foo.test.jac` came back as targets of their own, and since checking an annex resolves to its base file, every annex re-compiled `foo.jac` from scratch and reported nothing the base check had not already reported (compiling a module folds its annexes in). A directory walk now drops an annex whose base module is itself part of the same run, which is what makes the `foo.impl/` and `impl/` folders drop out with it. An annex named on the command line is still checked, and so is one whose base is not in the run, so `jac check pkg/impl/`, `jac check foo.impl.jac`, and a base-less annex all behave as before.
