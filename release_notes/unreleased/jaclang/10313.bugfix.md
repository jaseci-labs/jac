- **Fix: Writes made inside an HTTP SSE stream are committed**: A function or walker that streams its result over HTTP (SSE) used to lose every write its stream body made, in both colocated and fleet deployments, because the request scope closed when the response was returned, before the body ran. The response body now owns its request scope: the stream's writes commit when the producer is exhausted (before the terminal `end` event, so a write conflict at that commit arrives as an `error` event instead) and roll back when the producer raises or the client disconnects mid-stream.
