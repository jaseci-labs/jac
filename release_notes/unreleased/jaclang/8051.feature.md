- **Native: `**` spread keys bind declared parameters (CPython parity)**: A spread key that names a keyword-bindable declared parameter of the callee now binds that parameter at runtime instead of silently landing in the `**kwargs` sink: `f(**{"a": 5})` against `def f(a: int = 0, **kw: int)` yields `a=5, kw={}` on native exactly as on the Python backend. A slot bound twice -- positionally, by literal keyword, or by an earlier spread -- raises `TypeError: got multiple values for ... argument`, and a required slot no spread supplies raises `TypeError: missing 1 required ... argument`, matching CPython's messages. The sink parameter's own name, the varargs name, and positional-only parameters stay sink keys, as in CPython. Call sites without a spread are unaffected.
