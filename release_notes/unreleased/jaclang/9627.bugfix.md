- **Fix: a Python-side import skips a native module's C declarations**: after #9593 kept Python-side imports of native-only modules, an importer that named a C-import-declared struct or function beside a plain name (`import from .gfx { Matrix, helper }`) imported all of them, and Python callers failed at load with `cannot import name 'Matrix'`, since a native module's Python side does not bind its C declarations. Those names are now left out of the Python import; everything else, and the native side, are unchanged.
