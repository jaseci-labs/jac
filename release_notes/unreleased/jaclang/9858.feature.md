- **js_engine replaces Bun as jac's JavaScript runtime**: `js_engine/` holds a Node.js-compatible JavaScript engine written in Jac and compiled to a native binary by the in-repo compiler (`make` in `js_engine/`). Client builds and the dev server, `jac install --npm`, `jac x`, the cl test runner, sealing and the React Native tooling all run on it; `get_js_engine()` resolves `JAC_JS_ENGINE`, then the copy bundled in the binary, then a checkout's `js_engine/bin`, then `PATH`. The pinned Bun download (`zig build fetch-bun`, `payload fetch-bun`, `--bun=`, `JAC_BUN`) is gone; `zig build -Djs-engine=<dir>` bundles a tree staged by `make dist`.
