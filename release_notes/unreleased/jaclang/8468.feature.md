- **CLI: `jac ninja` and `jac ai` removed**: The fused neovim editor (`jac ninja`) and the built-in coding agent (`jac ai`) are gone, along with the editor tree and the agent's web UI. The `jac` binary no longer links neovim, so the build drops the neovim and Lua closure (and the `-Dno-ninja` option with it). Agent workflows continue through `jac mcp` plus the bundled guides (`jac guide`).
- **The single-binary launcher and its build tooling are Jac**: The Zig launcher (materialize, dlopen embed, the `libjacpyembed` desktop shim, `pack`, the payload tool) is replaced by Jac. The launcher stub is `launcher/launcher.jac` over a native fused-runtime library (`jaclang/runtimelib/fused`: the trailer codec shared with the Python tier, payload materialization through the bundled `compression.zstd` + `tarfile`, the PEP 741 CPython bring-up), compiled by the in-checkout compiler and linked by Jac's own linkers; the desktop host imports the same library instead of a shim. The payload tool is `jaclang.payload` (Python-tier Jac running on the fetched pbs CPython), `jac build --as binary` appends its overlay in-process, and the pins live in `bootstrap/pins.json`. `zig build` stays the entry point; Zig is now only the bootstrap seed that fetches CPython and the C/C++ cross-compiler for the LLVM shim and vendored runtimes.
- **Native stdlib: `io`, `compression.zstd`, `tarfile`**: CPython-congruent `BytesIO`, a streaming `ZstdFile`/`ZstdDecompressor` over the bundled libzstd, and a streaming tar reader (ustar, PAX, GNU long names, the `data` filter), with cross-backend equivalence tests; plus per-OS floors `_dl_native`, `_exec_native`, `_fd_native`.
- **Native compiler fixes**: function-pointer fields of foreign structs use the C scalar convention (`str`/`bytes` as `char*`), `os.environ[k] = v` accepts a `str` parameter, a dependency compiled for the native pathway resolves its own sibling/relative imports, glob-init symbols derive from each module's real path (one file reached through two import spellings no longer dangles), a symtab-only dependency is no longer mistaken for mid-compile on cold builds, and the placement verdict accepts inferred dotted local imports.
- Mach-O linker: internal GOT slots are keyed by symbol index, so same-named private literals (`l_.str.N`) from merged floor-archive members no longer overwrite the main object's slots; the macOS launcher stub now prints its own strings instead of OpenSSL error text.
