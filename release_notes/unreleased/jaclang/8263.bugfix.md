- **The type system's `types.jac` and `type_utils.jac` type-check clean**: twenty-four latent annotation and narrowing defects are fixed, including `ClassType.get_class_symbol`, which read `name` off a scope type that has none and declared a non-optional return for a value that is optional. Quoted forward references in `enum_utils.jac`, `operations.jac` and `helpers.jac` are unquoted so their bodies are checked at all.
- **The language server converts completion kinds across the two enums that carry them**: `type_utils.CompletionItemKind` and the LSP's own `CompletionItemKind` are separate IntEnums, and the bridge passed a member of one where the other was declared. The conversion is now explicit; serialized output is unchanged.
- **A generic method that cannot be monomorphized no longer emits invalid LLVM**: the specialization shell was left behind as a `declare private`, which LLVM rejects, failing the link at whichever module imported the generic. The shell is now erased and the calling function demotes instead.
