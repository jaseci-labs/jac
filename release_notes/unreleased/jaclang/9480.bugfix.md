- **Fix: a native caller of a demoted cross-module function no longer segfaults on a cold cache**: in the JIT lane (`jac run`, `jac test`) a module that called an imported function which falls back to Python was emitted before that function's verdict existed. The call referenced a symbol the link never defined, MCJIT resolved it (and its whole relocation batch) to null, and the first native call crashed with no diagnostic; a warm cache hid it. The importer now learns the verdict of every unit its own link compiles before it emits, so the caller demotes in cascade as it does on a warm cache. Releasing an unconsumed dependency unit now also evicts it from the context program that holds it, so a module whose importer fell back to Python is no longer demoted when it is imported on its own.
