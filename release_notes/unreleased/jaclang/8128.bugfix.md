- **Fix: Host client build runs on the bundle's staged sources**: A scale deploy now builds the client bundle inside the same filtered staging copy that defines the `.jab`'s membership, so files the bundle strips (`.env`, the raw `jac.toml`, `.jacignore`-parked trees, key material) no longer reach the shipped dist. A build that references a file outside membership fails loud on the host, naming the file, the matching `.jacignore` pattern, and the fix. A `.env` that declares `VITE_`-prefixed values is called out by key before the build, since those now compile to `undefined` in the served JS (put public build-time values under `[client.vite.define]`), and a `[scale.microservices.client] entry` that names a missing file fails the deploy instead of silently shipping a gateway with nothing to serve. The built dist replaces `<project>/.jac/client/dist` in one directory swap rather than being rebuilt in place, and a `jac.toml` the loader rejects fails the deploy instead of silently skipping the client build.
