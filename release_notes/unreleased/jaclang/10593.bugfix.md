- **Fix: `/=` on a module-level float and `print(bool(...))` give Python's answers natively**: on the native backend, `g /= 2` on a float assigned in a `with entry` block stored the right-hand side (`2.0` instead of `5.0`), and `%=` on such a float did the same; the module-global store now computes every scalar augmented operator the way a local does. `bool(...)` returned a 0/1 integer instead of a bool, so `print(bool(0))`, `str(bool(0))` and `f"{bool(3)}"` showed `0` and `1`; it now returns a bool, and `bool(nan)` is `True` as in Python.
