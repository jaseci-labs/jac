- **`jac check` no longer rejects a valid file because of how its path is spelled**: with the native compiler kernel, `jac check hello.jac` could fail with "the native compiler kernel analyzed hello.jac but reported no module for it" while `jac check "$PWD/hello.jac"` passed, and on macOS a path typed in a different letter case than the folder on disk failed the same way. The kernel and the CLI each canonicalized the path with a different `realpath` (the kernel's keeps a relative path when `realpath` fails, as under a parent directory that can be entered but not listed, and returns the on-disk case), so the CLI's lookup missed the kernel's entry. `jac check` now takes the entry module the kernel itself names.
