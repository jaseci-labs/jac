- **Fix: `str`, `list` and `tuple` no longer pretend to support `|`**: `jac check` used to accept `"abc".__ror__(1)` and `(1, 2).__or__(None)`, and quietly accepted `|` between plain values such as `text | None`, `my_function | None` or `math | None`, all of which fail when the program runs. These are now reported, while `|` in type annotations and type aliases keeps working.
