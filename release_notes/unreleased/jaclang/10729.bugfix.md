- **Fix: `str`, `list` and `tuple` no longer pretend to support `|`**: `jac check` used to accept `"abc".__ror__(1)` and `(1, 2).__or__(None)`, and typed `text | None` on a plain value as `_SpecialForm`, all of which fail when the program runs. These are now reported, while `|` in type annotations and type aliases keeps working.
