- **Breaking: `[dependencies]` in `jac.toml` now lists Jac packages**: Python packages move to `[dependencies.pypi]` (and `[dev-dependencies.pypi]`); the old `[dependencies.git]` table becomes `[dependencies.pypi]` entries with `git = "..."`. A bare `numpy = ">=2"` under `[dependencies]` is now an error that names the move, and `jac fix dependencies` rewrites existing manifests. On the command line, a Python package needs `--pypi`: `jac install --pypi numpy`, `jac remove --pypi numpy`, `jac update --pypi numpy`. See the [Packages reference](../../reference/packages.md).
- **Breaking: comptime `embed_file` and `embed_bytes` stay inside the package**: a path that resolves outside the module's project root (an absolute path or a `..` escape) is now a compile error.
- **Breaking: `jac build --as wheel` refuses to drop client modules silently**: a project whose client-codespace modules cannot ship in a Python wheel now fails the build with the list of modules; pass `--allow-drop-client` to build without them. A wheel also refuses a project with Jac package dependencies.
