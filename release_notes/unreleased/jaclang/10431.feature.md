- **SSO connected accounts**: a signed-in user can link Google, GitHub or Apple with the extra scopes listed in `[scale.sso.<platform>] scopes`, and server code gets a valid access token for the caller with `await sso_access_token(platform)` from `jaclang.scale.sso.grants`. The token is refreshed before it expires, a rotated refresh token is stored, and a grant the provider refuses is forgotten. Google is asked for offline access and keeps earlier grants. Grants are stored with the user's credentials, encrypted under the `[serve.auth]` secret, and never reach the client. The client runtime adds `jacSsoConnect`, `jacSsoFinish`, `jacSsoConnections` and `jacSsoDisconnect`, the server adds `GET /sso/connections` and `DELETE /sso/{platform}/connection`, and `POST /sso/{platform}/begin` takes `intent = "connect"` and `scopes`.
