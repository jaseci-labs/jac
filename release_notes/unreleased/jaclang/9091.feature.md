- **Native pure-Jac dependencies**: declare git/path dependencies in `[dependencies.jac]`, install with `jac install jac:<url>[@ref]`, and import them directly; packages resolve through a content-addressed store keyed by tree hashes, with flat conflict detection and `[override]` support. A committed `jac.lock` records resolved commits, tree hashes, and harvested python/npm pins; `jac install --frozen` replays it exactly and `jac update` re-resolves floating refs, reporting old→new commits.
- **`jac why <pkg>`**: prints every reverse-dependency chain for a package (pure-jac, python, or npm) from `jac.lock`, e.g. `urllib3 (python) <- requests (python) <- root`.
- **Store integrity on the frozen path**: store hits are verified against the tree hash recorded in `jac.lock` before being served, so a corrupted or tampered cache entry is repaired by refetch instead of loaded.
- **Local git sources**: `.git` suffixes on `file://` and filesystem paths are preserved during URL normalization (a bare repo at `repo.git` clones under its real name); remote URLs still canonicalize by stripping the suffix, and derived package names never keep it.
- **`jac update -d`**: updates dev-only pure-Jac dependencies (plain `jac update` leaves them frozen), matching the Python provider's `--dev` semantics.
