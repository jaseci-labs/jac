- **Fix: Broken native artifacts are no longer published on codegen failure**: When native codegen fails at any stage (dependency linking, kernel linking, the LLVM pipeline, or an unexpected exception), the compiler now withholds every native artifact (`llvm_ir`, `native_linked_ir`, `native_bitcode`, `native_engine`, `native_layout`, `py_bytecode`) instead of caching a poisoned module that later runs execute with holes.
- **Fix: New E0078 error for duplicate module functions**: Defining two top-level functions with the same name in one module now fails compilation with `error[E0078]` instead of silently keeping the last definition; add `@overload` to each declaration for intentional overloads. The qualified `@typing.overload` spelling is recognized too. A name that mixes `@overload`-decorated and plain declarations is still rejected, regardless of declaration order.
