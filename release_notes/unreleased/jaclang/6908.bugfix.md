- **Fix: KEDA `destroy()` now cleans up orphaned `TriggerAuthentication` resources**: `KEDAAutoscaler.destroy()` previously deleted only the `ScaledObject`, leaving any `TriggerAuthentication` resources created by `apply()` permanently orphaned in the namespace after a redeploy with changed trigger config. `destroy()` now reads the live `ScaledObject` first, extracts each trigger's `authenticationRef.name`, deletes the referenced `TriggerAuthentication` resources (404-safe), then deletes the `ScaledObject`.
