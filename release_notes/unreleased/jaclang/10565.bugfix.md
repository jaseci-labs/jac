- **Fix: a write that fails after a request commits is no longer hidden**: if a graph write from an `on_commit` callback or a response getter could not be saved, the request used to answer 200, or re-run the walker on top of its saved work and fire the callback again. It now answers `500 late_write_failed` without re-running, and a retry with the same idempotency key replays that answer. Keep graph writes in the walker body; a callback that fails for its own reasons is still only logged.
