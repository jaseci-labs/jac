- **Scale: a pinned local-channel deploy ships the admin console instead of rebuilding it in every pod**: `jac start --scale` with `JAC_SCALE_BINARY_PATH` set never staged the admin console, even when `[project] jac-version` pinned a release that publishes one, so every gateway pod rebuilt it from source at boot and the app could serve 503 for minutes behind an eager rollout. The console asset for the pinned version is now staged; a local deploy still never downloads a jac binary.
