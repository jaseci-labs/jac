- **Fix: Native compiler closure**: native compilation preserves configured project identity across staged builds and lowers additional compiler module paths without opaque fallbacks. A project whose `[project] name` is `jaclang` (this repository is one) no longer has its own unit mistaken for the compiler's package: only a unit root without a `jac.toml` is the package itself, so a native unit in such a project is still lowered instead of host-compiled.
