- **Bugfix: Native string builtins follow UTF-8 codepoint semantics**: `len`, indexing, slicing (incl. step), and iteration over native strings are codepoint-based; `find`/`rfind`/`index`/`rindex`/`count` return codepoint indices and honor `start`/`end`; `startswith`/`endswith` regions, strip charset membership, and `center`/`ljust`/`rjust`/`zfill`/`expandtabs` width arithmetic are codepoint-based; `expandtabs` no longer relies on NUL termination. `str(bytes)` and `bytes` builtins are unchanged; `__jac_str_len` remains a byte length for buffer sizing.
