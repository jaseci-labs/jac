- **Fix: `datetime`, `date`, `time` and `UUID` request values bind from strings**: A served walker or function field declared as `datetime`, `date`, `time` or `UUID` answered 422 for a valid ISO 8601 or UUID string, because the request binder tried to build it from an object. It now parses the string, and the OpenAPI schema lists these fields as strings with `format` `date-time`, `date`, `time` or `uuid`. A sized field such as `u8` or `f32` now follows the `int` or `float` rules and refuses a value outside its range instead of passing it through. The request binder and stored-data loading now share one type converter, so a type supported in one is supported in the other.
