- **Breaking: The dev server no longer writes `.jac/client/.jac-status.json`**: `jac run --dev` reported a client build error by creating that file inside the folder Vite serves. Vite took the new file for a project change, retried the failed import and reloaded the page, the reload was taken for a recovery, and one unresolvable import reloaded the preview forever. The build status now reaches the dev server as a command on its stdin, a Vite error is cleared only when the module that failed transforms again or the app loads, and the rendered diagnostic stays on screen. Read the status from `GET /__build_status`, which returns the same document. `.jac/client/.jac-force-reload` is gone for the same reason.
