- **`jac build --as client` reports how long each stage took**: a client build printed one timing, the bundler's, which on a mid-sized app is a few seconds of a minute-long build. The entry compile, the page compile and the package install now each print a line with their time when they end, and the closing line carries the total, so a slow build shows where it went and a build cut off midway shows how far it got. A stage that took under a tenth of a second prints nothing.
