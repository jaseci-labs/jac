- **Breaking: endpoint caching reads the types of what an endpoint changes, and `@effects` is gone**: a walker or `def:pub` is a writer only when it connects, disconnects, creates or destroys a node or edge, changes a value stored on one (`n.x = v`, `n.meta[k] = v`, `n.tags.append(v)`, including through a local bound to `n.meta`), or calls or spawns something that does. Calls to common built-ins (`len`, `str`, `sorted`, ...), read-only methods and changes to local values are reads, so ordinary readers are cached without a declaration. A walker that uses `visit`, an endpoint that uses `spawn`, and other Python calls count as writers. In-place changes to a node's list or dict fields were previously classified as reads, so their callers served stale cached data; they now invalidate. `jaclang.lib.effects` and its `@effects` decorator are removed: delete the import and the decorator. This also fixes #10410, where `@effects` was ignored whenever `jaclang.lib.effects` came from its cached interface.
