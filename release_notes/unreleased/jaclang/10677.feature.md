- **`JAC_PAYLOAD_ZSTD_LEVEL` sets the payload's compression level**: a `zig build` packs the binary's payload at zstd level 19 unless `JAC_PAYLOAD_ZSTD_LEVEL` names another level. CI's single-run kits use 3, which packs in seconds instead of about 5 minutes. Cached deps-layer frames are keyed by level, so a release never reuses a fast frame.
