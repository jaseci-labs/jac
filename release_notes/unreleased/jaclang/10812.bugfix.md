- **Fix: a `cli` app's `.jab` is sealed under the project's default codespace**: `jac build --as jab` sealed every app with an entry under the `server` codespace, including `cli` apps that run as scripts rather than serve. Only kinds a `.jab` serves (`service`, `service-mesh`, `web-app`, `web-static`) now seal under `server`, so a `cli` jab runs the bytecode it would get from `jac run`.
