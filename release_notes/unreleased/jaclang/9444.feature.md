- **Native compiler session**: application modules parse through the native compiler kernel, which runs the early analysis passes (AST validation, symbol construction, declaration/implementation matching, semantic analysis and the JSX intrinsic guard) for every program whose placement is known before parsing, instead of only when the compiler compiles itself. Per-context deep copies of parsed trees are gone. A development checkout whose kernel is stale rebuilds it on demand.
- **The compiler reaches the project through one host interface**: project configuration, workspaces and apps, module resolution, npm and typeshed queries, formatting and linting, native-unit records and the per-module compiler reach the compiler session through `HostServices` (`compiler/frontend/host.jac`), implemented in process by `ProjectHost`. The session's analysis stages (`driver/module_analysis.jac`) no longer import the project, runtime, cache or CLI packages, so the whole pre-backend pipeline can lower as native units.
