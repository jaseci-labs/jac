- **Native: `**` spread into a `**kwargs` sink**: A call site may now spread a dict into a callee that declares `**kwargs`, on the native backend. The sink dict is built at compile time -- literal keywords are inserted directly and each spread operand is merged with an index loop over the source dict -- so no runtime keyword binding is involved. A spread onto *declared named parameters* still raises E5090, since that would require resolving names to parameter slots at runtime.
- **Refactor: front-end method kinds use Jac keywords**: `passes/transform.jac` and `compiler.jac` now spell abstract and class-level methods with `abst` and plain instance methods instead of `@abstractmethod` / `@classmethod`. The keyword forms set the same `uni.Ability` flags and re-emit the same Python decorators, and they cross the native capability gate, which inspects decorator expressions.
- **Refactor: drop vestigial reflection in the front end**: `helpers.pascal_to_snake` no longer carries an `@lru_cache` sized for the reflective visitor dispatch that `gen_uni_dispatch` removed, and `placement.scan_native_blockers` names offending node types from a table instead of reading `typ.__name__` at runtime.
