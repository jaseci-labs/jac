- **Native: a Python-side base method that would dispatch past a native override refuses instead of running the wrong body** (#8310): the pyb shadow is built as `type(name, (base,), {})`, so it carries the Python-side base chain and none of the native subclass's bodies -- a base method invoked through it resolved its own `self.X()` against that hollow class and ran the base's body where the subclass's override should have, with no diagnostic and no seam (measured at 30 where the server lane answers 1020). E5088 closed this at the construction site; E5089 now closes it at the call, demoting the owning callable to the Python lane where the whole chain agrees. The check reports only what the tree can prove -- a Python-side ancestor declaring the called method, a literal `self.X(...)` in its body, and a live native override of `X` -- so a subclass overriding a name the base never dispatches to, and a base method reaching nothing on `self`, both keep lowering.
