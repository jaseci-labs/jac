- **Fix: a `for` target that rebinds a variable to another type is reported** (#10375): the loop writes the function's variable, but the checker never compared the target with that variable's type. `title = Label(); for (k, title) in pairs {}` (or a rebound parameter or annotated local) passed `jac check` and native code then used the string as the object; it is now `E1001`, the same as `title = "Top"`. A compatible element type, such as a subclass, is still accepted.
