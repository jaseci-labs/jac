- **Fix: `==` and `in` no longer narrow a variable to a type it may not have**: inside `if n == True`, an `n: int | None` is now `int` rather than `bool`, since `1 == True`. In the same way, `f == 1` keeps a `float` a `float`, and comparing a `str` with `1` no longer turns it into an `int`. The same holds for `in` and `not in` against literals: `n in (True, False)` keeps an `int` an `int`.
