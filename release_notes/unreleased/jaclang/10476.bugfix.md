- **Fix: JacPython builds on macOS**: The macOS layout tables of the JacPython runtime were computed against a Linux `pyconfig.h`, so the interpreter state offsets (`_PyRuntimeState`, its thread and tracemalloc state, the static singletons) and `max_align_t`'s alignment disagreed with the macOS headers and the build stopped at its layout check. `scripts/jacpython/gen_layouts.jac` now probes each platform's own `pyconfig.h` (`bootstrap/pyconfig_tool.zig`, the build's probes run for that target), and `ALIGNOF_MAX_ALIGN_T` is a per-platform constant (8 on Apple arm64). The macOS `timeval_store` writes the 32-bit `tv_usec` through its address: `timeval` type-checks as the LP64 record, so the native lowering widened the value and then refused to narrow it into the macOS field.
