- **Fix: a module named by `import from . { ... }` that is not where the dots point is E1134**: `import from . { nosuch_zz }`, or `import from . { top }` with `top.jac` at the project root, passed `jac check` with only a W1101 warning and failed at runtime with `cannot import name ...`. When the `from` location of a relative import is a folder, an item that is neither a module there nor a name its `__init__` defines is now E1134, unless the import is type-only, comptime, or inside a `try` that catches `ImportError`.
