- **Fix: f-strings render `None` as `None`**: a bare `None` interpolated into an f-string on the native backend printed `(null)` (and the underlying `%s` + null pointer was undefined behavior). f-string segments now route through the same `None` rendering as `print`/`str`, including format specs (`f"{None:>6}"`); `!r` yields the unquoted `repr(None)`; and a segment null only at runtime (e.g. `f"{s and 'u'}"` with `s = None`) selects the `None` text instead of handing printf a null pointer.
