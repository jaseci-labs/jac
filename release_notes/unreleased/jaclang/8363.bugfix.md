- **Native: a bool-valued dict no longer lends its 1-bit storage to the next int- or enum-valued dict in the unit.** The dict helper set and struct type are named from the lowered value type, and every non-pointer integer used to spell as `i64`, so once a `dict[str, bool]` literal had registered `ptr:i64` with an `i1` value slot, every later `dict[str, int]` / `dict[str, SomeEnum]` literal adopted it and stored values through one bit. The sealed `unitree` unit hit this as soon as `codeinfo` joined its closure: `Archetype.postinit`'s `{keyword: SymbolType}` table answered `MODULE` for every `node`, and every OSP program failed E1096/E1097/E1114 in the kit. The spec now names the integer width (`i1`, `i8`, …), each width gets its own helper set, and a red-first JIT test pins the three-dict sequence.
