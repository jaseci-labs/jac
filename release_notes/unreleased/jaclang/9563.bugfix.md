- **Fix: `round(x, ndigits)` types as `float`**: The checker solved a protocol's type variable from an overloaded implementation's first overload, so `round(x, 3)` on a float (typeshed's `_SupportsRound2[_T]` against `float.__round__`) was inferred as `int`. Natively an unannotated `[round(v, 3) for v in values]` then built an int list and truncated every element. The protocol member now binds to the overload whose signature fits the protocol method.
