- **Fix: only one caller now probes a recovering service-to-service dependency**: when the circuit breaker's cooldown elapsed, every caller that arrived was let through at once, so a dependency that had just been declared unhealthy took the full concurrent burst instead of a single trial call. One caller now carries the trial while the rest keep failing fast, and a trial that ends without a result hands the breaker back instead of leaving it stuck shedding every call. A reply that arrives after its trial has already been given up on is ignored, so a slow dependency cannot reopen itself to full traffic while a newer trial is still in flight, and cannot skew the failure count that decides when the breaker next opens. A trial is only given up on once the service's own configured request timeout has passed, so a service that is allowed a long timeout is never probed twice at once. A call that was already in flight when the breaker opened no longer cancels the cooldown by succeeding, so a dependency that has just been declared unhealthy is not returned to full traffic by a single straggler that got through, and it now gives up its remaining retries once the breaker stops letting it through rather than spending them alongside the trial call. The error reported to a shed caller no longer quotes a cooldown that does not apply while a trial call is in flight.
