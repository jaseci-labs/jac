- **Fix: bound-endpoint edge hops lower natively.** Traversals that bind the far endpoint (`[edge p ->:E:-> c]`, `[p ->:E:-> c]`, and the backward spellings) now emit native code instead of demoting; edge objects returned carry readable fields.
- **Fix: `jid()` lowers natively.** The identity builtin produces the same 32-char id shape on the native backend as on the server backend.
- **Fix: bare `from`-imported stdlib names lower natively.** `from os import getcwd`-style calls now reach the same emitters as `os.getcwd()`, so `random.seed` and other void stdlib calls work from bare names too.
- **Fix: server code can import members of natively-pinned modules.** Dropped cross-codespace imports now bind through `pyb_mirror_member` instead of raising `NameError`, and a natively-executed entry fills its native-to-server callback table at boot.
- **Fix: `*.test.jac` code no longer constrains module placement or lowers natively.** Tests that touch `root`, async abilities, or demoted functions stay on the server lane instead of dragging the module under test off native or hitting abort() stubs.
- **Fix: void lambdas with statement-call bodies emit `ret void`.** Modules carrying `lambda ... -> None { call(...) }` no longer fail LLVM verification and get demoted wholesale.
