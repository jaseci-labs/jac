- **Auth (breaking): a present-but-rejected identity token now 401s on public walkers**: When a transport adapter pre-validates identity (`identity_prevalidated`, e.g. JWT validation middleware) and the supplied token resolves to no user, the request now returns `401 Unauthorized` instead of being silently downgraded to the guest identity on anonymous-allowed (public) walkers. Anonymous access is unchanged when *no* token is supplied; only an explicitly *present but invalid* token is rejected. Clients that relied on an invalid token silently falling back to guest on public endpoints must now send a valid token or omit the credential entirely.
