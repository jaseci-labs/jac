- **Feature: an edit to one native module rebuilds that module, not its importers**: a native unit's cached products were invalidated far beyond what changed. A generic instantiation and a comptime evaluation depended on their source's whole file and annexes, so any edit there, a comment included, rebuilt every unit that used one of its generics; and a unit's native interface was not a function of its inputs, so lowering it again "changed" it and every consumer was lowered again (parameter names took the IR's order-dependent `.N` suffixes; a walker's event ability was declared as a node's when its module had not been semantically analyzed; an imported class's field element types and a declared parameter's type were lost when the declaring module was read only for its declarations). Generics and comptime reads now depend on the one definition they use, and the interface is the same however a unit's imports were read. A comment in one unit's annex now rebuilds that unit alone (it rebuilt 92 of the compiler kernel's 144 units). `JAC_NA_DEBUG=1` explains every rebuild: which cache check missed, which dependency row went stale, and which interface fields changed, with their old and new values.
