- **Feature: access changes on organization data are system-only**: `JacRuntime.set_org_root_resolver(resolver)` registers a function that says whether a root id is an organization root. While one is registered, `allow_root`, `disallow_root`, `allow_group`, `disallow_group`, `perm_grant` and `perm_revoke` on an organization root, or on anything it owns, succeed only for the system root. Any other caller, including a member holding WRITE, gets an `org_acl_write` diagnostic (a `PermissionError` in strict mode) and the access rules stay unchanged, so a member cannot let outsiders into an organization or remove other members' grants. `save(node, owner=org_root)` by anyone but the system root is refused with the same diagnostic when the node already carries an access rule, so a grant added before the first save cannot ride into organization ownership. Callers without WRITE still get the usual `acl_write` diagnostic. With no resolver registered, nothing changes.
