- **`jac browse type` types newlines**: each character was sent as a keyDown carrying it as text, and Chromium inserts nothing for `"\n"`, so typing `"a\nb"` into a textarea gave `"ab"`. A newline (`\n`, `\r` or `\r\n`) is now an Enter press, the same event `jac browse press Enter` sends, so multi-line text reaches a textarea and a trailing newline submits a form.
