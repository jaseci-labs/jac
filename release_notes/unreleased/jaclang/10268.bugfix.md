- **Fix: `jac build` copies `public/` into `dist/`**: `jac run --serve` served files from `public/` at the site root, but the web build never copied them, and jac-scale deployments serve only `dist/`, so a hand-written `robots.txt`, `sitemap.xml` or `favicon.ico` worked locally and returned 404 once deployed. The build now copies the client app's own `public/` and then the project root's (the app's file wins for a path in both, as when serving), and fails with a clear message if a `public/` file would overwrite a file the build creates, such as `index.html`.
