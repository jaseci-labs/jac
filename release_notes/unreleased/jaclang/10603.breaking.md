- **Breaking: `NaN` and `Infinity` in a JSON response are sent as strings**: They used to be sent as bare `NaN` and `Infinity`, which isn't valid JSON and which browsers can't parse. A response containing `float("inf")` now carries `"inf"`. In microservice mode, a function called from another service that returns `float("inf")` now gives the caller the string `"inf"` instead of a float, while monolith mode calls the function directly and still returns the float.
