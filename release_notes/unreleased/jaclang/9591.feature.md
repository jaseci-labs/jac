- **Bundled native `colorsys`, `uuid`, `sched`, `ipaddress`, `mimetypes`, `locale`, `gettext` and `logging`**: Eight more CPython-congruent `na_stdlib` modules resolve on the native pathway from the same `import` the Python backend uses. `colorsys` is a bit-identical transliteration of CPython's conversions; `uuid` grows from v4-only to the full RFC 4122/9562 surface (parsing, the derived field accessors, `uuid1`/`uuid3`/`uuid4`/`uuid5`/`uuid6`/`uuid7`/`uuid8`, `getnode`, the namespace constants) over the OpenSSL CSPRNG floor and the bundled `hashlib`; `sched` keeps CPython's `(time, priority, sequence)` queue discipline over closure actions; `ipaddress` covers the v4/v6 address, network and interface classes with CPython's error types and messages; `mimetypes` ships CPython 3.14's default tables verbatim and reads the same `knownfiles`; `locale` wraps `setlocale(3)`/`localeconv(3)`/`strcoll(3)` with CPython's alias engine and grouping algorithms; `gettext` parses `.mo` catalogues and evaluates C plural-form expressions through a real parser instead of `exec`; and `logging` gains a dotted-name logger hierarchy, `LogRecord`, `%`-style `Formatter`, and stream and file handlers. Per-module divergences are documented in `jac/jaclang/runtime/na_stdlib/README.md`.
