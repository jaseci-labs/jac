- **Fix: An imported module no longer stops a program over a call native can't compile**: A module imported by a default `jac run` or `jac test` is now placed the way the entry file is, so a call like `open(path, errors="ignore")` moves its function to Python instead of failing with E1054. A real type error still fails, and so do `jac build --native`, `jac run -b native` and `[native] require`. A `[placement.pins]` native pin on an import now falls back too, as it already does on an entry file.
