- **Fix: a `bytes` return under `@restspec(envelope=False)` now reaches the wire as bytes**: the raw-body path ran the return value through the API serializer, which has no `bytes` case, so a binary body arrived as the Python repr of those bytes (`b'PK\x03\x04...'`) and binary responses were impossible. The execution manager now leaves the return value unserialized when the endpoint asked for a raw body, so a function can serve a spreadsheet, an image or a PDF directly instead of base64 in a JSON field.
