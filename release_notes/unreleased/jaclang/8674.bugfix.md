- **Fix: looking up an enum member by name type-checks**: `Tokens["A"]` on an enum no longer fails with `Cannot assign Tokens[Literal["A"]] to Tokens`, and now has the enum's own type. More generally, subscripting a class in a value position calls its metaclass `__getitem__` when one is defined, as Python does. A subscript in a type-annotation position is still generic specialization, so `Box[int]` means a `Box` of `int` even when `Box` has a metaclass that defines `__getitem__`.
