- **Fix: the macOS binary no longer recompiles its compiler and exits on its first command**: building the binary on macOS tried to compile Linux-only standard-library modules, such as `subprocess.linux.jac`, for macOS. One of them could not be built there, so the binary shipped with an incomplete precompiled compiler, rebuilt it on first use and exited with status 1. A build now compiles only the platform variants of a module that its target uses.
- **Fix: `jac run` no longer segfaults on macOS when it runs a program natively**: the native code calls `_os_log_impl` with `__dso_handle`, a symbol only the linker provides, so the JIT could not find it and then left every C library call in the program unresolved. The JIT now supplies `__dso_handle` itself.
