- **`[client.seo]` generates `robots.txt` and `sitemap.xml`, and previews are not indexed**: set `[client.seo] site_url` and `jac build` writes both files into `dist/`. The sitemap lists the app's `pages/` routes, leaving out `(auth)`, catch-all and dynamic routes, with `[client.seo.sitemap] exclude`/`extra` on top. `robots.txt` disallows the `(auth)` routes (anchored, so `/admin` does not block `/administrators-guide`) and `[client.seo.robots] disallow`, never blocks the client bundle, stylesheet or a sitemap URL, and links the sitemap. Paths are percent-encoded, and every list must be a list of strings. A hand-written file in `public/` wins. `jac run --serve` and the jac-scale gateways answer `Disallow: /` to `/robots.txt` on any host other than `site_url`'s or one in `[client.seo] site_hosts` (case, port and a trailing dot ignored), log the host once, and answer ahead of any route the app declares, so preview and staging deployments are kept out of search results. A gateway reads the `[client.seo]` of the app it serves at `/`, so `[apps.<name>.client.seo]` works without `default-app`. The host is `Host`, or `X-Forwarded-Host` from a proxy listed in `[serve.proxy] trusted`. Both files are served with `Cache-Control: no-cache`; `jac run --serve` used to mark them cacheable for a year.
