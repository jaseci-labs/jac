- **Fix: a managed borrow is no longer rejected over an intrinsic call**: a `&`/`&mut` borrow of a place reached from managed data (`head: &memo | None = &p.tokens[0].memo_head`) must not have the fields on its path written while it is live, and a call the checker could not resolve counted as writing anything (`E1322`). Intrinsics (`__mem_load_i64`, `__float_bits`, `__list_data_ptr`, …) resolve to no function, so any intrinsic call in the borrow's live range was rejected, and so was a call to any function whose body uses one. An intrinsic reads or stores raw words, bits and addresses, never a counted field, so it can release nothing a borrow points at: such calls now write nothing, and a borrowed local keeps its zero-refcount binding around raw-memory helpers. `__mem_call_dtor` runs a destructor and `__rc_collect_cycles` may run a collected cycle's `drop`, so both still count as writing anything.
