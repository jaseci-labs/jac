- **Feature: streaming zlib/gzip decompression**: Native `zlib.decompress` and `gzip.decompress` now stream libz `inflate` through a shared `malloc`/`realloc` arena (`z_inflate_all` in `_zlib_native`) instead of restarting the one-shot API with doubling buffers, bringing both within ~1.1x of CPython (previously ~2.6x slower). `zlib.decompress(b"")` now raises `error -5`, matching CPython.
