- **Fix: an `any` value bound to a typed container natively**: binding an `any` that holds a container to a typed list or dict (for example `counts: dict[str, int] = json.loads(text)`) no longer reinterprets it with the target's slot layout, which returned `0` or `None` for keys that are present. A container whose layout matches passes through, an empty one is rebuilt with the target's layout, and any other raises `TypeError`.
