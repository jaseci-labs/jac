- **Fix: `root.shared` no longer goes permanently stale after a guest-root heal**: when the guest root anchor was missing from the anchor store (data store reset, or the execution context swapped out from under a booted runtime), the request healed itself by minting a fresh guest root -- but `JacRuntime.get_shared_root` kept resolving the previously cached root id, so every subsequent `root.shared` access failed with "Shared root unavailable: id ... did not resolve to a Root node." `get_shared_root` now invalidates its cached id on a resolution miss, re-queries the registered resolver once, and retries before giving up, so `root.shared` follows the healed root. This also unblocks graph-writing streaming requests that run after a context reset (e.g. across pytest test blocks that swap the Jac execution context).
