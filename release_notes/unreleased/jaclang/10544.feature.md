- **Feature: bundled `json` module reaches CPython surface**: The native `json` module gains `dump()`, `indent` pretty-printing (byte-for-byte with CPython), `JSONEncoder`/`JSONDecoder`/`JSONDecodeError` with CPython's error messages and `pos`/`lineno`/`colno`, and the decode hooks (`object_hook`, `object_pairs_hook`, `parse_float`, `parse_int`, `parse_constant`, `strict`), while `dumps`/`loads` accept the full CPython keyword set (`skipkeys`, `ensure_ascii`, `check_circular`, `allow_nan`, `indent`, `separators`, `default`, `sort_keys`; `cls` is accepted and raises `NotImplementedError` on the native pathway). The parser accepts `NaN`/`Infinity`/`-Infinity` and reports `JSONDecodeError`s for extra data, illegal trailing commas, unterminated strings, and invalid escapes; the dumper gains key coercion, circular detection, and the `default` fallback. `json.tool` ships with `main()` raising `NotImplementedError`.
