- **Feature: bundled `json` module reaches CPython surface**: The native `json` module gains `dump()`, `indent` pretty-printing (byte-for-byte with CPython), `JSONEncoder`/`JSONDecoder`/`JSONDecodeError`, and the decode hooks (`object_hook`, `object_pairs_hook`, `parse_float`, `parse_int`, `parse_constant`, `strict`), while `dumps`/`loads` accept the full CPython keyword set (`skipkeys`, `ensure_ascii`, `check_circular`, `allow_nan`, `cls`, `separators`, `default`, `sort_keys`). The parser accepts `NaN`/`Infinity`/`-Infinity` and reports `JSONDecodeError`s for extra data, unterminated strings, and invalid escapes; the dumper gains key coercion, circular detection, and the `default` fallback.
