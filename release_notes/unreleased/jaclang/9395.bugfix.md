- **Fix: native kernel build fails type-checking the LLVM IR module**: `IdentifiedStructType.get_declaration` is now annotated `-> str`. It was `-> object`, which made `Module._get_body_lines` return `list[object]` where it declares `list[str]`. The stricter flow narrowing from #9390 reports that mismatch, and it stopped `mkpayload` from sealing the kernel.
