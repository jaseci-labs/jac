- **Postgres-native persistence**: The tiered memory stack (TieredMemory/ChangeSet/Mongo/Redis/Firestore) is replaced by a Postgres-backed Session/Store where the database transaction is the single source of truth (#7945): each request runs in one SERIALIZABLE transaction with automatic re-run on conflict, so uncommitted attaches, detaches, and destroys are always visible to same-request traversals (fixes #7937 structurally); graph queries compile to single SQL statements; zero-config runs use an embedded Postgres fetched on first use while scale deployments provision postgres:18, run the jac image via `jac db serve`, or point JAC_DB_URL at any managed Postgres; websocket backplane, event streams, shared state, auth tokens, scheduler jobs, and webhook keys all ride the same database over an in-house wire client; 0.35.x session data is not migrated (clean break).
