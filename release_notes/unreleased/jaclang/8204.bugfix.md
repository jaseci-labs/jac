- **Fix: A method's own TypeVar is no longer bound by its class's type-var solution**: TypeVar solutions are keyed by name, so a generic base specialized anywhere in the MRO pinned every method TypeVar sharing a name with one of its parameters. `UniPass.get_all_sub_nodes(nd, typ: type[T])` inherits `Transform[Module, Module]`, so its own module-level `T` became `Module` and every call site reported "Cannot assign Archetype to parameter 'typ' of type type[Module]". Substitution is now lexically scoped: only the type parameters bound by the class that declares the member, or by one of its enclosing class scopes, may be substituted, and a function's own type parameters shadow the class's. A function's PEP-695 type parameter is also no longer flagged as a class type parameter.
- **Fix: Magic-method overloads solve their own TypeVars from the arguments**: `get_type_of_magic_method_call` returned the matched overload's declared return type verbatim, so `list[A] + list[B]` typed as `list[_S | A]` with `_S` free and every member access on the result was a spurious E1099.
- **Fix: Narrowing reaches a comprehension on an assignment RHS**: the comprehension was linked into the control-flow graph from an ancestor of the assignment rather than from the assignment itself, which cut the chain back to the preceding guards. `if x is None { return; } xs = [p for p in x.parts];` now sees `x` as narrowed. The protection that motivated the original skip is kept: an assignment predecessor that encloses the node being evaluated is a pass-through, because the right-hand side runs before the write.
- **Fix: Narrowing survives an elif whose condition short-circuits**: `elif <a> and <b>` produced no false target, because the search for the statement following the branch only looked in the immediate parent's body and an elif is its parent's `else_body`. The edge out of the chain dangled and everything after it fell back to declared types. A branch edge whose narrowing cannot be computed now also keeps what its predecessors established instead of collapsing the merge.
