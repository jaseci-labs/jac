- **A lowered cross-module caller can no longer link against a demoted callee's renamed symbol** (#8265): the native importer emitted call sites into imported free functions before the imported unit's demotion verdicts existed, so when the callee demoted and its symbol was renamed for the Python fallback, the caller kept referencing the original name and the linked artifact failed its dlopen canary with an undefined symbol. The importer now learns an imported unit's demotion set before its own codegen -- from a cached native layout, from the dependency IR cache's metadata, or by compiling the dependency itself (memoized so the link step consumes the same unit instead of compiling twice) -- and a call site into a demoted callee refuses with the same E5092 an intra-module refusal gets, cascading the caller into a coverage seam whose reason names the cross-module callee. Two adjacent gaps the new protocol surfaced are fixed with it: `resolve_diagnostic_tokens` now lowers, keeping the diagnostics emission path seam-free in fact rather than by blindness, and a sealed ELF artifact that merges clib floor archives defines an `atexit` forwarder over `__cxa_atexit`, since glibc does not export `atexit` dynamically.
