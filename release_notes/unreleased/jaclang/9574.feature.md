- **Feature: native kernel analysis**: the native compiler kernel gains a `jc_analyze` entry that runs a module's analysis (parsing, IR, placement and type checking) against a typed `KernelInputs` snapshot of everything the analysis asks the host, and reports diagnostics, completed passes and per-module facts as typed records; `jac check` and diagnostics use it when a kernel is available. The code generators now reach the project only through the host services interface. A manual CI dispatch on main seeds the stage-0 kernel caches like a push does.
