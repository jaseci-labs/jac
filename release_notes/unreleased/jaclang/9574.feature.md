- **Feature: native kernel analysis**: the native compiler kernel gains a `jc_analyze` entry that runs a module's analysis (parsing, IR, placement and type checking) against a typed `KernelInputs` snapshot of everything the analysis asks the host, and reports diagnostics, completed passes and per-module facts as typed records. The code generators (JCIR, ESTree/JS, LLVM) now reach the project only through the host services interface, the step before they move into the kernel. A manual CI dispatch on main seeds the stage-0 kernel caches like a push does.
