- **Native: compile-time hashes for static container keys**: The hash-core helpers behind native dicts and sets are split into prehashed cores that take the key's hash as an argument plus thin public wrappers that compute it, and every emitter site with a compile-time-known string key -- dict literals, subscript reads/stores, `in` membership, set literals, match map patterns, and the `**kwargs` sink paths -- now passes the FNV-1a constant computed at compile time. Inserts also stop hashing twice (the probe and the control byte now share one hash), which speeds runtime-keyed inserts as well. Measured per iteration: three-key dict literal construction 56.5ns -> 34.9ns, a static-key store plus two reads 14.7ns -> 3.5ns, set literal construction 37.8ns -> 30.7ns.
