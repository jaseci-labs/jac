- **Runtime: `save` can bind an anchor to an explicit owner root, and `owner_of` reads ownership back**: every anchor created during a request took its owner from the ambient user root with no override, so app code could mint a group `Root()` but that root could never own anything and a member granted on it read nothing. `Jac.save(obj, owner=root_id)` now creates the anchor under the given root when the caller holds `WRITE` on that root (raising `PermissionError` otherwise, and `ValueError` for an owner that is not a root, does not exist, or would re-own a persistent anchor); one root-level grant then covers all of that root's content via the existing cascade. `Jac.owner_of(obj)` returns the owning root id. Omitting `owner` preserves the previous behavior exactly. Note that a minted `Root()` is unowned, so grant yourself `WRITE` on it in the same function that mints it - see the `jac-sv-persistence` skill. Fixes #8458.
