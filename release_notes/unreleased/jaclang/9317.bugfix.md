- **Fix: native comprehensions iterate what native for-loops iterate**: A comprehension compiled to native code now walks strings, bytes, sets, stepped ranges, `enumerate`/`zip`/`map`/`filter` and user iterators through the same iterator protocol as a for-loop. Before, `[i for i in range(0, 10, 2)]` ignored the step, a comprehension over a `str` or a set produced wrong results, a comprehension over a string literal in a global initializer failed to compile, and several `if` clauses were all evaluated even after an earlier one was false.
