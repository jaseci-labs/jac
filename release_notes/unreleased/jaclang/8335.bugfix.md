- **Fix: a deploy says which directories its build-output heuristic dropped**: the bundle skips any path with a segment named `dist`, `build`, `node_modules` and the rest of the build-output list, so a project that keeps source in a directory with one of those names lost it from the bundle silently and the first evidence was an import error inside a pod. Every dropped directory is now named once at deploy time, at its full path, and a tree that still ships content (`.jac/client/dist`) is not reported. What ships is unchanged.
