- **Fix: a distinct brand is usable in client code** (#9279): `type Brand := int;` is an erased brand over a primitive, so `Brand(x)` is a zero-cost cast, but the client backend emitted nothing for the declaration -- the brand was a free identifier in the generated module and client codegen refused the whole file ("Client codegen emitted 'Brand', which the module never binds"). A brand now binds the primitive it erases to (`const Brand = _jac.types.int`) and is exported like an enum when it is `pub`, so client code can brand a value, hand a brand to `map`, or store one in a collection, exactly as the server lane does. A plain `type X = Y;` still emits nothing, since it is not callable.
