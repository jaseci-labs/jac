- **Feature: native `functools` bundled module**: The native codespace gains `na_stdlib/functools.jac`, a pure-Jac port of CPython's `functools` -- `reduce`, `partial`, `cmp_to_key`, `lru_cache` (+ `cache`) with CPython's maxsize semantics and `cache_info`/`cache_clear`/`cache_parameters`, `wraps`/`update_wrapper`, and `WRAPPER_ASSIGNMENTS`/`WRAPPER_UPDATES` -- so the same `import from functools { ... }` binds CPython on the sv backend and the bundled objects on na. Congruent call shapes are spelled `.__call__(...)` on na (the native call lowering has no general `__call__` instance dispatch); the key scheme matches CPython 3.14's equal-type-equality `lru_cache`. SCOPE divergences are documented in `na_stdlib/README.md`.
