- **A seal reads placement from the prepare instead of re-analysing the package**: When a workspace is not explicit, the seal's precompile classifies every package file to skip client-only modules. It looked up each file's placement record without the options the prepare used, so every lookup missed and the whole package was analysed again. It now uses the same options; on a 493-file package the step went from 428 s to 16 s with the same result.
