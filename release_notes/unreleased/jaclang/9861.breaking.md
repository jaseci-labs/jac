- **Placement is one judgment, made after a module is typed, per element**: a module with no declared codespace that could prefer native used to be stamped native by a guess before it was type-checked, and one that could not have it was analyzed again for the server with the verdict stored for the next compile. Such a module is now typed first with no codespace assumed. What only native code can do (a native-only builtin, a function address held as an `int`) is recorded as a requirement, and what native code lacks (a native capability, a native standard-library member, a finding that only matters natively) as a refusal. The placement pass reads those facts and places each top-level element: native unless something refuses it, and a call between elements placed apart is allowed when the callee's signature can cross that boundary. So one function that cannot be native no longer takes its module with it. A module that has anything placed native is then analyzed a second time under that plan, so the native backend sees native types; a module with a declared codespace (a pin, a project kind, a forced or ahead-of-time build, the native library) is typed once in that codespace as before, and client placement is inferred before typing as before. The native verdict is gone: nothing about placement is remembered between compiles. **Breaking:** a function or walker a client calls must have a signature that can cross as a request; a type with no wire form (a callable, a file handle, a dict with non-`str` keys, a generator parameter) is `E5115`. Native standard-library modules must conform to the Python interface of the same name, and each platform variant must expose the same public surface (`E5114`). Public names, parameters and members the interface does not declare were renamed or made internal (for example `calendar.calendar(theyear, ...)`, `os.path.getsize(filename)`, `locale.localize(string, ...)`; `gettext.c2py_ast` and `plural_index` give way to `gettext.c2py`; `urllib.request.urlopen` returns an `http.client.HTTPResponse` read with `read()` and `getheader()`), so native code that named them must use the Python spelling. A native-only builtin (`File`, `BinaryFile`) used in code that cannot be placed native is `E5090`.
