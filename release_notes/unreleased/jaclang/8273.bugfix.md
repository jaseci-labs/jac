- **A diagnostic code can only be claimed once**: Three code collisions landed inside forty-eight hours (E0108 twice, E0109 once), each the same merge artifact of two branches independently claiming one code, green apart and shadowed together, surfacing only at a native link that refused the diagnostics module on a symbol self-collision. Registering a code that is already registered now fails at registry-build time, which is import time, and the refusal names both claimants with their severity, category and message; a companion guard asserts every registered code still resolves to a module binding of its own name, so a second declaration that reuses a name with a fresh code is caught too.
- **`any()` and `all()` ask the element for its truth**: Both native emitters compared the element against an i64 zero regardless of the element's type, which for a pointer element printed as `icmp ne i8* %"any.elem", 0` and killed the whole module with an LLVM IR parse error instead of a diagnostic, taking the artifact of every module whose closure reached it. The element now goes through the emitter's real truth test (str descriptors, floats, i1, pointers, optionals and jacvals), the loop back-edge is registered from the block that test ends in, and an element whose truth does not lower refuses by name and demotes one callable.
- **Four passes import `UniPass` directly**: `layout_pass`, `mtir_gen_pass`, `pyjac_ast_link_pass` and `type_checker_pass` imported `UniPass` through the `jaclang.jac0core.passes` package re-export, which is a hard E5090 in the native lane; they import it from `jaclang.jac0core.passes.uni_pass` now, with diagnostics unchanged per file.
