- **Client: `has` state is now read-your-writes on react and preact**: assignments to component state are immediately visible to every later read (same ability, helper methods, lambdas, after `await`s), matching server-tier fields and the solid backend, instead of silently returning the previous render's value. State lowers to per-field store cells subscribed via `useSyncExternalStore`; augmented writes like `n += 1` read the current value. Assigning a state field in the component render body is now a compile error (`E0082`), since an immediate write there would re-render forever.
