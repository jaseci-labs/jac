- **Fix: a class-form archetype is constructed through a module alias in native code**: `module.Class(...)` for a class-form archetype was taken for a runtime class value and failed to lower, so the function fell back to its Python implementation. A module-qualified class reference now constructs the class directly, as it already did for object-form archetypes.
- **The native code generator is moving into the compiler kernel**: the generator, the primitive emitters and the LLVM IR builder are now kernel units, and a kernel session can lower a module placed in the native codespace itself. It returns the module's LLVM IR, native interface and layout in the unit record, and the host turns that into machine code, cache sections and an engine without analysing the module. A dependency the host has no cached unit for is lowered in the same session; a module that cannot be lowered is demoted and recompiled on the server inside the session, and the host records the verdict. `jac run` asks the kernel first for a natively placed program. Until every function of the generator lowers natively this is on for the kernel library only under `JAC_KERNEL_NATIVE=1`; a native program otherwise compiles on the host as before.
- **Native generation asks the host for target facts**: the target's data layout, struct offsets, codec tables and the host OS are answered by the host through one question (`native_fact`) instead of being read from LLVM and the Python standard library inside the generator.
