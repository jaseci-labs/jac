- **Fix: Client imports of walkers and functions a service entry re-imports**: Client code can now import a `:pub` / `:protect` walker or function through a service app's entry even when the entry re-imports it from an implementation module instead of declaring it. The call bridges to the entry's app, and exposure is read from the declaration (a re-imported private element is still `E5106`). Previously the client build failed with an empty `Failed to compile ... for client bundle:` message. That message now always gives a reason.
