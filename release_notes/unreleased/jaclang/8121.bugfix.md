- **Fix: Gateway rate limiter honors X-Forwarded-For only from trusted proxies**: per-IP bucket keys now come from the TCP peer address unless the peer is listed in the new `[scale.microservices.rate_limit] trusted_proxies` key (IPs or CIDRs), in which case the rightmost forwarded hop not itself trusted is used, so clients can no longer bypass rate limits by forging the header; the peer fallback also reads the field the serving Request actually has, replacing the dead `.client` access that keyed all direct traffic to one shared "unknown" bucket. Deployments behind a proxy or ingress must set `trusted_proxies` to its address to keep per-client limiting; until then all traffic arriving through it shares one bucket keyed on the proxy's address.
