- **An except clause that can never match is now an error, not a silent uncaught exception**: `except e { ... }` names a class `e`; it does not catch everything into `e`. On the native backend an undefined name or a misspelled class there (`except OverflwoError`) compiled to a handler that never matched, so the exception escaped as `Uncaught exception: ...` with only a W2001 warning at check time. An undefined name in an except clause is now the new E2001, and a handler type that is not an exception class, such as an `obj` that does not inherit from `Exception`, an exception instance, or `5`, is the new E1162. To catch every exception, write `except Exception as e`.
