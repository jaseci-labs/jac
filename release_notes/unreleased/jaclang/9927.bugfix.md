- **Fix: a `def drop` that takes arguments is a method, not a destructor hook**: Both backends took any `def` named `drop` for an archetype's destructor hook and called it with nothing but the object. For `def drop(name: str)` the native release function was built with too few arguments, which raised `IndexError: list index out of range` inside the compiler: `jac check` reported an internal error and a build sent the whole module to the server codespace. On the Python backend `drop()` was called without its argument at a region close, from `__del__`, or on `del`. Only an instance `def drop` that declares no parameters is the hook now; any other `drop` is an ordinary member and hides a hook the archetype would otherwise inherit.
