- **Breaking: streamed answers and tool loops are bounded by byLLM's `timeout`**: a streaming `by llm()` call and a tool-using call previously had no overall time limit. They now end with `LLMTimeout` once `[byllm.call_params] timeout` (default `600.0` seconds) has passed since the call started, including the time tools take. An agent that legitimately runs longer than ten minutes should set a larger `timeout`, or `timeout = 0` for no limit.
