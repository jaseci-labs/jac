- **Fix: A container image keeps the runtime's file digests warm**: The file-digest ledger matched each file on its inode, size, mtime and ctime. Unpacking a container image gives every file a new inode and ctime with the same bytes and mtime, so every digest recorded at image build missed, and the first start of each container re-hashed all of jaclang's runtime files it read. Files of the extracted runtime under the cache's `rt/` are never rewritten, so they are now matched on path, size and mtime, and a ledger built into an image stays valid. Project files are still matched on their full identity.
