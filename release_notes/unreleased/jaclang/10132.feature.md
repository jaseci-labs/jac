- **Feature: a context default owner for new data**: `ExecutionContext.default_owner` names a root that owns every anchor the request creates without an explicit `owner=`, with the same checks `save(obj, owner=)` makes (the owner must be a root and the caller needs WRITE on it; an organization root also refuses a node that already carries an access rule). It covers explicit saves, nodes and edges saved through `++>`, and the save cascade, so a walker spawned on an organization root writes organization-owned data while `root` stays the real user. An explicit `owner=` wins, an existing node keeps its owner, and with no default set nothing changes.
