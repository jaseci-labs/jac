- **Feature: a context default owner for new data**: `ExecutionContext.default_owner` names a root that owns every anchor the request creates without an explicit `owner=`, with the same checks `save(obj, owner=)` makes (the owner must be a root and the caller needs WRITE on it; an organization root also refuses a node that already carries an access rule). It covers explicit saves, nodes and edges saved through `++>`, and the save cascade, so a walker spawned on an organization root writes organization-owned data while `root` stays the real user. Child contexts that share the request's session inherit it, so the walker's context and local calls see the same default. The whole save cascade is checked before anything is marked persistent, and `++>` checks before it attaches the edge, so a refused save or connect leaves no saved or attached part behind. An explicit `owner=` wins, an existing node keeps its owner, and with no default set nothing changes.
