- **Fix: an exception saying "User not found" no longer logs the caller out**: The server recognised an unknown user by comparing error text, so a walker or function raising `Exception("User not found")` was answered 401, and the web client removes its stored token on a 401. It now answers 500 like any other exception. A valid token for a user that doesn't exist still gets the same 401, `Unauthorized: unknown user`. That text also replaces `User not found` for this failure in scheduler errors, webhook logs and WebSocket error frames.
