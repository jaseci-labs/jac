- **Performance: signal-mask-free native exception frames**: On Darwin and Linux, native exception frames (`try`, walker spawns, test bodies, user iterators, generator re-arms) now arm with `_setjmp` and unwind with the matching `_longjmp`, instead of `setjmp`/`longjmp`, which save and restore the signal mask with a syscall on every frame and every raise. On macOS arm64 a non-raising `try` call is about 35x faster, a raise-and-catch about 23x faster and a walker spawn about 1.5x faster. Windows and wasm keep `setjmp`/`longjmp`.
