- **Fix: the `jac check` exclusion policy has one home**: `jac check` read no exclusion config at all. A project's policy lived in `.jacignore`, which only a CI shell step consumed by grepping it into `--ignore`, next to three more patterns hardcoded in that same step. Nothing else read either, so `jac precommit --staged --verify` type-checked every staged `.jac` file, including the test fixtures that exist to hold diagnostics and that the CI gate deliberately skips, and blocked any commit that touched one. `[check] exclude` in `jac.toml` is now that home, beside the `[check.lint] exclude` the autolint rules already use: `jac check` reads it and `--ignore` adds to it, so CI, the precommit hook and a local run apply the same list. It merges through the same path as the rest of `[check]`, so environment profiles and overlay files can set it. The repo's own list moves into `jac.toml` verbatim and its root `.jacignore` goes away; the file keeps its other job, deciding what a `jac build` bundle ships, for projects that use it.
