- **Faster kit builds: runtime reuse, catalog reuse and a parallel bootstrap freeze**: pull-request kit builds reuse the JacPython runtime main last built when the sources it was lowered from are unchanged, instead of rebuilding it on every compiler change (about 9 minutes). The kit reuses the stub catalog built for the same type system (about 100 s). The seal's bootstrap freeze runs in the precompile worker pool (171 s to 34 s in CI). The payload stages report their timings on stderr, where CI shows them.
