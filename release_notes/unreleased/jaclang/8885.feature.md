- **`jac precompile --force`**: deletes the previous `_precompiled/` output tree (every python-version dir, `MANIFEST.json`, `PRECOMPILE_RESULT.json`) before rebuilding, so every unit is rewritten instead of reused when its module key still matches the source. The warm jir module cache still serves bytecode, so a forced rebuild mostly rewraps cached units; `JAC_REBUILD=1` remains the switch for a truly cold build. Combining `--force` with `--seal-finalize` is rejected up front, since finalize only re-manifests an existing tree; `--force --seal` composes (remove, recompile, finalize).
