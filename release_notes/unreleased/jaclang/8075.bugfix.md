- **Fix: sv-to-sv RPC no longer replays requests that may have executed**: walker and function POSTs between services were retried up to 3 times on read timeout, mid-body connection loss, and streaming HTTP errors, re-executing walkers that had already run. The serving client now classifies every transport failure by request lifecycle phase (`ClientRequestNotSent`, `ClientRequestSent`, `ClientReadTimeout`), and the RPC layer retries only failures that provably happened before the request was sent (DNS, connection refused, connect timeout). Read timeouts fail fast with a descriptive error instead of a silent replay and an empty message.
