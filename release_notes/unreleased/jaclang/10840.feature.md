- **neojac compatibility: graph spaces, stdjac, and core semantics**: `archwire.jac` takes a `graph spaces` block declaring a project's spaces and apps, from which each app's kind, entry point and placement pins derive; `jac fmt` keeps the block as written. The `stdjac` library (`remote`, `graph`, `codec`, `plan`) is importable by its short name. A page function's parameters become URL segments and page props. The checker types `flow`/`wait` as `Task[T]`, accepts a reserved word as a keyword-argument name at a call site, narrows across a `with` block, lets an async function satisfy a coroutine-returning callable, and reports an attribute read on a value that may be `None` as W1099 (a warning, no longer E1099).
