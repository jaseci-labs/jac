- **Fix: `bool()` on a client object follows the Python data model**: `bool(x)` judged every JavaScript object by its own enumerable keys, so host objects that keep their data on prototype getters (`File`, `Blob`, `Date`, `URL`, DOM nodes) were always falsy and a button gated on `bool(selected_file)` never enabled. Emptiness now decides only for jac's own containers; a value defining `__bool__` or `__len__` answers for itself, and every other object is truthy. `bool(0n)` is also false now, since a bigint is an `int` to the client runtime.
