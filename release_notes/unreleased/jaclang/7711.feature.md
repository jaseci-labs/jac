- **Feature: warning for `pages/` files that are not routes**: When some `pages/` files are routes but another still returns `JsxElement`, the dev server and build now name that file and suggest returning `JsxPage` (or `JsxLayout` for a layout). Previously the page was silently left out and its URL returned 404. A file that names `JsxPage` or `JsxLayout` and still does not resolve to a route (for example a wrapped `-> (JsxPage)` return type) is named too, instead of being passed over in silence. The same per-file reporting now backs the zero-route diagnostic, which previously skipped any file that merely mentioned `JsxPage` somewhere, including on an `obj` method the router never sees. The warning does not fail the build, since a `pages/` component returning `JsxElement` on purpose is still allowed.
