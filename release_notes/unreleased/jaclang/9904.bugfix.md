- **Fix: importing a type that a server endpoint also returns no longer blanks the page**: A client module that imported an `obj` from a shared module and called a bridged endpoint returning that type got two declarations of the same identifier in its JavaScript (the import, and the decoder class the compiler adds for the endpoint), so the browser rejected the module with `Identifier '...' has already been declared` and rendered nothing, with `jac check` and the build both green. The decoder class now takes a private name when the module already binds the type's name.
