- **Fix: an `abc.ABC` import no longer blocks native placement**: `import from abc { ABC }` was an unresolved import, and the placement solver reads that as an all-or-nothing verdict that travels the whole import closure, so one such line demoted every module reaching it -- including `type_system/types.jac` and `jac0core/passes/transform.jac`, the base every pass inherits. Jac already models abstractness with its own `abst` keyword and the server lane emits `@abstractmethod` from it rather than reading it, so the `ABC` base is erased as the compile-time marker it is. Exactly that one name is erased: `abstractmethod` keeps refusing, because the keyword forms are the native spelling and the decorator spellings demote, and `ABCMeta` and a bare `import abc` refuse as before.
- **Fix: A type-parameter glob is a declaration, not a runtime value**: `glob T = TypeVar('T', bound=UniNode)` read as an assignment whose value is a call, so native codegen gave `T` storage and tried to lower the constructor filling it. `TypeVar`, `ParamSpec` and `TypeVarTuple` globs now go through the same compile-time declaration test as `TypeAlias`.
- **Fix: An empty container constructor in a ternary arm learns its element type**: `collect_generics() if is_p('<') else set()` refused to lower because inference leaves nothing on the empty arm's call node. The sibling arm now supplies the element flavor, from inference where the sibling is annotated and from the already-lowered arm where it is declared bare. This accounts for five of the six lowering failures in `type_system/ts_decl_parser.jac`.
- **Fix: `list[jacval]` reaching a `list[ptr]` slot is rebuilt rather than refused**: The two layouts store elements at different slot widths, so the list is now rebuilt element by element through the same helper the spread path uses, instead of the coercion being rejected outright.
- **Fix: `id()` answers for float values**: Pointer-backed values take their address and unboxed scalars take their own bits; floats previously matched neither rule and refused the whole compile rather than just the call.
- **Fix: `dict.keys()` and `dict.values()` no longer crash the emitter**: Both named their result list under the canonical pointer flavor but handed the helper emitter the dict's own pointer type, raising out of the IR builder where those helpers already existed and minting a second incompatible layout where they did not.
