- **Native links emit unit objects in parallel**: a link in objects mode emitted each unit's object one at a time inside the link step, which was most of the link time of a native build with many rebuilt units (319 of 349 s in a CI kernel build). Pending objects are now emitted on a thread pool, one thread per core up to 8, each from its own LLVM context; on 8 threads emission is about 5x faster and the objects are byte-identical. `JAC_NATIVE_EMIT_JOBS` (then `JAC_JOBS`) sets the thread count, and 0 or 1 emits serially.
