- **Feature: emailers send extra mail headers**: `Emailer.send_email` takes optional `headers`, for headers such as `List-Unsubscribe` and `List-Unsubscribe-Post` that give mail providers a one-click unsubscribe button. The SMTP emailer folds a long ASCII value at its spaces and no longer encodes it to make it wrap, so a long URL stays intact. A header that sets something `send_email` owns (`From`, `To`, `Cc`, `Bcc`, `Subject`, `Reply-To`, `Sender`, `MIME-Version`, any `Content-*` or `Resent-*`), has an invalid name or a line break, or can't fit on one mail line makes `send_email` return `False`. A custom emailer's `send_email` must accept `headers` before a caller passes it.
