- **Fix: native programs that ran and printed the wrong thing**: found by running ordinary programs on both tiers and comparing. A `switch` now falls through to the next case until a `break`, runs a default it reaches before any match, honours a case with no body and a case naming several values, and `break` leaves the switch rather than the enclosing loop; `(a, b) = pair` inside a function assigns module globals `a` and `b` instead of binding locals; untyped numbers of different kinds compare by value, so `3 == 3.0` and `True == 1` hold through `any`. An integer and a float are equal only when they are the same number, so `9007199254740993 == 9007199254740992.0` is false through `any`; `(a, b) = (b, a)` on module globals holding objects keeps both objects; a connect written toward its source (`sinks <++ src`) yields the destination side; a `continue` inside a `switch` runs the `finally` blocks it leaves; and the default text of an object (`Name(field=value, ...)`) nests to any depth, is tracked per thread, and prints in full again after an error interrupted it.
- **Fix: `continue` inside a `switch` never returned on the Python tier**: the switch restarted itself forever. It now moves the enclosing loop on, through any switch around it.
