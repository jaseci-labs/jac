- **Fix: native programs that ran and printed the wrong thing**: found by running ordinary programs on both tiers and comparing. A `switch` now falls through to the next case until a `break`, runs a default it reaches before any match, honours a case with no body and a case naming several values, and `break` leaves the switch rather than the enclosing loop; `(a, b) = pair` inside a function assigns module globals `a` and `b` instead of binding locals; untyped numbers of different kinds compare by value, so `3 == 3.0` and `True == 1` hold through `any`.
