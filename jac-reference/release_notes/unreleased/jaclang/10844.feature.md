- **Scale: build and deploy in separate steps**: `jac scale build <entry> --out <dir> --arch amd64|arm64` seals the app into a `bundle-<sha>.jab` plus a `build.json` record that names it, without contacting the cluster, and `jac scale deploy <entry> --from-build <dir>` applies that build without building anything. The deploy refuses a build whose bundle sha256 does not match its record, that another jac version made, that targets another app, node architecture or channel, or whose sealed `jac.toml` files (root and nested) differ from the ones the deploy would ship, naming each file and key that differs. `--plan-out <file>` writes the rendered Deployments as JSON before applying.
