- **Fix: head-tag attribute values are now quoted, so link previews see the whole description**: the client head emitter wrote every attribute unquoted (`<meta name=description content=One language, one compiler, ... />`), so HTML parsers kept only the first word and link-preview crawlers (Discord, Slack, iMessage) rendered a one-word description for any site whose `[client.app_meta_data]` values contain spaces. All meta/link/og emission now quotes attribute values, with each attribute built in its own f-string to sidestep #7750 (a quote-delimited literal between two interpolations loses its quotes, which is likely how the quoting was lost originally). `og_site_name` now emits `og:site_name` instead of the invalid `og:site:name`, and new `twitter_*` keys in `[client.app_meta_data]` emit `name="twitter:*"` meta tags so summary cards are configurable alongside the existing `og_*` support.
