- **Feature: unmigrated `pages/` routes surface on the dev error overlay (#7738)**: the per-file route diagnostic (#7711) printed only to the terminal, so a `pages/` module that lost its route (e.g. `JsxPage` -> `JsxElement`) left that URL a silent white screen in the browser. Unlike a syntax error, a valid type change compiles, so the HMR rebuild lands in the broken state rather than freezing the last-good app. `_refresh_routing` now mirrors the diagnostic to the dev build-error channel after a routing rescan, so the existing Vite overlay names the offending file and the exact fix (`JsxLayout` for `layout.jac`, `JsxPage` otherwise); fixing the type clears the overlay and reloads. Fires only on a real route regression, so a co-located `JsxElement` helper does not trip it. Dev-only.
