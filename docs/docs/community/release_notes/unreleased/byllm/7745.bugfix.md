- **Fix: Silent empty responses from `by llm()` calls against `claude-fable-5`**: `SYSTEM_PERSONA` and `INSTRUCTION_TOOL` embedded the source file's own indentation directly into the prompt text sent to the model. Provider-side safety filters could read the resulting padded/indented instruction block as an obfuscation signal and silently withhold the response (empty content, no exception) for otherwise benign requests. The prompt literals no longer carry stray whitespace, and the tool-enabled system prompt now inserts an explicit separator between the persona and tool instructions instead of relying on that same incidental whitespace.
