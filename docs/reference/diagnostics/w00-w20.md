# W0060 to W2001: stray strings, inference, modules and names

Codes that start with `W` are conditions the reference design reports as warnings. jac keeps the reference design's code, so the same mistake has the same code in both. Where native code can give the program no meaning past the condition, jac reports it as an error and the build stops until it is fixed: a value whose type cannot be inferred, a module that cannot be found and a name that is not defined. A string that documents nothing, W0060, is a warning here too: it is shown as `warning[W0060]` and fails nothing. See [Variables](../../language/variables.md) and [Modules](../../language/modules.md).

## W0060

```text
a string here must document the declaration that follows it
```

A string written on its own as a docstring is followed by something it cannot document: an import, a `comptime assert`, a statement. A string in that place documents the declaration after it (a function, an archetype, a global); the first string of a module documents the module. It is a warning: `jac check` and `jac build` show it and go on, with status 0 when nothing else is wrong.

```jac
# expect: W0060
"""Settings for the build."""

"""Checks the configuration."""
comptime assert True;

with entry {
    print(1);
}
```

**Fix:** write a `#` comment, or move the string to the declaration it describes. `jac fmt --fix` deletes the stray string.

## W1051

```text
cannot infer {what}; {remedy}
```

A local or a global is bound to a value that does not say its type, and nothing else in the code does: an empty dict `{}`, `None`, `list()` or `set()` with no elements, a bare `list` as a value. `{what}` is what could not be typed, and `{remedy}` what to write. In Python an empty container holds anything; here a container has one element type, fixed where it is made.

```jac
# expect: W1051
with entry {
    d = {};
}
```

**Fix:** annotate it.

```jac
with entry {
    d: dict[str, int] = {};
    d["a"] = 1;
    print(d);
}
```

```output
{'a': 1}
```

For `z = None;`, write the type the variable will hold: `z: int | None = None;`.

## W1100

```text
cannot find module '{module}'
```

An import names a module that is not found: not a module of the project, not the standard library, not an installed Python or npm package. `{module}` is the name as written.

```jac
# expect: W1100
import nosuchmodule;

with entry {
    print(1);
}
```

**Fix:** correct the name, create the module, or install the package. A module's name is its path from the project's root, with `.` for `/` (`app/view.jac` is `app.view`). See [Modules](../../language/modules.md) (`jac docs modules`).

## W2001

```text
unknown name '{name}'
```

A name is read that is not defined: not a local, a parameter, a global, a declaration of the module, an import or a builtin. `{name}` is the name. A function declared further on in the same block is not defined yet where it is called. A misspelling, or a missing import, is the usual cause. Python's `pass` as a statement, an unknown name alone, is [E2225](e22-2.md#e2225) instead.

```jac
# expect: W2001
with entry {
    print(total);
}
```

**Fix:** define the name before it is read, import it, or correct the spelling.

```jac
with entry {
    total = 3;
    print(total);
}
```

```output
3
```
