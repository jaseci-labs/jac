# E1313-E1330: parallel loops, views and borrowed places

These errors cover the forms of a parallel `flow for`, splitting a region, views (objects that hold
a borrow), moving a value out of an owned field or element, writing through a shared borrow or
under a live one, the places `take()`, `swap()` and a borrow work on, and `&mut` of a value that is
copied. They are about the same ownership annotations as E1301 to E1311: `own`, `lin`, `imm`, `&`
and `&mut`.


## E1313

```text
`flow for` does not allow {what}
```

A `flow for` is written in a form a parallel loop cannot take. `{what}` names the form:

| `{what}` | Written |
|---|---|
| ``iterating a collection that is not lent: write `&xs` or `&mut xs` `` | `flow for x in xs` |
| `control flow that leaves its body` | a `break`, `return` or `yield` that is not inside a loop of the body's own |
| `an else` | `flow for ... { } else { }` |
| `a range whose step is not a constant` | `flow for i in range(0, n, k)` |
| `binding a chunk to anything but one name` | `flow for (a, b) in &mut xs.chunks(2)` |

A `flow for` over tensors, tiles or vectors reports its own forms under this code, each saying what
the loop must index or write.

```jac
# expect: E1313
with entry {
    xs = [1, 2, 3];
    flow for x in xs {
        print(x);
    }
}
```

**Fix:** lend the list to the loop, `flow for x in &xs`, or `&mut xs` when the body writes its
elements. Iterations run in any order and all of them run, so a loop that stops early is a plain
`for`. See [What crosses into a place](../../accel/crossing.md).

## E1314

```text
partition(n) takes a literal count; call partition() for each child
```

`r.partition(n)` splits region `r` into `n` child regions, given back as a tuple, so `n` is an int
literal of 1 or more. A count held in a variable is refused, because the number of children is part
of the tuple's type.

```jac
# expect: E1314
def split(k: int) {
    r: own Region = Region();
    (a, b) = r.partition(k);
}

with entry {
    split(2);
}
```

**Fix:** write the count, `(a, b) = r.partition(2);`, or call `partition()` again on a child for
each further split.

## E1315

```text
A view does not allow {what}
```

A view is an object of a class with a borrowed field (`has buf: &Buffer;`), or a container of such
objects. It lives no longer than what it borrows, so it is never owned and goes nowhere that could
outlive the borrow. `{what}` says where it went:

| `{what}` | Written |
|---|---|
| ``an `own` binding`` | `v: own Holder = Holder(buf=b);` |
| `storing it in a field or an element` | `self.h = v;`, `xs[0] = v;` |
| `storing it in module global '<name>'` | assigning it to a global |
| `storing it in a container (<method>())` | `xs.append(v)` on a list that is a parameter or a field |
| `returning it while it borrows '<name>'` | returning a view of a local of the function, not of what a parameter lends |

```jac
# expect: E1315
obj Buffer {
    has n: int = 0;
}

obj Holder {
    has buf: &Buffer;
}

def peek(b: &Buffer) {
    v: own Holder = Holder(buf=b);
    print(v.buf.n);
}

with entry {
    a: own Buffer = Buffer();
    peek(&a);
}
```

**Fix:** bind the view as a plain local, `v = Holder(buf=b);`, and use it where the borrow lives.

## E1316

```text
Cannot move '{name}' out of '{place}' without take()
```

An `own` field is moved into an owning binding by reading it: `b: own Buffer = p.inner;`.
`{name}` is the field and `{place}` the place as written. Reading an owned field leaves it holding
its value, so the value would have two owners.

```jac
# expect: E1316
obj Buffer {
    has n: int = 0;
}

obj Pair {
    has inner: own Buffer = Buffer();
}

def split(p: own Pair) -> own Buffer {
    b: own Buffer = p.inner;
    return b;
}

with entry {
    print(split(Pair()).n);
}
```

**Fix:** move it out with `take()`, which leaves `None` in the field, so the field is declared to
hold `None`:

```jac
obj Buffer {
    has n: int = 0;
}

obj Pair {
    has inner: own Buffer | None = Buffer();
}

def split(p: own Pair) -> own Buffer | None {
    b: own Buffer | None = take(p.inner);
    return b;
}

with entry {
    print(split(Pair()));
}
```

```output
Buffer(n=0)
```

## E1317

```text
Cannot move '{name}' out of the element '{place}'
```

An element of a list of owned values (`list[own T]`) is moved into an owning binding by indexing
it. `{name}` is the local the list is reached from and `{place}` the element, `{name}[...]`. Indexing
leaves the element in the list, so it would have two owners.

```jac
# expect: E1317
obj Buffer {
    has n: int = 0;
}

obj Bag {
    has items: list[own Buffer] = [];
}

def first(g: own Bag) -> own Buffer {
    b: own Buffer = g.items[0];
    return b;
}

with entry {
    print(first(Bag(items=[Buffer()])).n);
}
```

**Fix:** remove the element as you take it: `b: own Buffer = g.items.pop(0);`.

## E1318

```text
Cannot call mutating method '{method}' through a shared borrow of '{name}'
```

A method that changes its receiver is called through a shared borrow. `{method}` is the method and
`{name}` the borrow: a `&` parameter, or a local that a `&` borrow initialized. A shared borrow
reads; changing goes through `&mut`.

```jac
# expect: E1318
def drain(xs: &list[int]) {
    xs.clear();
}

with entry {
    ys = [1, 2];
    drain(&ys);
}
```

**Fix:** take and lend the value mutably:

```jac
def drain(xs: &mut list[int]) {
    xs.clear();
}

with entry {
    ys = [1, 2];
    drain(&mut ys);
    print(ys);
}
```

```output
[]
```

## E1319

```text
invalid {operation} place: {reason}
```

`take()`, `swap()` or a borrow is given what it cannot work on. `{operation}` is `take()`, `swap()`
or `borrow`, and `{reason}` says what it needs:

| `{operation}` | `{reason}` |
|---|---|
| `take()` | `it takes a field or local that can be None`: the argument is not a place |
| `take()` | `it leaves None, which <type> cannot hold`: the place's type has no `None` |
| `swap()` | `each place is lent with &mut`: written `swap(a, b)` |
| `swap()` | `it exchanges locals or fields` |
| `swap()` | `the places have one type, not <a> and <b>` |
| `borrow` | `a scalar is borrowed from a variable or a field`: a C function's borrow parameter is given `&` of a number that is not stored |
| `borrow` | `a complex is immutable, so '<field>' cannot be borrowed mutably`: `&mut c.real` given to a C function |

```jac
# expect: E1319
obj Cell {
    has v: int = 0;
}

def empty(c: &mut Cell) {
    v = take(c.v);
    print(v);
}

with entry {
    c: own Cell = Cell();
    empty(&mut c);
}
```

**Fix:** declare the place to hold `None` (`has v: int | None = 0;`), or read it without `take()`
when nothing is moved. For `swap()`, write `swap(&mut a, &mut b)` with two places of one type.

## E1320

```text
Cannot assign '{field}' through a shared borrow of '{name}'
```

A field is assigned through a shared borrow. `{field}` is the field and `{name}` the borrow, a `&`
parameter or a local bound to a `&` borrow.

```jac
# expect: E1320
obj Link {
    has v: int = 0;
}

def mark(head: Link) {
    cur: &Link = &head;
    cur.v = 3;
}

with entry {
    mark(Link());
}
```

**Fix:** borrow mutably, `cur: &mut Link = &mut head;`, or assign through the owner, `head.v = 3;`.

## E1321

```text
Cannot write '{field}' while the borrow '{name}' reads through it
```

A borrow reached its value through a field, as `cur = &head.next` does through `next`, and that
field is assigned while the borrow is still in use. `{field}` is the field and `{name}` the borrow.
Replacing the field may release the value the borrow reads.

```jac
# expect: E1321
obj Link {
    has v: int = 0,
        next: Link | None = None;
}

def cut(head: Link) -> Link | None {
    cur: &Link | None = &head.next;
    head.next = None;
    return cur;
}

with entry {
    print(cut(Link()));
}
```

**Fix:** finish with the borrow before the write, or keep a reference of your own instead of a
borrow: `cur = head.next;`.

## E1322

```text
Call to '{callee}' may write '{field}' while the borrow '{name}' reads through it
```

The same as E1321, through a call: `{callee}` may write `{field}`, which the borrow `{name}`
walked through, while the borrow is still in use. The callee is a function or method whose body,
or what it calls, assigns the field, a builtin method that removes items, or a call the compiler
cannot follow (which may write anything).

```jac
# expect: E1322
obj Link {
    has v: int = 0,
        next: Link | None = None;
}

def unlink(l: Link) {
    l.next = None;
}

def cut(head: Link) -> Link | None {
    cur: &Link | None = &head.next;
    unlink(head);
    return cur;
}

with entry {
    print(cut(Link()));
}
```

**Fix:** make the call after the borrow's last use, or keep a reference instead of a borrow:
`cur = head.next;`.

## E1323

```text
Borrow '{name}' must start at a parameter, `self`, an `own` value or another borrow
```

A borrow `{name}` is taken of a value that no binding is answerable for: a plain local, not a
parameter, `self`, an `own` value or another borrow. A borrow is checked against the binding it
starts at, so that binding states who owns the value.

```jac
# expect: E1323
obj Link {
    has v: int = 0,
        next: Link | None = None;
}

def second -> Link | None {
    head = Link(v=1);
    cur: &Link | None = &head.next;
    return cur;
}

with entry {
    print(second());
}
```

**Fix:** declare the local an owner, `head: own Link = Link(v=1);`, or read the field without
borrowing: `cur = head.next;`.

## E1328

```text
'{name}' borrows mutably; lend it with &mut
```

A parameter declared `&mut` is given a shared borrow, `&x`. `{name}` is the parameter. The callee
may change the value, so the caller lends it mutably and says so at the call.

```jac
# expect: E1328
obj Buffer {
    has n: int = 0;
}

def bump(b: &mut Buffer) {
    b.n += 1;
}

def run {
    a: own Buffer = Buffer();
    bump(&a);
    print(a.n);
}

with entry {
    run();
}
```

**Fix:** lend with `&mut`: `bump(&mut a);`.

## E1330

```text
a mutable borrow of {type} cannot reach the value: a scalar is copied, so lend storage that holds it
```

`&mut` is applied to a scalar such as a number or a bool (`{type}` is its type), or a `for` loop
takes a list of scalars with `&mut`. A scalar is copied wherever it goes, so changing the copy would not change the value the
borrow was meant to reach.

```jac
# expect: E1330
with entry {
    fs = [1.0, 2.0];
    for v in &mut fs {
        print(v);
    }
}
```

**Fix:** write the element through its index, or lend the object or list that holds the number:

```jac
with entry {
    fs = [1.0, 2.0];
    for i in range(len(fs)) {
        fs[i] = fs[i] * 2.0;
    }
    print(fs);
}
```

```output
[2.0, 4.0]
```

A `&mut` loop over a list of structs lends each element where it is. See
[Packed lists](../../language/packed-lists.md).
