# E1200-E1209: special methods, casts and patterns

These errors come from the type checker. They are reported where a statement or operator calls a
method the class must declare in a fixed shape (`__enter__`, `__next__`, `__contains__`), and for a
`yield`, an `as` cast, a class pattern, an `except` clause, a keyword argument, a `wait` or a
property that cannot mean what was written.

Each entry gives the message template as the compiler holds it. A name in braces is filled in when
the error is reported.

## E1200

```text
{method} must {requirement}
```

A method the language calls for you is declared in a shape that call cannot use. `{method}` names
the method (for `__exit__`, one of its parameters), and `{requirement}` says what it has to take or
return.

| Called by | Method | Requirement |
|---|---|---|
| `with` | `__enter__` | an instance method that takes no arguments |
| `with` | `__exit__` | an instance method that takes three positional arguments: the exception's type (typed `any`), the exception (`any`, or `BaseException` or `None`) and its traceback (`any`, or `traceback` or `None`) |
| `for`, `next()` | `__iter__`, `__next__` | take no arguments |
| a binary operator | `__add__`, `__lt__`, ... | take one argument |
| a unary operator | `__neg__`, ... | take no arguments |
| `in`, `!=` | `__contains__`, `__eq__` | return `bool` |
| `copy.copy()` | `__copy__` | take no arguments and return an object |
| `copy.deepcopy()` | `__deepcopy__` | take the copies made so far, a dict[int, any], and return an object |
| `int()`, `float()` | `__int__`, `__float__`, `__index__` | return the type converted to |
| `a < b < c` | each comparison of the chain | give `bool` |

```jac
# expect: E1200 x3
obj Door {
    def __enter__(key: int) -> Self {
        return self;
    }

    def __exit__(exc_type: any, exc: any, tb: Door | None) -> None {}

    def __deepcopy__ -> Door {
        return Door();
    }
}

with entry {
    with Door() as d {
        print("in");
    }
}
```

**Fix:** declare the method as the requirement says. Here `__enter__` takes nothing,
`def __enter__ -> Self`, `__exit__` takes the traceback as an `any`, `tb: any`, and `__deepcopy__`
takes the copies made so far, `def __deepcopy__(memo: dict[int, any]) -> Door`. See [Methods](../../language/methods.md).

## E1201

```text
slice step cannot be zero
```

A tuple is sliced with a step that is the constant 0, as in `t[::0]`. A tuple's slice is taken at
compile time, so its bounds and step are constants, and no slice has a step of zero. A list's slice
with a zero step is not known until the program runs, and raises `ValueError` with the same words.

```jac
# expect: E1201
with entry {
    t = (1, 2, 3);
    print(t[::0]);
}
```

**Fix:** give a step that is not zero, or leave it out for a step of 1: `t[::2]`, `t[::-1]`,
`t[1:]`. See [Collections](../../language/collections.md).

## E1202

```text
yield needs a function declared to return Iterator[T]
```

A function holds a `yield`, and its declared return type is not `Iterator[T]`. A function is a
generator only when its signature says so; one with no return type, or with the type of the values
it yields, is refused.

```jac
# expect: E1202
def count {
    yield 1;
}

with entry {
    count();
}
```

**Fix:** declare what the generator yields: `def count -> Iterator[int]`. In Python the `yield`
alone makes a function a generator; here the return type does too.

```jac
def count -> Iterator[int] {
    yield 1;
}

with entry {
    print(list(count()));
}
```

```output
[1]
```

## E1203

```text
cannot cast {type} to {target}{hint}
```

`x as T` asserts that `x` is a `T`; it never converts. The cast is refused when the value's type
`{type}` and the target `{target}` are unrelated, so that no value of one is ever the other, when
a `float` is cast to an int type or to `bool`, and when an int type is cast to one that does not
hold all of its values (`n as i8` of an `int`). `{hint}` is empty, or says what to use instead.

```jac
# expect: E1203 x2
with entry {
    print(3.9 as int);
    n = 300;
    print(n as i8);
}
```

**Fix:** convert with the type's constructor: `int(3.9)`, `str(n)`, `float(s)`, `i8(n)` (which
raises `OverflowError` out of range; `i8.wrap(n)` wraps). Keep `as` for a
value whose static type is wider than what it holds: an `any`, a union, a base class. See
[Types](../../language/types.md).

## E1204

```text
too many positional patterns for {class}(): it takes {count}, found {given}
```

A class pattern lists more positional sub-patterns than the class has fields. `{class}` is the
class, `{count}` the number of fields it declares and `{given}` the number of sub-patterns written.
A builtin scalar type (`int`, `str`, `float`, ...) takes one.

```jac
# expect: E1204
obj Pt {
    has x: int,
        y: int;
}

def show(p: Pt) -> str {
    match p {
        case Pt(a, b, c):
            return "three";
    }
    return "other";
}
```

**Fix:** write one sub-pattern for each field, in the order the class declares them, or fewer:
`case Pt(a, b):`.

## E1205

```text
{what} must name a class
```

Something that takes a class is given what is not one. `{what}` is `a class pattern`, for a
`case Name(...)` whose `Name` is not a class (a function, a variable, an enum) or, with
sub-patterns, not a class with fields; or `each argument of issubclass()`.

```jac
# expect: E1205
def show(v: any) -> str {
    match v {
        case complex(re):
            return "complex";
    }
    return "other";
}
```

**Fix:** name a class of the program in the pattern. To test only the type of a value, write the
pattern with no sub-patterns and bind the value with `as`: `case complex() as c:`.

## E1206

```text
{what} is not an exception class
```

An `except` clause names something that is not a class derived from `BaseException`. `{what}` is
the name as the clause wrote it, in quotes, or `this expression`. A misspelled or unimported
exception name is the usual cause.

```jac
# expect: E1206
with entry {
    try {
        print(1);
    } except Missing {
        print(2);
    }
}
```

**Fix:** name an exception class: a builtin one (`except ValueError`), or one the module declares
or imports (`obj Missing(Exception) {}`). See [Builtin exceptions](../../library/exceptions.md).

## E1207

```text
keyword arguments need str keys, not {type}
```

A keyword argument's name becomes a `str` key, and the dict that receives it has keys of `{type}`.
`d.update(a=3)` on a `dict[int, int]` is the common case.

```jac
# expect: E1207
with entry {
    d: dict[int, int] = {1: 2};
    d.update(a=3);
    print(d);
}
```

**Fix:** pass the pairs as a dict of the right key type, `d.update({3: 4})`, or assign the item,
`d[3] = 4`. See [Collections](../../language/collections.md).

## E1208

```text
wait needs a task started with flow, not {type}
```

`wait` is given a value of `{type}`, which is not a task. `wait` takes the task that `flow` started
and gives its result. Writing `wait f()` waits on what `f()` returns, not on a task.

```jac
# expect: E1208
def work -> int {
    return 1;
}

with entry {
    print(wait work());
}
```

**Fix:** start the call with `flow` and wait on the task it gives. For a coroutine (an `async def`),
the word is `await`, not `wait`.

```jac
def work -> int {
    return 1;
}

with entry {
    t = flow work();
    print(wait t);
}
```

```output
1
```

## E1209

```text
{owner}.{name} has no getter
```

A property is read, and it declares no `getter`. `{owner}` is the class and `{name}` the property.
A property with only a `setter` can be assigned and nothing else.

```jac
# expect: E1209
obj Temp {
    has _c: float = 0.0;

    has celsius: float {
        setter(v: float) {
            self._c = v;
        }
    }
}

with entry {
    t = Temp();
    print(t.celsius);
}
```

**Fix:** give the property a getter beside its setter: `getter { return self._c; }`. See
[Fields](../../language/fields.md).
