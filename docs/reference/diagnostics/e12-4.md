# E1263-E1289: archwire rules, reports, coroutines, interfaces, npm trees and phone apps

This page holds five groups of errors:

- E1263 to E1276 are about `archwire.jac`'s `graph spaces` blocks: a line whose feature is not built
  yet, and what the spaces, apps and profiles a project declares must agree on. They need a project,
  so their entries show the lines that raise them instead of a whole program. See
  [Archwire](../../apps/archwire.md) (`jac docs archwire`).
- E1277 to E1279 are about a walker's typed reports, a coroutine that is never run, and a space's
  pages under a `ui` plugin that has no file routes.
- E1280 to E1286 are about interfaces, bounded type parameters and `where` clauses.
- E1287 and E1288 are about which of `jac.toml`'s npm trees a space's packages come from. They
  need a project too. See [Packages](../../toolchain/packages.md) (`jac docs packages`).
- E1289 is about the identifier a phone app is installed under. It needs a project too. See
  [UI plugins and bundlers](../../apps/ui-bindings.md#expo).

## E1263

```text
an app grants space '{space}' '{grant}', and grants aren't built yet: there is no embedded wasm space to grant to
```

An app grants a space a capability, with a line such as `api has fs.read;` inside
`app other { ... }`. `{space}` is the space and `{grant}` the capability. Grants are for embedded
wasm spaces, which are not built yet.

**Fix:** remove the grant from the app.

## E1264

```text
'{name}' is space '{space}''s: a call of it crosses to that space, and it is called there, never a value here
```

A function of another space is used as a value: assigned, passed or stored, as in `f = plain;`.
`{name}` is the function and `{space}` the space that holds it. A call of such a function crosses
to its space and runs there; the function itself never exists in the calling space, so there is no
value to hold.

**Fix:** call it where it is wanted (`plain()`), or wrap the call in a function of this space and
pass that: `f = lambda -> int { return plain(); };`. See [Crossings](../../apps/crossings.md).

## E1270

```text
space '{space}' has more than one entry: a space's program starts at one module
```

A space declares more than one `entry` module. `{space}` is the space. A space's program starts at
one module.

It arises for `space api: native { entry main; entry other; svc; }`.

**Fix:** keep one `entry` line and list the other module as an ordinary member of the space:
`entry main; other; svc;`.

## E1271

```text
a profile holds only apps, so {what} belongs in the unnamed `graph spaces` block, not in profile '{profile}'
```

A named `graph spaces` block, a profile, holds something that is not an app. `{what}` describes the
line (`space 'extra'`) and `{profile}` is the profile. A profile regroups the project's spaces into
other apps; the spaces themselves are the same under every profile, and are declared once, in the
unnamed block.

It arises for `graph spaces fleet { space extra: native { extra; } }`.

**Fix:** move the line to the unnamed `graph spaces { ... }` block and leave only `app` declarations
in the profile.

## E1272

```text
app '{app}' serves '{space}', a {host} space: an app serves browser and wasm spaces, and runs the others
```

An app serves a space that is not handed to a browser. `{app}` is the app, `{space}` the space and
`{host}` its host. `serve` sends a `browser` or `wasm` space's files to the client; a space on any
other host is run by the app.

It arises for `app web { serve tool; }` where `tool` is a `native` space.

**Fix:** list the space under `run`: `app web { run tool; }`.

## E1273

```text
app '{app}' {how} '{space}', and no space of that name is declared
```

An app names a space that no `space` line declares. `{app}` is the app, `{how}` is `runs` or
`serves` and `{space}` the name written. A misspelled space name is the usual cause.

It arises for `app web { serve nowhere; }` with no `space nowhere`.

**Fix:** correct the name, or declare the space in the unnamed block:
`space nowhere: browser { pages.*; }`.

## E1274

```text
archwire.jac has no profile '{profile}': {known}
```

`--profile {profile}` names a profile `archwire.jac` does not declare. `{known}` lists the ones it
does: `it declares none`, `its profile is 'fleet'`, or `its profiles are 'a' and 'b'`.

It arises on `jac build api --profile nosuch`. It arises too where `profiles` in `jac.toml`'s
`[apps.<app>]` lists a name that is no profile; `{known}` then says where the name is:
`jac.toml's [apps.shop] profiles names it`.

**Fix:** pass a declared profile, or declare this one as a named block of apps:
`graph spaces nosuch { app solo { run api; } }`. Without `--profile`, the apps are the unnamed
block's, which `profiles` names `default`
([Building apps](../../apps/building.md#several-arrangements-in-one-artifact)).

## E1275

```text
spaces '{first}' and '{second}' both hold '{pattern}': a module is in one space, so two can't name it alike
```

Two spaces list the same module or pattern. `{first}` and `{second}` are the spaces and `{pattern}`
what both hold. A module belongs to one space; the same line in two would put it in both.

It arises for `space api: native { svc; }` beside `space site: browser { svc; }`.

**Fix:** keep the module in the space whose host it runs on. The other space reaches its functions
by a wire in `graph import`, and a call over that wire crosses between the spaces.

## E1276

```text
'{caller}' calls space '{space}', which no app of {apps} runs or serves
```

A space that an app runs calls another space, and no app runs or serves that one. `{caller}` is the
calling space, `{space}` the one called and `{apps}` the group of apps checked:
``the unnamed `graph spaces` block``, or `profile '<name>'`. Every profile is checked, since a profile changes
which app holds a space and never whether the space runs.

It arises when profile `fleet` redeclares `app cli` without the space `work` that it ran in the
unnamed block, while a module of space `api` is wired to a module of `work`.

**Fix:** list the called space under `run` (or `serve`, for a browser space) in an app of that
block or profile.

## E1277

```text
this `report` adds to the reports of whichever walker it runs for, and {walker} declares its reports' type: report from an ability of the walker that declares them, or of walkers that don't
```

A walker that declares `has reports: list[T]` takes each `report` as a `T`. This `report` is in an
ability that may run for that walker but cannot be checked against it: an ability of a node or
edge that names no walker, or an ability of a base walker that the declaring walker inherits.
`{walker}` is the walker that declares its reports' type.

```jac
# expect: E1277
obj Leg {
    has to: str;
}

node Port {
    has name: str;

    can note with entry {
        report self.name;
    }
}

walker Route {
    has reports: list[Leg] = [];

    can sail with Port entry {
        report Leg(to=here.name);
    }
}

with entry {
    print((Port(name="x") spawn Route()).reports);
}
```

**Fix:** report from an ability of the walker that declares the type, where the value is checked
(`can sail with Port entry { report Leg(to=here.name); }`), or name in the node's ability the
walkers it runs for, none of which declares its reports: `can note with Plain entry`. See [Walkers](../../language/walkers.md) and [Abilities](../../language/abilities.md).

## E1278

```text
this makes a coroutine and lets it go, so it never runs: `await` it, or give it to what will
```

A statement calls an `async def` and drops the result. The call only makes a coroutine; nothing in
it runs until the coroutine is awaited. Python accepts this and warns "coroutine was never awaited"
when the program runs; here it is an error.

```jac
# expect: E1278
async def save(n: int) {
    print(n);
}

async def all_of {
    save(1);
}
```

**Fix:** `await save(1);` in an `async def`. To run it later, keep the coroutine and hand it to
what will await it.

## E1279

```text
'{module}' is a page of space '{space}', whose `ui` plugin '{name}' has no file routes: under it the space's entry module renders into the page itself
```

A browser space holds a module below `pages/`, and its `ui` plugin does not say how a routed app
starts, so the page would have no route. `{module}` is the first such module, `{space}` the space
and `{name}` its plugin. Of the `ui` plugins jac ships only `react` has file routes; a
project's own has them when its `[ui]` table names `boot`, the module whose `startApp` starts a
routed app. The error is reported once, at the space's declaration in `archwire.jac`.

It arises for `space site: browser { entry web; pages.*; }` with `pages/index.jac` in the project
and `plugin = "solid"` under `[spaces.site.ui]` in `jac.toml`.

**Fix:** leave the space on the `react` plugin, the standard one for a browser space, or take the
pages out of the space and render from its `entry` module's `with entry` block, with the library's
own function. See [UI plugins and bundlers](../../apps/ui-bindings.md#only-react-has-file-routes) and
[Pages](../../apps/pages.md).

## E1280

```text
{name} is {what}, which has no instances: construct a class that conforms to it
```

An interface is called as a constructor. `{name}` is the interface, and `{what}` is `an interface`
or `a type parameter bounded by interfaces`. An interface is an `obj` with no fields whose every
member is an abstract ability or a compile-time member with no value; it says what a class
provides and has no instances of its own. Python refuses to instantiate an abstract base class
when the program runs; here it is refused when it is compiled.

```jac
# expect: E1280
obj Shape {
    def area -> float abst;
}

with entry {
    s = Shape();
}
```

**Fix:** construct a class that lists the interface as a base and defines its abilities:
`obj Circle(Shape) { ... }`, then `s = Circle(r=1.0);`.

## E1281

```text
{cls} conforms to interface {iface}, and gives no {member}
```

A class lists an interface among its bases and leaves out something the interface requires.
`{cls}` is the class, `{iface}` the interface and `{member}` what is missing: `method scale`, or
`compile-time member BYTES`. A method the class itself declares `abst` counts as missing.

```jac
# expect: E1281
obj Shape {
    def area -> float abst;
    def scale(k: float) -> Self abst;
}

obj Blob(Shape) {
    has r: float;

    def area -> float {
        return self.r;
    }
}
```

**Fix:** define every ability the interface declares, here
`def scale(k: float) -> Self { return Blob(r=self.r * k); }`, and give every compile-time member a
value.

## E1282

```text
{cls}'s {member} {found}, and interface {iface} requires {wanted}
```

A class gives a member its interface requires, with another signature or type. `{cls}` is the
class, `{member}` the method or compile-time member, `{found}` what the class declares, `{iface}`
the interface and `{wanted}` what it declares. A method conforms with the same parameter names and
types, and a return type that is the interface's or a subclass of it.

```jac
# expect: E1282
obj Shape {
    def area -> float abst;
}

obj Wrong(Shape) {
    has r: float;

    def area -> int {
        return 1;
    }
}
```

**Fix:** declare the member as the interface does: `def area -> float`. Parameter names are part
of the signature: `def scale(f: float)` does not give `def scale(k: float)`.

## E1283

```text
{type} does not conform to {iface}, which {what} is bounded by
```

A type parameter is bounded by an interface, and the type given for it does not conform. `{type}`
is the type, `{iface}` the interface and `{what}` the parameter (`total()'s T`). The type is the
one written in brackets or the one found from the arguments. A class conforms only by listing the
interface among its bases; having methods of the right names is not enough.

```jac
# expect: E1283
obj Shape {
    def area -> float abst;
}

def total[T: Shape](xs: list[T]) -> float {
    t = 0.0;
    for x in xs {
        t += x.area();
    }
    return t;
}

with entry {
    print(total([1, 2]));
}
```

**Fix:** pass values of a class that conforms, or make the class conform: add the interface to its
bases and define what it requires.

## E1284

```text
{callee} is checked where it is declared against its bounds, {bounds}, and its body uses what they do not provide
```

A function or class with bounded type parameters is checked once, where it is declared, knowing of
each type parameter only what its bounds provide. `{callee}` is the function or class and
`{bounds}` its bounds (`T: Shape`). Its body uses something they do not provide; the error
reported with this one, at the use, says what.

It always comes with that second error. For example, with `obj Shape { def area -> float abst; }`,
the function `def perimeter[T: Shape](x: T) -> float` whose body returns `x.perimeter()` is refused
with E1284 at the declaration and E1030 (`T has no method 'perimeter'`) at the call.

**Fix:** add what the body uses to the interface (`def perimeter -> float abst;` in `Shape`), bound
the parameter by another interface that has it as well (`T: Shape & Edged`), or stop using it.

## E1285

```text
the where clause of {callee} does not hold for {args}{detail}
```

A `where` clause is a compile-time condition on a function's or archetype's compile-time
parameters, and it is false for the arguments given. `{callee}` is the function or archetype,
`{args}` the arguments (`N=-1`) and `{detail}` the clause's message after a colon, when it has one.

```jac
# expect: E1285
def doubled[comptime N: int](x: int) -> int where N >= 0, "N counts doublings" {
    return x * N;
}

with entry {
    print(doubled[-1](3));
}
```

**Fix:** give arguments the condition accepts: `doubled[2](3)`.

## E1286

```text
{cls}'s compile-time member {name} has no value: only an interface's members are required ones
```

A class declares a compile-time member with no value, and the class is not an interface. `{cls}` is
the class and `{name}` the member. Only an interface leaves a compile-time member for its
conforming classes to give. A class with a field or a method body is not an interface.

```jac
# expect: E1286
obj Half {
    has x: int = 0;
    comptime N: int;
}

with entry {
    print(Half().x);
}
```

**Fix:** give the member its value: `comptime N: int = 2;`.

## E1287

```text
space '{space}' takes its npm packages from the tree '{tree}', which jac.toml does not declare: a tree is a table, [npm.<tree>]
```

A space names an npm tree that `jac.toml` does not declare. `{space}` is the space and `{tree}` the
name its `[spaces.<space>]` table gives as `npm`. A tree is a `[npm.<tree>]` table, which is that
tree's `package.json`. It is reported where a module of the space first imports from npm.

```toml
[spaces.site]
npm = "wbe"

[npm.web.dependencies]
nanoid = "^5"
```

```text
web.jac:1:1: error[E1287]: space 'site' takes its npm packages from the tree 'wbe', which jac.toml does not declare: a tree is a table, [npm.<tree>]
```

**Fix:** name a tree `jac.toml` declares (`npm = "web"`), or declare the one named:
`jac install --npm nanoid --tree wbe` makes it.

## E1288

```text
{who} imports from npm, and jac.toml declares the trees {trees}: a space says which is its own, `npm = "<tree>"` under its [spaces.<space>]
```

A module imports an npm package, `jac.toml` declares several npm trees, and nothing says which one
the import resolves in. `{who}` is the space, or the program when it is of no space, and `{trees}`
the trees declared. A project with one tree needs no naming: that tree is every space's.

```toml
[npm.web.dependencies]
nanoid = "^5"

[npm.mobile.dependencies]
expo = "~54.0.0"
```

```text
web.jac:1:1: error[E1288]: space 'site' imports from npm, and jac.toml declares the trees web, mobile: a space says which is its own, `npm = "<tree>"` under its [spaces.<space>]
```

**Fix:** name the space's tree in `jac.toml`:

```toml
[spaces.site]
npm = "web"
```

A program of no space (a module built by itself in a project with no `graph spaces`) has no table
to name one in: keep such a project to one tree.

## E1289

```text
app '{app}' is installed as '{identifier}', which is no application identifier: one is two or more names joined by dots, each a letter and then letters, digits and underscores (dev.example.app)
```

An app that runs a `hermes` space is a phone app, and a phone installs it under an application
identifier: `identifier` under the app's `[apps.<app>]` in `jac.toml`, or `app.jac.<app>` where
there is none. `{app}` is the app and `{identifier}` what its table gives. Android takes only
names joined by dots, at least two, each starting with a letter.

```toml
[apps.mobile]
identifier = "diffwalker"
```

```text
archwire.jac:5:5: error[E1289]: app 'mobile' is installed as 'diffwalker', which is no application identifier: one is two or more names joined by dots, each a letter and then letters, digits and underscores (dev.example.app)
```

**Fix:** give an identifier of that shape, by convention a domain you own, reversed, and then the
app:

```toml
[apps.mobile]
identifier = "dev.diffwalker.mobile"
```
