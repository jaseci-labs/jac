# E1229-E1248: specialization, fields, tensors and reflection

These errors come from the type checker. They cover a copy of a function or class that cannot be
made for the compile-time arguments given, a subclass's fields, tensor types and their uses, and
the compile-time reflection functions of `jaclang.comptime` (`fields`, `get_field`, `set_field`,
`restore`, `params`, `args_type`, `kind`, `type_args`).

For the constructs themselves see [Inheritance](../../language/inheritance.md).

## E1229

```text
{callee} cannot be specialized for {types}
```

A function or class with compile-time parameters is copied for each set of arguments it is given,
and the copy for these arguments could not be made. `{callee}` is the function or class, and
`{types}` the compile-time arguments: types, values, or the arguments as written. This error marks
the call that asked for the copy, and it always comes with a second error, reported inside the copy,
that says what is wrong there. For example, take
`def positive[comptime N: int](x: int) -> int`, whose body holds
`comptime assert N > 0, "N is positive";`. The call `positive[-1](3)` is refused with E1229 at the
call and E0109 at the assertion.

**Fix:** read the other error and give arguments the body accepts: `positive[2](3)`.

## E1230

```text
field {name} of {base} is {type}; a subclass cannot declare it again as {found}
```

A subclass declares a field its base already has, with another type. `{name}` is the field,
`{base}` the class that declares it first, `{type}` its type there and `{found}` the type the
subclass wrote. The base's own methods read the field as `{type}`, so a subclass may repeat the
declaration only to change the default.

```jac
# expect: E1230
obj Base {
    has x: int = 1;
}

obj Sub(Base) {
    has x: str = "s";
}

with entry {
    print(Sub().x);
}
```

**Fix:** keep the base's type (`has x: int = 2;`), or give the new field a name of its own. See
[Inheritance](../../language/inheritance.md).

## E1231

```text
{cls} declares field {name} with no default, which the init it takes from {base} does not set: write it an init
```

A class with no `init` of its own takes the `init` its base wrote, and that `init` knows nothing of
the fields the subclass adds. `{cls}` is the subclass, `{name}` a field it declares without a
default and `{base}` the class whose `init` it takes. The field would be left unset.

```jac
# expect: E1231
obj Pair {
    has total: int = 0;

    def init(x: int, y: int) {
        self.total = x + y;
    }
}

obj Tagged(Pair) {
    has tag: str;
}

with entry {
    print(Tagged(1, 2).total);
}
```

**Fix:** give the field a default (`has tag: str = "none";`), or write the subclass an `init` that
sets it. See [Inheritance](../../language/inheritance.md) and [Fields](../../language/fields.md).

## E1233

```text
a tensor holds numbers, of an int type, a float type or bool, or structs of plain data, not {type}
```

A tensor type names an element type that a tensor cannot hold. `{type}` is the element type
written. A tensor is a block of numbers: its element is an int type, a float type, `bool`, or a
struct whose fields are plain data. A `str`, a list or an object is a reference, not a number.

```jac
# expect: E1233
import from accel { tensor }

with entry {
    words: tensor[str, 3] | None = None;
}
```

**Fix:** use a number type for the element (`tensor[f32, 3]`, `tensor[i64, 3]`), or keep
references in a list: `list[str]`. See [Tensors](../../accel/tensors.md)
(`jac docs tensors`).

## E1234

```text
a tensor's dimension is a compile-time int that is not negative, or `_` for one known when the program runs
```

A dimension in a tensor type is a negative number. Each dimension after the element type is an int
known at compile time, zero or more, or `_` for a length known only when the program runs.

```jac
# expect: E1234
import from accel { tensor }

with entry {
    less: tensor[f32, -1] | None = None;
}
```

**Fix:** write the length (`tensor[f32, 3]`) or `_` (`tensor[f32, _]`). A `-1` that stands for
"whatever length", as in a NumPy shape, is `_` here. See [Tensors](../../accel/tensors.md).

## E1235

```text
{what} takes {expected}, found {actual}
```

An operation on tensors, arrays, vectors or kernels is given the wrong number of something.
`{what}` names the operation, `{expected}` what it takes and `{actual}` what was written. It covers
the indices of a tensor's item, the axes of `transpose()`, the extents of `blocks()`, the values an
array is made from and the arguments of a kernel's `launch()` and `run()`.

```jac
# expect: E1235
import from accel { tensor }

with entry {
    a = tensor[f32, 3]([1.0, 2.0, 3.0]);
    print(a[0, 1]);
}
```

**Fix:** give as many as the message says. A tensor's item takes one index for each dimension, so
a `tensor[f32, 3]` is indexed `a[0]` and a `tensor[f32, 2, 3]` is indexed `m[0, 1]`. See
[Tensors](../../accel/tensors.md).

## E1239

```text
{callee} names a field, and {type}'s '{name}' is not one
```

`get_field()` or `set_field()` (`{callee}`) names a member that is not a field. `{type}` is the
class and `{name}` the member, which is a method or a property. These functions read and write the
fields a class declares with `has`.

```jac
# expect: E1239
import from jaclang.comptime { get_field }

obj P {
    has a: int;

    def total -> int {
        return self.a;
    }
}

def read(p: P) -> int {
    return get_field(p, "total")();
}
```

**Fix:** name a field (`get_field(p, "a")`), and call a method the ordinary way: `p.total()`.

## E1240

```text
set_field() is a statement of its own: it gives no value
```

`set_field()` is used as an expression: assigned, passed or returned. It sets a field and gives
nothing back.

```jac
# expect: E1240
import from jaclang.comptime { set_field }

obj P {
    has a: int;
}

with entry {
    p = P(a=1);
    x = set_field(p, "a", 2);
}
```

**Fix:** write the call as a statement: `set_field(p, "a", 2);`. Read the field afterwards with
`p.a` or `get_field(p, "a")` if its value is wanted.

## E1241

```text
'{name}' is used before set_field() sets its field '{field}'
```

`restore(T)` makes an instance of `T` without running its `init`, so every field that has no
default is unset until `set_field()` sets it. `{name}` is the restored local and `{field}` a field
that may still be unset where the local is used: returned, passed, or read. A `set_field()` inside
one arm of an `if`, inside a loop or inside one `case` does not count for the code after it.

```jac
# expect: E1241
import from jaclang.comptime { restore, set_field }

obj P {
    has a: int,
        b: int;
}

def make -> P {
    o = restore(P);
    set_field(o, "a", 1);
    return o;
}
```

**Fix:** set every field that has no default, on every path, before the first use:
`set_field(o, "b", 2);` before the `return`.

## E1242

```text
restore() gives a local its value: write `{name} = restore(...);`
```

`restore()` is written anywhere but as the whole value of a plain assignment to one local, with no
type annotation. `{name}` is the name the message suggests for that local: the assignment's own
target when it has one, else `x`. The compiler follows the restored local to check that its fields
are set (E1241), so the instance starts in a local.

```jac
# expect: E1242
import from jaclang.comptime { restore }

obj P {
    has a: int = 0;
}

def make -> P {
    return restore(P);
}
```

**Fix:** bind it first, then use the local: `o = restore(P);` and `return o;`.

## E1243

```text
{callee} cannot take {type} apart
```

A reflection function is asked about a type it has nothing to say of. `{callee}` is the function
and `{type}` the type. `fields()` and `restore()` take a class of the program, `type_args()` a type
written with arguments (`list[int]`, `dict[str, int]`, a tuple), `members()` an enum, and `bits()`
and `signed()` a number type.

```jac
# expect: E1243
import from jaclang.comptime { fields }

with entry {
    comptime for f in fields(int) {
        print(f.name);
    }
}
```

**Fix:** pass a type the function applies to, such as a class of the program for `fields()`.

## E1244

```text
{what} is a compile-time {kind}, not a type
```

A compile-time value that is not a type is written where a type is wanted. `{what}` is the
expression and `{kind}` what it is: `int`, `str`, `list`, `record`, `function` and so on.

```jac
# expect: E1244
import from jaclang.comptime { fields }

with entry {
    comptime n = 3;
    comptime for f in fields(n) {
        print(f.name);
    }
}
```

**Fix:** pass the type itself (`fields(P)`), not a value. See
[Compile-time evaluation](../../language/compile-time.md).

## E1245

```text
{what} is a compile-time {kind}, which no value of the program is
```

A type, a reflection record or a function known at compile time is used where the running program
needs a value, alone or inside a collection. `{what}` is the expression (or the reflection function
that made it) and `{kind}` is `type`, `record` or `function`, or what holds one: `list holding a
record` for `print(fields(P))`. Such values exist only while the program is compiled:
`print(type_args(list[int])[0])` has nothing to print when the program runs. What a record holds
that is a value is one: `fields(P)[0].name` is a str.

```jac
# expect: E1245
import from jaclang.comptime { type_args }

with entry {
    print(type_args(list[int])[0]);
}
```

**Fix:** keep the value at compile time, in a `comptime` binding, and use it as a type there:
`comptime T = type_args(list[int])[0];` then `x: T = 3;`. See
[Compile-time evaluation](../../language/compile-time.md).

## E1247

```text
{callee} takes a function, not {what}
```

A reflection function that takes a function is given something else. `{callee}` is the function
called (`params()`, `args_type()`, `apply()`) and `{what}` the argument as written, or
`an ability`: `args_type()` describes a function, or a method named by its class
(`args_type(Greeter.greet)`), not an ability, which a walk calls.

```jac
# expect: E1247
import from jaclang.comptime { params }

with entry {
    comptime n = 3;
    comptime for p in params(n) {
        print(p.name);
    }
}
```

**Fix:** pass a function by name: `params(spread)`.

## E1248

```text
{callee} cannot make a record of the parameters of '{name}': it takes {what}
```

`params()` or `args_type()` (`{callee}`) describes a function's parameters as a record with one
field for each, and function `{name}` has parameters no record can list. `{what}` says which:
`*args or **kwargs`, `type parameters` or `compile-time parameters`.

```jac
# expect: E1248
import from jaclang.comptime { fields, args_type }

def spread(*xs: int) -> int {
    return len(xs);
}

with entry {
    comptime for f in fields(args_type(spread)) {
        print(f.name);
    }
}
```

**Fix:** pass a function whose parameters are each named and typed, such as
`def spread(a: int, b: int) -> int`.
