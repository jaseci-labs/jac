# E1301-E1311: moves, borrows, regions and imm

These errors hold a program to its ownership annotations: an `own` or `lin` binding owns its value
and hands it on when it is assigned or passed, `&x` and `&mut x` lend a value without handing it on,
`imm` freezes one, and a `Region` holds what is allocated inside `in r { ... }`. Code that writes no
annotation is not checked for moves; the errors start where a binding says it owns or borrows.


In the examples, `Buffer` is a small class: `obj Buffer { has n: int = 0; }`.

## E1301

```text
Use of '{name}' after it was moved
```

An `own` or `lin` binding is read after its value was moved out of it. `{name}` is the binding.
Assigning an owned value to another name, passing it to an `own` parameter or returning it moves
it: the binding it came from is empty afterwards. In Python `b = a` makes a second reference to one
object; for an `own` binding it is a move.

```jac
# expect: E1301
obj Buffer {
    has n: int = 0;
}

def run {
    a: own Buffer = Buffer();
    b = a;
    print(a.n, b.n);
}

with entry {
    run();
}
```

**Fix:** read the value through the binding that holds it now (`print(b.n);`), lend it instead of
moving it (`b = &a;`), or leave out `own` where the value is meant to be shared.

## E1302

```text
Conflicting mutable borrow of '{name}' while another borrow is live
```

A mutable borrow of `{name}` is taken, or `{name}` is written, while another borrow of it is still
in use. A `&mut` borrow is exclusive: while it lives, nothing else reads or writes the value it
lends. A borrow lives until the last line that uses it.

```jac
# expect: E1302
obj Buffer {
    has n: int = 0;
}

def run {
    a: own Buffer = Buffer();
    e1: &mut Buffer = &mut a;
    e2: &mut Buffer = &mut a;
    print(e1.n, e2.n);
}

with entry {
    run();
}
```

**Fix:** finish with one borrow before taking the next, so their uses do not overlap:

```jac
obj Buffer {
    has n: int = 0;
}

def run {
    a: own Buffer = Buffer();
    e1: &mut Buffer = &mut a;
    e1.n = 1;
    e2: &mut Buffer = &mut a;
    e2.n = 2;
    print(a.n);
}

with entry {
    run();
}
```

```output
2
```

## E1303

```text
Cannot mutate '{name}' while a shared borrow of it is live
```

An owner is written while a shared borrow of it (`&{name}`) is still in use. A shared borrow reads
the value as it was lent; changing the value under it is refused. Writing a field of the owner
counts, unless the borrow lends a different field.

```jac
# expect: E1303
obj Buffer {
    has n: int = 0;
}

def run {
    a: own Buffer = Buffer();
    v: &Buffer = &a;
    a.n = 5;
    print(v.n);
}

with entry {
    run();
}
```

**Fix:** make the change before the borrow is taken or after its last use: here, move `a.n = 5;`
below `print(v.n);`.

## E1304

```text
'{name}' is destroyed while still borrowed
```

The owner `{name}` is moved away, or goes out of scope, while a borrow of it is still in use. The
new owner may destroy the value, and the borrow would read what is gone. It is also reported for a
borrow kept past the end of the block that declares its owner.

```jac
# expect: E1304
obj Buffer {
    has n: int = 0;
}

def finish(b: own Buffer) {
    print(b.n);
}

def run {
    a: own Buffer = Buffer();
    r = &a;
    finish(a);
    print(r.n);
}

with entry {
    run();
}
```

**Fix:** use the borrow before the owner is handed on: `print(r.n);` and then `finish(a);`.

## E1305

```text
Linear binding '{name}' is never consumed
```

A `lin` (linear) binding reaches the end of its function, on some path, without its value being
consumed. `{name}` is the binding. A linear value must be used up exactly once, by a move: passed to
an `own` parameter, returned, or assigned on. An `if` that consumes it on one branch only leaves
the other branch holding it.

```jac
# expect: E1305
obj Buffer {
    has n: int = 0;
}

def finish(b: own Buffer) {
    print(b.n);
}

def run(flag: bool) {
    f: lin Buffer = Buffer();
    if flag {
        finish(f);
    }
}

with entry {
    run(True);
}
```

**Fix:** consume the value on every path, here after the `if`:

```jac
obj Buffer {
    has n: int = 0;
}

def finish(b: own Buffer) {
    print(b.n);
}

def run(flag: bool) {
    f: lin Buffer = Buffer();
    if flag {
        print("flagged");
    }
    finish(f);
}

with entry {
    run(True);
}
```

```output
flagged
0
```

## E1306

```text
Borrow of '{name}' escapes its scope
```

A function returns a borrow of `{name}`, an owned local of its own: `return &a;`, or a local that
borrows from it. The local is destroyed when the function returns, so the borrow would outlive it.
A function may return a borrow of what its caller lent it (a `&` parameter, or `self`).

```jac
# expect: E1306
obj Buffer {
    has n: int = 0;
}

def newest -> Buffer {
    a: own Buffer = Buffer();
    v: &Buffer = &a;
    return v;
}

with entry {
    print(newest().n);
}
```

**Fix:** return the value itself, which moves it to the caller:

```jac
obj Buffer {
    has n: int = 0;
}

def newest -> own Buffer {
    a: own Buffer = Buffer();
    return a;
}

with entry {
    print(newest().n);
}
```

```output
0
```

## E1307

```text
a reference to {what} escapes its region: what a region allocates may not be stored outside it or returned from it
```

What is allocated inside `in r { ... }` lives in region `r` and is freed with it, all at once. A
value made there is assigned to a name declared outside the block, to a field or item of something
made outside it, given to a method of a list, dict or set from outside that keeps it
(`out.append(x)`, `d.update(...)`, or `out += [x]`), or returned. `{what}` says which value: `call result` for an object a call made,
the kind of value a display or comprehension made (`a list`), or the name of a local of the block,
quoted (`'b'`).

```jac
# expect: E1307
obj Buffer {
    has n: int = 0;
}

with entry {
    kept = Buffer();
    r: own Region = Region();
    in r {
        kept = Buffer(n=1);
    }
    print(kept.n);
}
```

**Fix:** carry out a value that is not on the heap, such as a number or a bool, or make the object
outside the region. Here the number is carried out:

```jac
obj Buffer {
    has n: int = 0;
}

with entry {
    kept = 0;
    r: own Region = Region();
    in r {
        b = Buffer(n=1);
        kept = b.n;
    }
    print(kept);
}
```

```output
1
```

## E1308

```text
'{name}' is not sendable across a concurrency boundary
```

A value goes where another thread, task or space may reach it, and its type or binding does not
allow that. `{name}` is the local, or for a call between spaces the parameter, result or field
with its type (`'s: Slot'`). It is reported when:

- the body of a parallel `flow for` reads or changes outer state that is not shared (plain data,
  what never changes, an object of a `Shared` class) or `imm`, other than a reduction such as
  `s += x`;
- a borrow bound to a name is passed to a task started with `flow`, which could outlive it;
- a call between spaces sends or returns a value that is not sendable, such as a function value or
  an `any`.

```jac
# expect: E1308
def total(xs: &list[int]) -> list[int] {
    seen: list[int] = [];
    flow for x in &xs {
        seen.append(x);
    }
    return seen;
}

with entry {
    ys = [1, 2, 3];
    print(total(&ys));
}
```

**Fix:** have the body compute a reduction (`s += x`, `s = max(s, x)`), write the iteration's own
element of a list lent `&mut`, or use a plain `for`. For a task, pass the owned value
(`flow show(a)`) or an inline `&a` whose task is waited for. See
[What crosses into a place](../../accel/crossing.md) (`jac docs crossing`).

```jac
def total(xs: &list[int]) -> int {
    s = 0;
    flow for x in &xs {
        s += x;
    }
    return s;
}

with entry {
    ys = [1, 2, 3];
    print(total(&ys));
}
```

```output
6
```

## E1309

```text
Cannot mutate '{name}' through a deep-immutable `imm` binding
```

A value is changed through an `imm` binding. `{name}` is the binding. `imm` is deep: neither the
value's fields nor what they hold may be written, and no method that changes it may be called
(`xs.append(1)` on an `imm list[int]`).

```jac
# expect: E1309
obj Buffer {
    has n: int = 0;
}

def run {
    v: imm Buffer = Buffer();
    v.n = 5;
}

with entry {
    run();
}
```

**Fix:** make the changes while the value is owned, then freeze it:

```jac
obj Buffer {
    has n: int = 0;
}

def run {
    v: own Buffer = Buffer();
    v.n = 5;
    w: imm Buffer = imm v;
    print(w.n);
}

with entry {
    run();
}
```

```output
5
```

## E1311

```text
Cannot freeze '{name}': the value may be aliased
```

`imm {name}` freezes a value that other bindings may still reach. Freezing needs the only handle on
the value: an `own`, `lin` or `imm` binding. A plain parameter or local may share its value with
the caller or with another name, which could still change it.

```jac
# expect: E1311
obj Buffer {
    has n: int = 0;
}

def frozen(b: Buffer) {
    d = imm b;
    print(d.n);
}

with entry {
    frozen(Buffer());
}
```

**Fix:** take the value as an owner, so the freeze is of the only handle:
`def frozen(b: own Buffer)`.
