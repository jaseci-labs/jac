# E1500 to E1521: structs

These codes report a struct used as if it were an object. A struct is a value: copied where it goes, held in place, with no identity and no owner of its own, and made from its fields alone. See [Structs](../../language/structs.md) (`jac docs structs`) and [Where structs are held](../../language/structs-storage.md).

## E1500

```text
a struct conforms to interfaces and inherits nothing: {name} lists {base}, which is {what}
```

A struct lists a base that is not an interface. `{name}` is the struct, `{base}` the class listed and `{what}` what it is: `a struct`, or `an archetype with fields or code`. A struct conforms to interfaces, classes of abstract methods alone; it inherits no fields and no code.

```jac
# expect: E1500
obj Base {
    has y: int = 0;
}

struct Point(Base) {
    has x: int = 0;
}

with entry {
    print(Point().x);
}
```

**Fix:** write the fields in the struct itself, or list an interface and implement its methods.

```jac
obj Shape {
    def area -> float abst;
}

struct Square(Shape) {
    has side: float = 1.0;

    def area -> float {
        return self.side * self.side;
    }
}

with entry {
    print(Square().area());
}
```

```output
1.0
```

## E1501

```text
{name} holds itself: a struct holds its fields in place, so it cannot hold a {type} in any of them
```

A struct has a field of its own type, directly or through another struct. `{name}` is the struct and `{type}` the struct it would hold. A struct holds its fields in place, so a struct inside itself would have no finite size.

```jac
# expect: E1501
struct Nest {
    has inner: Nest;
}

with entry {
    print(1);
}
```

**Fix:** make it an `obj`, whose fields hold references, with the field optional: `obj Nest { has inner: Nest | None = None; }`.

## E1502

```text
a struct is made from its fields, given or defaulted: {name} cannot have {what}
```

A struct declares an `init` or a `postinit`, or a field set after it is made. `{name}` is the struct and `{what}` what it has. A struct is made by giving its fields, each given or defaulted, and nothing runs when it is made.

```jac
# expect: E1502
struct Point {
    has x: int = 0;

    def init(x: int) {
        self.x = x;
    }
}

with entry {
    print(Point(x=1).x);
}
```

**Fix:** drop the `init` and make the struct from its fields (`Point(x=1)`), or write a function that computes the fields and returns the struct.

## E1503

```text
'{op}' compares references, and {type} is a value: compare it with ==
```

`is` or `is not` compares a struct. `{op}` is the operator and `{type}` the struct. A struct is a value with no identity of its own: two structs are the same only by their fields.

```jac
# expect: E1503
struct Point {
    has x: int = 0;
}

with entry {
    a = Point();
    b = Point();
    print(a is b);
}
```

**Fix:** compare with `==`.

```jac
struct Point {
    has x: int = 0;
}

with entry {
    a = Point();
    b = Point();
    print(a == b);
}
```

```output
True
```

## E1504

```text
{what} is a temporary copy of a {type}, and {action} would change only the copy: assign it to a variable and change that
```

A field or an element of a struct that is a temporary copy is assigned to: the result of a call, or an element read out of a value. `{what}` is the expression, `{type}` the struct and `{action}` the change. The copy disappears at the end of the statement, so the change would be lost.

```jac
# expect: E1504
struct Point {
    has x: int = 0;
}

def origin -> Point {
    return Point();
}

with entry {
    origin().x = 3;
}
```

**Fix:** bind the struct to a variable and change that.

```jac
struct Point {
    has x: int = 0;
}

def origin -> Point {
    return Point();
}

with entry {
    p = origin();
    p.x = 3;
    print(p.x);
}
```

```output
3
```

## E1505

```text
{type} is a struct, a value, and {want} is a reference to an object: a struct reaches an interface it conforms to as a dyn of it, or through a type parameter bounded by it
```

A struct is given where a reference to an object is wanted: a variable, a parameter or a field whose type is a class. `{type}` is the struct and `{want}` the class. A struct is copied, not referred to; it reaches an interface it conforms to as a `dyn` of the interface, or through a type parameter bounded by it.

```jac
# expect: E1505
obj Shape {
    has sides: int = 0;
}

struct Point {
    has x: int = 0;
}

with entry {
    s: Shape = Point();
}
```

**Fix:** have the struct conform to an interface and hold it as a `dyn` of it.

```jac
obj Shape {
    def sides -> int abst;
}

struct Point(Shape) {
    has x: int = 0;

    def sides -> int {
        return 0;
    }
}

with entry {
    s: dyn Shape = Point();
    print(s.sides());
}
```

```output
0
```

## E1506

```text
a struct is copied where it goes, and each copy would own what its field '{name}' holds: a field of a struct cannot be marked {mode}
```

A field of a struct is marked with an ownership mode such as `own`. `{name}` is the field and `{mode}` the mark. A struct is copied where it goes, and every copy would claim to own the same value. See [Ownership](../../language/ownership.md).

```jac
# expect: E1506
struct Person {
    has name: own str = "";
}

with entry {
    print(1);
}
```

**Fix:** drop the mark: `has name: str = "";`.

## E1507

```text
'{name}' holds a {type}, a value its place holds, not a reference: {mode} marks the owner of a reference
```

A parameter or a local holding a struct is marked `own`, `lin` or `imm`. `{name}` is the variable, `{type}` the struct and `{mode}` the mark. Those marks say who owns a reference; a struct is a value held in the variable's own place, so there is nothing to own.

```jac
# expect: E1507
struct Point {
    has x: int = 0;
}

def first(p: own Point) -> int {
    return p.x;
}

with entry {
    print(first(Point()));
}
```

**Fix:** drop the mark: `def first(p: Point) -> int`.

## E1521

```text
{name}'s {type} holds its elements in place, as values: they have no owner but the list, and own marks the owner of a reference (write {plain})
```

A list of structs is written with its element marked `own`, as `list[own Point]`. `{name}` is the variable, `{type}` the list's type and `{plain}` the type to write. A list of structs holds them in place, packed one after another, so the list owns them already. See [Packed lists](../../language/packed-lists.md).

```jac
# expect: E1521
struct Point {
    has x: int = 0;
}

with entry {
    ps: list[own Point] = [];
    print(len(ps));
}
```

**Fix:** write the list's type as the message says: `ps: list[Point] = [];`.
