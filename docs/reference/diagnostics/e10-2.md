# E1050 to E1098: calls and statements

E1050 to E1057 are reported when a call's arguments cannot be bound to the callee's parameters:
too few, too many, an unknown keyword, the wrong type. E1090 to E1098 are reported when a statement
or a graph operator is given a value of a kind it does not take. In the call codes, `{callee}` is
the function as the message names it: `area()`, `Point()`, `list.append()`.

## E1050

```text
{callee} is missing {missing}
```

A call leaves out an argument the callee requires. `{missing}` says what is missing, as
`1 required positional argument: 'h'`, `2 required keyword-only arguments: 'a' and 'b'`,
`an argument` for a builtin, or `1 argument` for a call through a function value, a function's
or a bound method's, whose `Callable` type names no parameters (see
[Function values](../../language/functions-values.md)). Constructing a class is a call to its
`init`; a class with no `init` of its own takes its fields, or the parameters of its nearest
base's `init`.

```jac
# expect: E1050
def area(w: int, h: int) -> int {
    return w * h;
}

with entry {
    print(area(3));
}
```

**Fix:** pass the missing argument (`area(3, 4)`), or give the parameter a default
(`h: int = 1`). See [Functions](../../language/functions.md).

## E1051

```text
{callee} takes {expected}, found {given}
```

A call passes more positional arguments than the callee takes. `{expected}` is what it takes, as
`2 positional arguments` or `from 1 to 2 positional arguments`, and `{given}` is the number passed.
A method read off its object (`Box().scale`) takes the method's arguments: the object it keeps is
none of them.

```jac
# expect: E1051 x2
obj Box {
    has n: int = 2;

    def scale(k: int) -> int {
        return self.n * k;
    }
}

def area(w: int, h: int) -> int {
    return w * h;
}

with entry {
    print(area(3, 4, 5));
    scale = Box().scale;
    print(scale(3, Box()));
}
```

**Fix:** remove the extra argument, or declare a `*args` parameter if the function is meant to
take any number.

## E1052

```text
{callee} takes no keyword argument '{name}'
```

A call passes a keyword argument that names no parameter of the callee. `{name}` is the keyword as
written. Builtins take only the keywords they document: `max()` takes `key` and `default`.

```jac
# expect: E1052
def area(w: int, h: int) -> int {
    return w * h;
}

with entry {
    print(area(3, height=4));
}
```

**Fix:** use the parameter's name (`area(3, h=4)`), or declare a `**kwargs` parameter to take
keywords the function does not name.

## E1053

```text
{what} expects {expected}, found {actual}
```

An argument, or a value in an argument's role, has the wrong type. `{what}` names the place, as
`area()'s parameter 'h'`, `{expected}` is the type it takes and `{actual}` the type given. This is
[E1001](e10-1.md) for a call: the same mismatch, named by the parameter it was passed to.

```jac
# expect: E1053
def area(w: int, h: int) -> int {
    return w * h;
}

with entry {
    print(area(3, "4"));
}
```

**Fix:** pass a value of the parameter's type, converting by name where the value is another type
(`area(3, int("4"))`).

A function that makes a coroutine (an `async def`, or a lambda that calls one) passed where one that
gives nothing is declared is this error too:
`expects Callable[[str], None], found Callable[[str], Coroutine[any, any, None]]`.
[Props](../../apps/components.md#props) gives the parameter type that takes it.

## E1054

```text
no form of {callee} takes {what}
```

A builtin is called in a combination of arguments that none of its forms accepts. `{callee}` is the
builtin and `{what}` the combination. `min()` and `max()` take either several values or one
iterable; `default=` belongs to the one-iterable form, where it is the result for an empty
iterable.

```jac
# expect: E1054
with entry {
    print(max(1, 2, default=0));
}
```

**Fix:** pass one iterable with the default (`max([1, 2], default=0)`), or drop the default.

## E1056

```text
{callee} got positional-only arguments passed as keyword arguments: {names}
```

A call names, as a keyword, a parameter declared before `/` in the callee's parameter list. Such a
parameter is positional-only. `{names}` lists the parameters named, each in quotes.

```jac
# expect: E1056
def half(n: int, /) -> int {
    return n // 2;
}

with entry {
    print(half(n=4));
}
```

**Fix:** pass it by position: `half(4)`.

## E1057

```text
{callee} got multiple values for argument '{name}'
```

A call gives one parameter two values: once by position and again by keyword, or by the same
keyword twice. `{name}` is the parameter.

```jac
# expect: E1057
def half(n: int) -> int {
    return n // 2;
}

with entry {
    print(half(4, n=4));
}
```

**Fix:** pass the argument once: `half(4)` or `half(n=4)`.

## E1090

```text
only exceptions can be raised, found {type}
```

`raise` is given a value that is not an exception. `{type}` is its type. An exception is an
instance of `Exception` or of a class derived from it.

```jac
# expect: E1090
with entry {
    raise "failed";
}
```

**Fix:** raise an exception carrying the message: `raise ValueError("failed");`. See
[Exceptions](../../language/exceptions.md).

## E1091

```text
'{type}' object does not support the context manager protocol
```

A `with` statement is given a value that is not a context manager. `{type}` is its type. A context
manager is an object whose class defines both `__enter__` and `__exit__`.

```jac
# expect: E1091
with entry {
    with 5 as n {
        print(n);
    }
}
```

**Fix:** give `with` an object that has both methods, such as what `open()` returns or a class of
your own:

```jac
obj Timer {
    def __enter__ -> Timer {
        print("start");
        return self;
    }

    def __exit__(et: any, ev: any, tb: any) -> bool {
        print("stop");
        return False;
    }
}

with entry {
    with Timer() as t {
        print("working");
    }
}
```

```output
start
working
stop
```

See [Context managers](../../language/context-managers.md).

## E1093

```text
yield needs a value of type {type}
```

A bare `yield;` appears in a generator whose declared element type does not include `None`.
`{type}` is the element type, the `T` of its `Iterator[T]` or `AsyncIterator[T]` return type.

```jac
# expect: E1093
def numbers -> Iterator[int] {
    yield 1;
    yield;
}
```

**Fix:** yield a value of the element type (`yield 2;`), or declare the generator as
`Iterator[int | None]` if it is meant to yield `None`. See
[Generators](../../language/generators.md).

## E1094

```text
visit needs a node, an edge or a list of them, found {type}
```

`visit` is given something a walker cannot go to. `{type}` is the type of the expression. A walker
visits a node, an edge, or a list of nodes or edges, which is what an edge reference such as
`[-->]` gives.

```jac
# expect: E1094
node City {}

walker Tour {
    can go with City entry {
        visit 5;
    }
}
```

**Fix:** visit nodes or edges: `visit [-->];` for every node an outgoing edge leads to. See
[visit](../../language/visit.md).

## E1096

```text
the left side of a connect or disconnect is a node, not {type}
```

The left operand of a connect operator (`++>`, `<++>`, `+>:E:+>`) or a disconnect (`del -->`) is
not a node. `{type}` is the operand's type.

```jac
# expect: E1096
node City {}

with entry {
    c = City();
    5 ++> c;
}
```

**Fix:** put a node on each side: `a ++> c;` where `a` and `c` are instances of `node` archetypes.
See [Connecting](../../language/connecting.md).

## E1097

```text
the right side of a connect or disconnect is a node, not {type}
```

The right operand of a connect or disconnect operator is not a node. `{type}` is the operand's
type. This is [E1096](#e1096) for the other side.

```jac
# expect: E1097
node City {}

with entry {
    c = City();
    c ++> 5;
}
```

**Fix:** connect to a node. To store a plain value in the graph, give a node a field that holds
it.

## E1098

```text
'{name}' is not an edge
```

The type written inside a typed connect (`+>:E:+>`) or a typed edge reference (`[->:E:->]`) is not
an `edge` archetype. `{name}` is the name written, or the type of the value when a variable is
given.

```jac
# expect: E1098
node City {}

obj Road {}

with entry {
    a = City();
    b = City();
    a +>:Road:+> b;
}
```

**Fix:** declare the type as an edge, with the node types it joins:

```jac
node City {}

edge Road: City --> City {}

with entry {
    a = City();
    b = City();
    a +>:Road:+> b;
    print(len([a -->]));
}
```

```output
1
```

See [Edges](../../language/edges.md).
