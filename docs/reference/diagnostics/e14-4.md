# E1490 to E1496: decorators

A decorator is a call of a `comptime` function as the program compiles, given the declaration it precedes. `jaclang.comptime`'s facts (`inline`, `noinline`, `cold`, `align`, `fast_math`) are recorded this way. These codes report a decorator that is not a compile-time function, and a fact recorded somewhere it cannot hold. See [Decorators](../../language/decorators.md) (`jac docs decorators`).

## E1490

```text
decorator {name} is not a compile-time function: a decorator records facts on its declaration as the program compiles, so a run-time wrapper is an ordinary call (`f = {call}(f_impl);`)
```

A decorator names a function that is not a `comptime` function, or a value that is not a function at all. `{name}` is the decorator, quoted, and `{call}` the function to call instead. In Python a decorator wraps its function as the program runs; here a decorator runs as the program compiles and records facts on the declaration, so a run-time wrapper is called like any other function.

```jac
# expect: E1490
def wrap(f: Callable[[int], int]) -> Callable[[int], int] {
    return f;
}

@wrap
def twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

**Fix:** call the wrapper on the function and bind the result.

```jac
def wrap(f: Callable[[int], int]) -> Callable[[int], int] {
    return f;
}

def twice_impl(x: int) -> int {
    return 2 * x;
}

with entry {
    twice = wrap(twice_impl);
    print(twice(1));
}
```

```output
2
```

## E1491

```text
{fact}() records a fact on the declaration a decorator precedes, and only there: write it as a decorator before the declaration, or call it on the declaration a comptime function's decorator gives it
```

One of `jaclang.comptime`'s facts (`inline`, `noinline`, `cold`, `align`, `fast_math`) is called as an ordinary function, outside a decorator's evaluation. `{fact}` is the fact. A fact belongs to a declaration, and is recorded on it only by a decorator, or by a `comptime` function that a decorator calls and that is given the declaration.

```jac
# expect: E1491
import from jaclang.comptime { inline }

def twice(x: int) -> int {
    return 2 * x;
}

with entry {
    inline(twice);
    print(twice(1));
}
```

**Fix:** write the fact as a decorator.

```jac
import from jaclang.comptime { inline }

@inline
def twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

```output
2
```

## E1492

```text
{fact}() records a fact of {applies}, and {what} is not one
```

A fact is recorded on a declaration it does not apply to. `{fact}` is the fact, `{applies}` what it applies to and `{what}` the declaration. `inline`, `noinline`, `cold` and `fast_math` apply to a function with a body, and `align` to such a function or to a struct; a class, a C function, a `comptime` function and an abstract method take none of them.

```jac
# expect: E1492
import from jaclang.comptime { inline }

@inline
obj Point {
    has x: int = 0;
}

with entry {
    print(Point().x);
}
```

**Fix:** put the decorator on a function with a body, or remove it.

## E1493

```text
'{name}' is always inlined, and it is on a cycle of calls, which inlining cannot end: drop @inline or break the cycle
```

A function marked `@inline` calls itself, directly or through other functions. `{name}` is the function. Inlining copies the body into each caller, and a body that calls itself would be copied without end.

```jac
# expect: E1493
import from jaclang.comptime { inline }

@inline
def countdown(n: int) -> int {
    return 0 if n == 0 else countdown(n - 1);
}

with entry {
    print(countdown(3));
}
```

**Fix:** drop `@inline` from the recursive function, or rewrite the recursion as a loop.

## E1494

```text
'{name}' is {first} and {second}: say one
```

A declaration's decorators record facts that contradict each other: `inline` with `noinline` or `cold`, or two `align`s that differ. `{name}` is the declaration, and `{first}` and `{second}` are the two facts.

```jac
# expect: E1494
import from jaclang.comptime { inline, noinline }

@inline
@noinline
def twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

**Fix:** keep the one fact that is meant.

## E1495

```text
an alignment is a compile-time power of two, at most 4096, not {found}
```

`align(n)` is given a number that is not a power of two from 1 to 4096, or one not known as the program compiles. `{found}` is what was written. The alignment is the byte boundary a function's code, or a struct, starts at.

```jac
# expect: E1495
import from jaclang.comptime { align }

@align(24)
def twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

**Fix:** use a power of two: `@align(16)` or `@align(32)`.

## E1496

```text
a decorator is written before the declaration it records facts on, not before {what}
```

A decorator is written before an `impl` or a `test`. `{what}` says which, and where to write the decorator instead. The facts belong to the declaration: an `impl` only supplies its body.

```jac
# expect: E1496
import from jaclang.comptime { inline }

def twice(x: int) -> int;

@inline
impl twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

**Fix:** move the decorator to the declaration.

```jac
import from jaclang.comptime { inline }

@inline
def twice(x: int) -> int;

impl twice(x: int) -> int {
    return 2 * x;
}

with entry {
    print(twice(1));
}
```

```output
2
```
