# E2101 to E2118: bases, edge endpoints and special names

These codes report a declaration the language gives a fixed shape: what an archetype may derive from, what an edge connects, a static field or a global with nothing to give it a value or a type, and `self`, `here` or `visitor` used where they do not exist. See [Inheritance](../../language/inheritance.md) (`jac docs inheritance`) and [Archetypes](../../language/archetypes.md).

## E2101

```text
a base is the name of an archetype
```

An archetype lists a base that is not the name of an archetype: a builtin type such as `int` or `list[int]`, or an expression. In Python a class may subclass `int` or `list`; here an archetype derives from archetypes (and, alone, from one Python class: E2191).

```jac
# expect: E2101
obj Sub(list[int]) {
    has m: int = 0;
}

with entry {
    print(Sub().m);
}
```

**Fix:** hold the value in a field.

```jac
obj Sub {
    has items: list[int] = [],
        m: int = 0;
}

with entry {
    print(Sub().m);
}
```

```output
0
```

## E2102

```text
an edge's endpoints are node names
```

An edge's endpoint is written as something other than a node's name, or several names joined by `|`. An edge connects one node to another; a list or another type is not an endpoint. See [Edges](../../language/edges.md).

```jac
# expect: E2102
node City {
    has name: str = "";
}

edge Road: City --> list[City] {
    has km: int = 0;
}

with entry {
    print(1);
}
```

**Fix:** name node types, with `|` between several: `edge Road: City --> City | Port`.

## E2103

```text
a static field needs a value
```

A `static has` field is declared without a value. A static field belongs to the class, not to an object, and no constructor sets it, so its declaration gives its value.

```jac
# expect: E2103
obj Config {
    static has limit: int;
}

with entry {
    print(1);
}
```

**Fix:** give it a value.

```jac
obj Config {
    static has limit: int = 10;
}

with entry {
    print(Config.limit);
}
```

```output
10
```

## E2105

```text
the bases of {name} form a cycle
```

An archetype's bases lead back to itself. `{name}` is the archetype where the cycle is found. An archetype cannot be its own ancestor.

```jac
# expect: E2105
obj A(B) {
    has a: int = 0;
}

obj B(A) {
    has b: int = 0;
}

with entry {
    print(1);
}
```

**Fix:** remove one of the bases.

## E2106

```text
{name} and its base {base} are different archetypes
```

An archetype derives from an archetype of another kind: a `node` from an `obj`, a `walker` from a `node`, an `edge` from a `walker`. `{name}` is the archetype and `{base}` the base. Each kind has its own place in the graph, so a base is of the same kind.

```jac
# expect: E2106
obj Base {
    has n: int = 0;
}

node City(Base) {
    has name: str = "";
}

with entry {
    print(1);
}
```

**Fix:** derive from an archetype of the same kind.

```jac
node Place {
    has n: int = 0;
}

node City(Place) {
    has name: str = "";
}

with entry {
    print(City(name="a").n);
}
```

```output
0
```

## E2111

```text
'{name}' is not available here
```

A name that exists only in some places is used outside them. `{name}` is the name: `self` outside a method or an ability, `here` outside a walker's ability, `visitor` outside a node's ability. See [Abilities](../../language/abilities.md).

```jac
# expect: E2111
def show {
    print(here);
}

with entry {
    show();
}
```

**Fix:** use the name where it exists, or pass the value as a parameter. In a walker's ability `here` is the node it is on; in a node's ability `visitor` is the walker.

```jac
node City {
    has name: str = "";

    can greet with Tour entry {
        print(self.name, visitor.seen);
    }
}

walker Tour {
    has seen: int = 0;

    can see with City entry {
        self.seen += 1;
        print(here.name);
    }
}

with entry {
    City(name="a") spawn Tour();
}
```

```output
a
a 1
```

## E2118

```text
'{name}' needs a type or a value
```

A `glob` is declared with neither a type nor a value. `{name}` is the global. A global's type comes from its annotation or from its value, and without either there is nothing to read.

```jac
# expect: E2118
glob total;

with entry {
    print(1);
}
```

**Fix:** give it a value, or a type and a value.

```jac
glob total: int = 0;

with entry {
    print(total);
}
```

```output
0
```
