# E1475 to E1484: float formats, compile-time parameters and interfaces

These codes report a type used where it means nothing: a small float format outside a tensor or C memory, a compile-time parameter marked the wrong way, and an interface or a `dyn` in the wrong place. See [Small float formats](../../language/numbers-float-formats.md) (`jac docs f8e4m3fn`), [Compile-time parameters](../../language/comptime-parameters.md) and [Interfaces](../../language/interfaces.md).

## E1475

```text
{type} is a storage format, the element of a tensor or of C memory (a ptr's) and no other type's: an element reads as an f32, and takes the conversion by the format's name
```

A small float format (`f8e4m3fn`, `f8e5m2`, `f4e2m1fn`) is written as the type of something other than an element of a tensor or of C memory: a local, a parameter, a field, a list's element, a vector's lanes. `{type}` is the format. A format is a way of storing a number in a byte, not a number type to compute with.

```jac
# expect: E1475
with entry {
    xs: list[f8e5m2] = [];
}
```

**Fix:** hold the elements in a tensor or a `ptr` of the format, and compute with the `f32` an element reads as.

```jac
import from accel { tensor }

with entry {
    t = tensor[f8e4m3fn, _]([0.5, 1.0, 3.0]);
    t[0] = f8e4m3fn(t[1] * 2.5);
    print(t[0], t[1]);
}
```

```output
2.5 1.0
```

## E1476

```text
{type} values are stored as a tensor's or a ptr's elements and used no other way: the format has no arithmetic, so compute with the f32 an element reads as and store the conversion of the result
```

The conversion to a small float format, `f8e4m3fn(x)`, is used as a value: bound to a local, passed, returned or computed with. `{type}` is the format. The conversion's value has one use, to be stored as an element.

```jac
# expect: E1476
with entry {
    q = f8e4m3fn(0.5);
}
```

**Fix:** store the conversion straight into the element: `t[0] = f8e4m3fn(0.5);`, with `t` a `tensor[f8e4m3fn, _]`. Keep the value as an `f32` until then.

## E1477

```text
an element of {type} takes {conv}(x), the value converted by name, not {found}
```

An element of a small float format is assigned something other than the conversion by the format's name: a float, another element, another format's conversion. `{type}` and `{conv}` are the format and `{found}` the type assigned. Rounding to a format loses precision, so the program says where it happens.

```jac
# expect: E1477
import from accel { tensor }

with entry {
    t = tensor[f8e4m3fn, _]([0.5, 1.0, 3.0]);
    t[0] = 0.5;
}
```

**Fix:** convert by the format's name: `t[0] = f8e4m3fn(0.5);`.

## E1478

```text
{callee}'s {param} is made from a number in its body (a literal as one, or a conversion to it), which a number type does and a class does not: {type} cannot stand for it
```

A generic function bounded by a number interface makes a value of its type parameter from a number in its body (`a + 1`, `T(0)`, `x: T = 1`), and is called with a class that conforms to the interface. `{callee}` is the function, `{param}` the type parameter and `{type}` the class given for it. An int or a float type turns `1` into a value of itself; a class has no literals.

```jac
# expect: E1478
obj Cents(Number) {
    has c: int;

    def __add__(o: Cents) -> Cents {
        return Cents(c=self.c + o.c);
    }

    def __sub__(o: Cents) -> Cents {
        return Cents(c=self.c - o.c);
    }

    def __mul__(o: Cents) -> Cents {
        return Cents(c=self.c * o.c);
    }

    def __neg__ -> Cents {
        return Cents(c=-self.c);
    }

    def __lt__(o: Cents) -> bool {
        return self.c < o.c;
    }

    def __le__(o: Cents) -> bool {
        return self.c <= o.c;
    }

    def __gt__(o: Cents) -> bool {
        return self.c > o.c;
    }

    def __ge__(o: Cents) -> bool {
        return self.c >= o.c;
    }
}

def plus_one[T: Number](a: T) -> T {
    return a + 1;
}

with entry {
    print(plus_one(Cents(c=1)).c);
}
```

**Fix:** call the function with a number type (`plus_one(2)`, `plus_one(2.5)`), or have the caller pass the value the body needs as a `T`: `def plus[T: Number](a: T, step: T) -> T { return a + step; }`.

## E1479

```text
'comptime' marks a compile-time value parameter, and type parameter {name} is compile-time already: drop the word
```

`comptime` is written before a type parameter. `{name}` is the parameter. Every type parameter is known as the program compiles; the word marks a parameter that stands for a value, such as `[comptime N: int]`.

```jac
# expect: E1479
obj Box[comptime T] {
    has item: T;
}

with entry {
    print(Box[int](item=1).item);
}
```

**Fix:** drop the word: `obj Box[T] { has item: T; }`.

## E1480

```text
{name} is a compile-time value of type {type}, which is written with 'comptime' before it
```

A parameter in brackets is bounded by `int`, `bool` or `str` without `comptime` before it. `{name}` is the parameter and `{type}` its type. `[N: int]` would read as a type parameter bounded by `int`; a parameter that stands for a value says so.

```jac
# expect: E1480
def times[N: int](x: int) -> int {
    return x * N;
}

with entry {
    print(times[3](2));
}
```

**Fix:** write `comptime` before it.

```jac
def times[comptime N: int](x: int) -> int {
    return x * N;
}

with entry {
    print(times[3](2));
}
```

```output
6
```

## E1481

```text
{name}(...) makes a value of the type it stands for, as that type's own name does: a number type converts, a class constructs, a bool, a str, bytes, a bytearray, a complex, an array and a vector are made, and {type} is none of these
```

A type parameter is called to make a value, `T(x)`, in a copy of a generic function whose `T` is a type that has no such call: a list, a dict, a tuple. `{name}` is the type parameter and `{type}` the type it stands for in this copy. The call that asked for the copy is reported too, as E1229.

```jac
# expect: E1481, E1229
def make[T](x: int) -> T {
    return T(x);
}

with entry {
    print(make[list[int]](3));
}
```

**Fix:** give the function a type its call makes (`make[float](3)`, `make[str](3)`), or build the value without calling `T`.

## E1482

```text
{name} is an interface, which no value is of: write dyn before it for a reference to any class conforming to it, or bound a type parameter by it
```

An interface, a class with abstract methods and no fields, is written as the type of a value: a parameter, a local, a field, a return type. `{name}` is the interface. No object is of the interface itself, and a reference to any object conforming to it is written `dyn`. In Python and in the reference design an abstract base class is an ordinary annotation; here it is not.

```jac
# expect: E1482
obj Shape {
    def area -> float abst;
}

def area_of(x: Shape) -> float {
    return x.area();
}

with entry {
    print(1);
}
```

**Fix:** write `dyn Shape` for a reference to any conforming object, whose methods dispatch as the program runs, or bound a type parameter by it, which compiles a copy for each class.

```jac
obj Shape {
    def area -> float abst;
}

obj Circle(Shape) {
    has r: float = 1.0;

    def area -> float {
        return 3.0 * self.r * self.r;
    }
}

def area_of(x: dyn Shape) -> float {
    return x.area();
}

def area_in[T: Shape](x: T) -> float {
    return x.area();
}

with entry {
    print(area_of(Circle()), area_in(Circle()));
}
```

```output
3.0 3.0
```

## E1483

```text
'dyn' takes an interface, and {type} is not one: a class's own type is written by its name
```

`dyn` is written before a class that is not an interface: one with fields, or with code of its own. `{type}` is the class. A class's own name already is a reference to an object of it or of a subclass.

```jac
# expect: E1483
obj Plain {
    has n: int;
}

def show(x: dyn Plain) -> int {
    return 0;
}

with entry {
    print(1);
}
```

**Fix:** drop `dyn`: `def show(x: Plain) -> int`.

## E1484

```text
dyn of {name} is refused: builtin numbers, bools and strs conform to it, and a dyn holds a reference, which would box each and dispatch its operators when the code runs; bound a type parameter by it instead
```

`dyn` is written before an interface that the builtin numbers, bools or strs conform to, such as `Number`, `Int`, `Float` or `Ordered`. `{name}` is the interface. A `dyn` holds a reference, so each int in it would be boxed and each `+` dispatched as the program runs.

```jac
# expect: E1484
def show(x: dyn Number) -> int {
    return 0;
}

with entry {
    print(1);
}
```

**Fix:** bound a type parameter by the interface, which compiles a copy for each type it is called with.

```jac
def show[T: Number](x: T) -> T {
    return x + x;
}

with entry {
    print(show(1), show(2.5));
}
```

```output
2 5.0
```
