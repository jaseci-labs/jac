# E1401 to E1421: the ownership contract, kernels, vectors and arrays

E1401 to E1407 report where a module breaks the ownership contract. They are reported only for a module held to it: every module under the `nogc` memory profile (`jac check --memory nogc`, or `[memory] profile = "nogc"` in `jac.toml`), and under the other profiles the modules a `[memory] enforce` pattern in `jac.toml` names. In their messages `{provenance}` says which: `enforced by the nogc profile` or `enforced by jac.toml [memory] "<pattern>"`. See [Memory](../../language/memory.md) and [Ownership](../../language/ownership.md) (`jac docs memory`, `jac docs ownership`).

E1409 to E1421 report a kernel, a vector type or an array type written with something it cannot take. See [Kernels](../../accel/kernels.md), [Vectors](../../accel/vectors.md) and [Packed lists](../../language/packed-lists.md).

## E1401

```text
Heap-typed {position} '{name}' has no ownership state in a nogc-enforced module ({provenance})
```

A parameter or a local whose type lives on the heap (a `str`, a `list`, a `dict`, an `obj`) does not say who owns its value. `{position}` is `parameter` or `local` and `{name}` is its name. A parameter always states its ownership. A local takes the state its bindings give it (a fresh value is owned, a read through a borrow is borrowed, a string literal is `imm`), and is reported when they give none or disagree. A number, a bool, a node, an edge and a walker need no mark.

<!-- example: not checked: reported only in a module held to the nogc contract -->
```jac
def total(xs: list[int]) -> int {
    return len(xs);
}

with entry {
    print(total([1, 2]));
}
```

`jac check --memory nogc` reports `Heap-typed parameter 'xs' has no ownership state in a nogc-enforced module (enforced by the nogc profile)`.

**Fix:** mark the parameter: `xs: &list[int]` to borrow it, `&mut` to change it, `own` to take it, `imm` for a value that never changes. For a local whose bindings disagree (`m = [1];` then `m = p.items;`), bind each value to a local of its own.

## E1402

```text
Owned value '{name}' is sealed into managed storage inside a nogc-enforced module ({provenance})
```

A value the module owns is stored where reference counting holds it: appended to a module global, or assigned to a field or an item of one. `{name}` is the value. The contract keeps owned values out of managed storage unless the program says so.

<!-- example: not checked: reported only in a module held to the nogc contract -->
```jac
glob cache: list[list[int]] = [];

with entry {
    row = [3];
    cache.append(row);
    print(len(cache));
}
```

With `enforce = ["strict_*"]` under `[memory]` in `jac.toml`, checking this as `strict_cache.jac` reports `Owned value 'row' is sealed into managed storage inside a nogc-enforced module (enforced by jac.toml [memory] "strict_*")`.

**Fix:** hand the value over explicitly with `managed()`: `cache.append(managed(row));`. Under the `nogc` profile there is no managed storage: keep the value in a local that owns it and lend it to the functions that need it.

## E1403

```text
Heap value '{name}' crosses implicitly out of a nogc-enforced module ({provenance})
```

A heap value is passed to a function of a module that is not held to the contract, so nothing says who owns it there. `{name}` is the value passed.

<!-- example: not checked: needs two modules and a jac.toml with a [memory] enforce pattern -->
```jac
import from loose_lib { consume }

with entry {
    data = [1, 2];
    print(consume(data));
}
```

Here `loose_lib.jac` declares `def consume(xs: list[int]) -> int`, and `jac.toml` has `enforce = ["strict_*"]` under `[memory]`. Checking the program as `strict_calls.jac` reports `Heap value 'data' crosses implicitly out of a nogc-enforced module`.

**Fix:** take the value across explicitly: `consume(managed(data))`. Or hold the other module to the contract too, by a pattern that matches it.

## E1404

```text
'{name}' is `any`-typed and could be heap-allocated in a nogc-enforced module ({provenance})
```

A parameter's type cannot say whether its value is on the heap: `any`, or a union such as `int | None`. `{name}` is the parameter. The contract cannot follow a value it cannot see the type of.

<!-- example: not checked: reported only in a module held to the nogc contract -->
```jac
def show(v: any) -> int {
    return 0;
}

with entry {
    print(show(1));
}
```

**Fix:** give the parameter one concrete type (`v: int`), with its ownership mark if the type lives on the heap (`v: &list[int]`).

## E1405

```text
Closure capture of '{name}' escapes its scope in a nogc-enforced module ({provenance})
```

A lambda reads a heap value from the function around it, or from a module global. `{name}` is the value. The closure could outlive the scope that owns the value.

<!-- example: not checked: reported only in a module held to the nogc contract -->
```jac
def shifted(data: &list[int]) -> int {
    return (lambda (x: int) -> int { return x + len(data); })(1);
}

with entry {
    print(shifted([1, 2]));
}
```

**Fix:** capture a number computed outside the lambda (`n = len(data);` and use `n`), or give the lambda the value as an argument.

## E1406

```text
{reason} ({provenance})
```

A construct the contract has no place for. `{reason}` says which:

| `{reason}` | Written |
|---|---|
| `module global 'x' would hold heap storage for the program's lifetime, which the owned world cannot free` | a `glob` of a heap type, under the `nogc` profile |
| `iter() retains a raw reference to its collection` (also `globals()`, `locals()`) | the builtin called on a heap value |
| `'managed()' on a heap value re-enters the reference-counted world, which a nogc build does not have` | `managed(x)` under the `nogc` profile |
| `'xs', a borrowed value, cannot enter a list literal, which owns its elements` (also an `imm` value, one with no ownership state, a read of a place another value owns) | a value that is neither fresh nor owned put in a list, set or dict display, an `append`, `add` or `insert`, or an item store, under the `nogc` profile |

<!-- example: not checked: reported only under the nogc memory profile -->
```jac
glob names: list[str] = [];

with entry {
    print(len(names));
}
```

**Fix:** for a global, declare it owned (`glob names: own list[str] = [];`) or hold the value in a local and lend it. For a container, put in a fresh value (`[1, 2]`, a call's result) or one a local owns, which moves in. In place of `iter(xs)`, loop with `for x in xs`.

## E1407

```text
'{name}' raises {exc}, and the entry block does not handle it
```

The entry block of a module held to the contract can raise an exception that nothing catches. `{name}` is the function called, or `raise` for a `raise` statement in the entry block itself, and `{exc}` is the exception's class. Under the contract errors propagate without an unwinder, so the entry block handles every exception the program's own code can raise.

<!-- example: not checked: reported only in a module held to the nogc contract -->
```jac
def half(n: int) -> int {
    if n % 2 == 1 {
        raise ValueError("odd");
    }
    return n // 2;
}

with entry {
    print(half(4));
}
```

`jac check --memory nogc` reports `'half' raises ValueError, and the entry block does not handle it`.

**Fix:** catch it in the entry block, or in a function on the way, by its class, a base of it, `Exception` or `BaseException`: `try { print(half(4)); } except ValueError { print("odd"); }`. See [Exceptions](../../language/exceptions.md).

## E1409

```text
kernel() takes {expected}, found {actual}
```

`kernel()` is given something that is not a function it can compile for a device. `{expected}` is `a function of the program, by its name` (not a method, a C function, a generator, an `async` function, a function with type parameters, or a variable holding a function) or `a function of plain parameters` (no `*args` or `**kwargs`). `{actual}` is what was written.

```jac
# expect: E1409
import from accel { tensor, kernel }

def fill(i: int, y: tensor[f32, _]) {
    y[i] = 1.0;
}

with entry {
    f = fill;
    kernel(f);
}
```

**Fix:** name the function itself.

```jac
import from accel { tensor, kernel }

def fill(i: int, y: tensor[f32, _]) {
    y[i] = 1.0;
}

with entry {
    y = tensor[f32, _](shape=4);
    kernel(fill).run(4, y);
    print(y[0]);
}
```

```output
1.0
```

## E1410

```text
a vector's lanes are numbers of an int or float type, not {type} (a mask, of bools, is what comparing vectors gives)
```

A vector type `simd[T, N]`, or a vector read from a `ptr[T]`, names an element type that is not an int or float type of 64 bits or fewer. `{type}` is the type written. In Python-style code a "vector of bools" is usually meant as a mask, which is the result of comparing two vectors, not a type to construct.

```jac
# expect: E1410
with entry {
    v = simd[bool, 4](True);
}
```

**Fix:** use a number type for the lanes, and get a mask by comparing.

```jac
with entry {
    a = simd[f32, 4](1.0);
    b = simd[f32, 4](2.0);
    print(select(a < b, a, b).sum());
}
```

```output
4.0
```

## E1411

```text
a vector's length is a compile-time int, a power of two from 2 to 64, not {found}
```

A vector's length is not one of 2, 4, 8, 16, 32 or 64. `{found}` is the length written. The length is part of the type, so it is a compile-time int.

```jac
# expect: E1411
with entry {
    v = simd[f32, 3](1.0);
}
```

**Fix:** use the next power of two (`simd[f32, 4]`) and leave the extra lanes unused, or use an `array[f32, 3]`, which has any length above 0.

## E1412

```text
{index} is not an index of {type}, whose are 0 to {last}
```

A literal index is outside a vector or an array. `{index}` is the index written, `{type}` the vector's or array's type and `{last}` its last index. The same code reports a lane out of range in a vector's `slice()`, `insert()` and `shuffled()`. Negative indices do not count from the end here.

```jac
# expect: E1412
with entry {
    v = simd[f32, 4](1.0);
    print(v[4]);
}
```

**Fix:** index from 0 to `{last}`: `v[3]` is the last lane of a `simd[f32, 4]`.

## E1413

```text
{what} would make a vector of {lanes} lanes, and a vector has 2 to 64
```

An operation would produce a vector with fewer than 2 or more than 64 lanes. `{what}` is the operation and `{lanes}` the length it would make. `low()`, `high()`, `even()` and `odd()` give half the lanes, so they need 4 or more; `join()` and `interleave()` give twice the lanes, so they take vectors of 32 or fewer.

```jac
# expect: E1413
with entry {
    v = simd[f32, 2](1.0);
    print(v.low());
}
```

**Fix:** read one lane of a two-lane vector by its index (`v[0]`), and keep halves and joins within 2 to 64 lanes.

## E1415

```text
{what}() takes its axis as the literal 0, 1 or 2, found {actual}
```

A grid kernel's position intrinsic (`thread_idx`, `block_idx`, `block_dim`, `grid_dim`, `global_idx`) is given an axis that is not the literal `0`, `1` or `2`. `{what}` is the intrinsic and `{actual}` what was written. A variable holding 0 is refused too: the axis is read as the program compiles.

```jac
# expect: E1415
import from accel { tensor, kernel, global_idx }

def fill(y: tensor[f32, _]) {
    y[global_idx(3)] = 1.0;
}

with entry {
    y = tensor[f32, _](shape=4);
    kernel(fill).launch(1, 32, y);
}
```

**Fix:** write the axis as a literal: `global_idx(0)` for x, `1` for y, `2` for z.

## E1418

```text
run() and begin() call a kernel for each index, so its first parameter is the int index it runs for: '{kernel}' takes {actual}
```

`run()` or `begin()` is called on a kernel whose first parameter is not an `int`. `{kernel}` is the kernel's function and `{actual}` is `no parameter` or `a <type> first`. `run(n, args...)` calls the function once for each index from 0 to n - 1 and passes the index itself, so the function declares it first.

```jac
# expect: E1418
import from accel { tensor, kernel, global_idx }

def fill(y: tensor[f32, _]) {
    y[global_idx(0)] = 1.0;
}

with entry {
    y = tensor[f32, _](shape=4);
    kernel(fill).run(4, y);
}
```

**Fix:** give the function its index (`def fill(i: int, y: tensor[f32, _])` and write `y[i]`), or start a kernel that finds its own position with `launch(grid, block, args...)`, which passes every parameter.

## E1419

```text
shared[T, N]() takes an element type and how many, an int literal: found {actual}
```

A grid kernel's shared memory is written without an element type and an int literal count. `{actual}` is what was found: the size as written (`'k'`), `1 type argument`, or `shared() of no type arguments`.

```jac
# expect: E1419
import from accel { tensor, kernel, shared }

def fill(y: tensor[f32, _], k: int) {
    s = shared[f32, k]();
    y[0] = 1.0;
}

with entry {
    y = tensor[f32, _](shape=4);
    kernel(fill).launch(1, 32, y, 8);
}
```

**Fix:** write the count as a literal: `s = shared[f32, 8]();`.

## E1420

```text
an array holds numbers, structs of plain data or arrays, not {type}
```

An array type `array[T, N]` names an element type an array cannot hold in place. `{type}` is the type written. An array holds numbers, structs of plain data and other arrays; a `str`, a list, an `obj` and a vector are refused.

```jac
# expect: E1420
with entry {
    a = array[str, 2]();
}
```

**Fix:** use a `list[str]` for values that are references, and an array for numbers: `array[f32, 2]()`.

## E1421

```text
an array's length is a compile-time int above 0, not {found}
```

An array type's length is zero or negative. `{found}` is the length written. An array holds at least one element, and its length is a compile-time int.

```jac
# expect: E1421
with entry {
    a = array[f32, 0]();
}
```

**Fix:** give a length of 1 or more, or use a `list[f32]` where the collection may be empty.
