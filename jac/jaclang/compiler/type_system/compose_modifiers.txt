// AndroidX Compose Modifier extension signatures (metalava shape), bundled for
// the Jac type-checker. Ingested at TypeEvaluator init via compose_signatures
// (parse_modifier_text) -> _install_compose_modifiers, which installs each
// Modifier extension as a chainable method on `ModifierChain`, so
// `Modifier.padding(8.dp).fillMaxWidth().clickable(onClick=..)` type-checks and
// chains. Regenerate/extend from the upstream signature files:
//   compose/ui/ui/api/current.txt
//   compose/foundation/foundation-layout/api/current.txt
//   compose/foundation/foundation/api/current.txt
// Only `public static` methods whose return type is androidx.compose.ui.Modifier
// (and that are NOT @Composable) are parsed; the unnamed leading `Modifier`
// receiver is dropped, leaving the addressable arguments. Since Jac has no
// overloading, a few methods that ship as several upstream overloads (padding,
// offset, size) are authored here as one convenience signature carrying the
// union of keyword arguments — matching how the hand-written stub modeled them.
