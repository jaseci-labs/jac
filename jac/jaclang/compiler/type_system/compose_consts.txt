// AndroidX Compose constant namespaces (metalava shape), bundled for the Jac
// type-checker. Ingested at TypeEvaluator init via compose_signatures
// (parse_const_text) -> _install_compose_consts, which installs each named
// constant as a member on the matching `<Name>Namespace` class in js_globals.pyi,
// so `Arrangement.Center`, `Alignment.CenterVertically`, `Color.Red` type-check
// (and a typo like `Arrangement.Centre` is flagged) under
// `[client.android] type_check = true`. Regenerate/extend from the upstream
// signature files:
//   compose/foundation/foundation-layout/api/current.txt   (Arrangement)
//   compose/ui/ui/api/current.txt                          (Alignment)
//   compose/ui/ui-graphics/api/current.txt                 (Color)
// Only `property`/`field` lines (not getter methods) are parsed; the enclosing
// class name — with a trailing `.Companion` stripped, since Compose keeps these
// on the companion object but Kotlin/Jac address them straight off the type —
// keys the namespace. Constant value classes (Color as a callable, TextStyle,
// Shape) are a separate concern; these entries only make the named members
// resolve, with their Kotlin type mapped where it is a scalar.
