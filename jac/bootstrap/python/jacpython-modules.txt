# Standard-library extension modules implemented in native Jac.
#
# One module per line: <module> [<upstream tests> [linker flags...]]
#   <module>          CPython import name; its PyInit_<module> is a :pub
#                     definition under jaclang/runtime/python/bindings/ and is
#                     imported by compiler/backends/py/jacpython/native_api.jac.
#   <upstream tests>  Comma-separated pinned CPython test modules that
#                     scripts/run_cpython_compiler_tests.jac runs against it.
#                     Omitted when every upstream suite for the module needs
#                     something outside it (_testcapi, compiler features).
#   linker flags      Extra Setup.local flags for a foreign library. A path
#                     Modules/<name>.a names an archive CPython's makefile
#                     builds (the vendored HACL* libraries); build.sh makes
#                     it before linking the interpreter.
#
# This file is the single list. build.sh writes the Setup.local *static* block
# from it and fails when native_api.jac does not import a listed PyInit;
# smoke.py asserts each module is built in; CI runs each module's tests.
# The C sources a module replaces are the `# removed:` entries of
# cpython-sources.txt; build_python.zig owns that parser.
