# CPython source allowlist for Jac's Linux/macOS x86_64 and aarch64 builds.
# Paths are relative to the checksum-pinned CPython archive in sources.json.
# One exact file per line; a trailing / includes a directory recursively.
# Blank lines and full-line # comments are ignored, except marked removals
# restored by the build-only host (see below). No globs.
# Unlisted archive contents are discarded before configure/make. Missing,
# overlapping, or incorrectly typed entries fail the build.
#
# A commented path carries a marker saying which builds must lack it. Counts
# use pinned CPython 3.14.6 source lines, including comments and blanks.
#
#   "# path  # removed: N source lines"
#   Replaced by the native Jac implementation. A separate build-only CPython
#   host restores these to produce the native object; no shipped runtime has
#   them, and compiler-bridge.patch detaches upstream rules that name them.
#   Excluded: 274 C files / 475,969 lines; 171 headers / 159,773 lines.
#   Total: 445 files / 635,742 source lines.
#
#   "# path  # pruned: N source lines"
#   Not needed by any build. Neither the host nor a shipped runtime has them,
#   so build-graph.patch detaches upstream rules that name them.
#   A path is pruned only when no supported platform's configure selects it
#   and its outer #if has no #else that the retained build still links.
#   Total: 29 files / 59,417 source lines.
#
#   "# path  # generated: N source lines"
#   Written from the Jac instruction table by scripts/jacpython/gen_opcode_meta.jac
#   and checked in as bootstrap/python/generated/<path>.in. Neither tree keeps
#   the archive's copy; both builds stage the checked-in one in its place.
#   Total: 5 files / 4,286 source lines.
#
# After each build, build.sh checks that no removed or pruned path came back,
# reading the marker to decide which builds must lack it.
# Keep build dependencies and ABI adapters aligned with these exclusions.
# Split a directory entry before removing only part of its contents.
# CI hashes this manifest and rebuilds/verifies Python when it changes.
# This list covers CPython; sources.json also pins its external dependencies.
# Generated headers, build prerequisites and licenses remain necessary even
# when they are not directly compiled. The mimalloc WASI source is an
# unconditional make prerequisite even when the selected platform does not
# use it.
