# CPython source allowlist for Jac's Linux/macOS x86_64 and aarch64 builds.
# Paths are relative to the checksum-pinned CPython archive in sources.json.
# One exact file per line; a trailing / includes a directory recursively.
# Blank lines and full-line # comments are ignored. No globs.
# Unlisted archive contents are discarded before the build: the C that the
# native Jac implementation, the Jac generators (scripts/jacpython/) and the
# JacPython build (bootstrap/pyconfig.zig's probes in place of configure,
# build_jacpython.zig in place of Makefile.pre.in, makesetup and Setup*)
# replace is simply not listed. Missing, overlapping, or incorrectly typed
# entries fail the build.
#
# A commented path carries a marker saying why the build lacks it. Counts
# use pinned CPython 3.14.6 source lines, including comments and blanks.
#
#   "# path  # pruned: N source lines"
#   Needed by neither the build nor the runtime.
#   A path is pruned only when no supported platform's configure selects it
#   and its outer #if has no #else that the retained build still links.
#   Total: 31 files / 61,064 source lines.
#
#   "# path  # generated: N source lines"
#   Written by a Jac generator and checked in as
#   bootstrap/python/generated/<path>.in: the opcode tables from the Jac
#   instruction table (scripts/jacpython/gen_opcode_meta.jac), every C API
#   header (Include/*.h, Include/cpython/*.h, Include/internal/) from the Jac
#   layouts, constants, C API declarations and global strings
#   (scripts/jacpython/gen_include.jac). The archive's copy is discarded and
#   the checked-in one staged in its place; a header under Include/ that is
#   not marked here fails the build.
#   Total: 283 files / 53,699 source lines.
#
# After each build, build_jacpython.zig checks that no pruned path came back.
# Keep build dependencies and ABI adapters aligned with these exclusions.
# Split a directory entry before removing only part of its contents.
# CI hashes this manifest and rebuilds/verifies Python when it changes.
# This list covers CPython; sources.json also pins its external dependencies.
# Generated headers, build prerequisites and licenses remain necessary even
# when they are not directly compiled. The mimalloc WASI source is an
# unconditional make prerequisite even when the selected platform does not
# use it.
