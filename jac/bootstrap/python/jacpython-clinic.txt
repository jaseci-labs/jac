# Native Jac modules whose argument parsing is generated from their
# Argument Clinic input by scripts/jacpython/gen_clinic.jac into
# jaclang/runtime/python/bindings/clinic/<name>.jac.
# `jac run scripts/jacpython/gen_clinic.jac --check` fails when any is stale.
# `raise-free` after a name says the module's _impl functions report errors
# as C does and never raise boundary_failure, so its glue calls them without
# an exception frame when no argument conversion can raise.
# `checked-converters` says the module's own converters and return
# converters report failure through the error indicator as C's do, so its
# glue converts those arguments without an exception frame too.
